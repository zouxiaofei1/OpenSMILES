# P-41 化合物类别的优先顺序

化合物的类别优先顺序见表 4.1。该表对由后缀表示的类别（第 1 至 20 类）以及基于化合物中优先原子的类别（第 21 至 43 类）进行了排序。*

**表 4.1 化合物一般类别按优先性递减顺序排列**

| 序号 | 类别 |
|------|------|
| 1 | 自由基 (Radicals) |
| 2 | 自由基阴离子 (Radical anions) |
| 3 | 自由基阳离子 (Radical cations) |
| 4 | 阴离子 (Anions) |
| 5 | 两性离子 (Zwitterions) |
| 6 | 阳离子 (Cations) |
| 7 | 酸 (Acids) |
| 7a | '后缀'酸，按以下顺序：羧酸（不包括碳酸或多碳酸，它们属于子类 '7b'）、磺酸、亚磺酸、硒代磺酸、亚硒代磺酸、碲代磺酸、亚碲代磺酸，每一类后面依次为相应的过氧酸、亚胺酸和腙酸。硫族类似物依次排在各含氧酸之后，在各情况下，以具有较多优先硫族原子数（O > S > Se > Te）的硫族类似物为先，首先考虑 -OOH 基团，然后根据需要再考虑 -OH 基团。（酸的完整优先顺序列表见 P-42，通过官能团置换修饰的后缀见 P-43，所有后缀优先顺序的详尽列表见表 4.4。） |
| 7b | 无可取代氢原子的碳酸，按以下顺序：多核碳酸（三碳酸、二碳酸），然后是碳酸，以及氰酸。 |
| 7c | 具有连接于中心原子的可取代氢原子的含氧酸及其酸性衍生物，按优先性递减顺序：氮酸 (azonic)、亚氮酸 (azinic)、膦酸、次膦酸、亚膦酸、亚次膦酸等（完整列表见 P-42）。 |
| 7d | 除 7b 类之外的、不具有连接于中心原子的可取代氢原子（见上述 7b），但可通过官能团置换进行官能团化或形成衍生物的单核和多核含氧酸。 |
| 7e | 用作官能母体化合物的其他一元'含氧酸'。 |
| 8 | 酸酐 (Anhydrides) [取代命名法用于命名为杂环的环状酸酐（见下述第 16 类）；官能类别名称用于无环酸酐以及少数对应于保留名酸的环状酸酐；当使用官能名称时，环状酸酐优先于非环状酸酐]。 |
| 9 | 酯 (Esters)（官能类别名称用于非环状酯；内酯及其他环状酯命名为杂环；见下述第 16 类）。 |
| 10 | 酰卤和拟卤化物 (Acid halides and pseudohalides) [首先按上述相应酸的顺序，然后按卤素原子的顺序（-F > -Cl > -Br > -I）；再按拟卤素基团的以下顺序（-N₃ > -CN > -NC > -NCO > -NCS > -NCSe > -NCTe > -CNO）]。 |
| 11 | 酰胺 (Amides) [按相应酸的顺序；环状酰胺命名为杂环（见下述第 16 类）]。 |
| 12 | 酰肼 (Hydrazides)（按相应酸的顺序）。 |
| 13 | 酰亚胺 (Imides)（仅包括衍生自具有保留名的有机二碱基或多碱基酸的环状酰亚胺）。 |
| 14 | 腈 (Nitriles)。 |
| 15 | 醛及其硫族类似物 (Aldehydes and chalcogen analogues)。 |
| 16 | 酮（类型为 -C-CO-C-）、假酮（类型为 -C-CO-X、X-CO-X 或 -CO-X-CO-，其中 X ≠ C、卤素、拟卤素或 NH₂，见 P-64.1.2）和杂酮（见 P-64.4）。参见第 8、9、11 和 13 类中关于内酯、内酰胺、酸酐、酰亚胺的内容。 |
| 17 | 羟基化合物及其硫族类似物 (Hydroxy compounds and chalcogen analogues)（包括醇和酚，二者不再有单独的排序）。 |
| 18 | 氢过氧化物（过氧醇）(Hydroperoxides, peroxols)，即 -OOH。 |
| 19 | 胺 (Amines)（定义为与一个氮原子有三个共价单键连接的化合物，即 NR₃）。 |
| 20 | 亚胺 (Imines)，R=NH 或 R=N-R′。 |

**杂环命名中由优先原子表示的类别**

| 序号 | 类别 |
|------|------|
| 21 | 氮化合物：杂环、多氮烷 (polyazanes)、肼（酰肼除外）、二氮烯 (diazenes)、羟胺、氮烷 (azanes)（酰胺、胺和亚胺除外） |
| 22 | 磷化合物：杂环、多磷烷 (polyphosphanes)、磷烷 (phosphanes) |
| 23 | 砷化合物：杂环、多砷烷 (polyarsanes)、砷烷 (arsanes) |
| 24 | 锑化合物：杂环、多锑烷 (polystibanes)、锑烷 (stibanes) |
| 25 | 铋化合物：杂环、多铋烷 (polybismuthanes)、铋烷 (bismuthanes) |
| 26 | 硅化合物：杂环、多硅烷 (polysilanes)、硅烷 (silanes) |
| 27 | 锗化合物：杂环、多锗烷 (polygermanes)、锗烷 (germanes) |
| 28 | 锡化合物：杂环、多锡烷 (polystannanes)、锡烷 (stannanes) |
| 29 | 铅化合物：杂环、多铅烷 (polyplumbanes)、铅烷 (plumbanes) |
| 30 | 硼化合物：杂环、多硼烷 (polyboranes)、硼烷 (boranes) |
| 31 | 铝化合物：杂环、多铝烷 (polyalumanes)、铝烷 (alumanes) |
| 32 | 镓化合物：杂环、多镓烷 (polygallanes)、镓烷 (gallanes) |
| 33 | 铟化合物：杂环、多铟烷 (polyindiganes)、铟烷 (indiganes) |
| 34 | 铊化合物：杂环、多铊烷 (polythallanes)、铊烷 (thallanes) |
| 35 | 氧化合物：杂环、多氧化烷 (polyoxidanes)（三氧化烷 trioxidane，但不包括过氧化物或醚） |
| 36 | 硫化合物：杂环、多硫烷 (polysulfanes)（三硫烷 trisulfane、λ⁶ 和 λ⁴ 单硫烷和二硫烷，但不包括二硫化物或硫化物） |
| 37 | 硒化合物：杂环、多硒烷 (polyselanes)（三硒烷 triselane，但不包括二硒化物、硒化物） |
| 38 | 碲化合物：杂环、多碲烷 (polytellanes)（三碲烷 tritellane，但不包括二碲化物、碲化物） |
| 39 | λ⁷、λ⁵ 和 λ³ 卤素化合物，按 F > Cl > Br > I 的顺序。 |
| 40 | 碳化合物：环、链 |
| 41 | 醚，然后硫化物、亚砜、砜；然后硒化物、硒亚砜等。 |
| 42 | 过氧化物，然后具有较多优先硫族原子数的硫族类似物，其中 O > S > Se > Te。 |
| 43 | λ¹ 卤素化合物，按 F > Cl > Br > I 的顺序 |

\* 在本表中，符号 '>' 表示'优先于'。

**示例：**

| 结构式 | 名称 | 说明 |
|--------|------|------|
| HOOC-CH₂-CH₂- | 2-羧乙基 (2-carboxyethyl)（推荐前缀） | [自由价 = 自由基 > 羧酸] |
| (CH₃)₃N⁺-CH₂-COO⁻ | (N,N-二甲基甲铵基)乙酸酯 (PIN) | （阴离子 > 阳离子） |
| HO-CH₂-CH₂-CONH₂ | 3-羟基丙酰胺 (PIN) | （酰胺 > 醇） |
| OHC-CH₂-CH₂-CN | 4-氧代丁腈 (PIN) | （腈 > 醛） |
| HSSS-SiH₃ | 三硫烷基硅烷 (trisulfanylsilane) | （预选名称；见 P-12.2）（Si > S） |
| BH₂-PH₂ | 硼烷基磷烷 (boranylphosphane) | （预选名称；见 P-12.2）（P > B） |
| (CH₃)₄Si | 四甲基硅烷 (PIN) | （Si > C） |
| (C₆H₅)₃P | 三苯基磷烷 (PIN) | （P > C） |
| CH₃-O-CH₂-S-CH₃ | 甲氧基(甲硫基)甲烷 (PIN) | （C > 醚和硫化物） |
| CH₃-SeSe-CH₂-S-CH₃ | (甲基二硒烷基)(甲硫基)甲烷 (PIN) | （C > 二硒化物和硫化物） |
| CH₃-S-CH₂-CH₂-SO-CH₃ | 1-(甲亚磺酰基)-2-(甲硫基)乙烷 (PIN) | （C > 硫化物和亚砜） |
