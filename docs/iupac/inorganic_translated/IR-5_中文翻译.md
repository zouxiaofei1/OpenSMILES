## IR-5.1 引言（Introduction）

组成命名法（compositional nomenclature）在形式上以组成为基础而非以结构为基础，因此在结构信息很少或没有、或只需传达最少结构信息时，（可能）是唯一的选择。

最简单的组成名称是*计量*名称（*stoichiometric* name），它不过是化合物经验式（第 IR-4.2.1 节）或分子式（第 IR-4.2.2 节）的反映。在计量名称中，组成元素的比例可以用几种方式表示：使用倍数前缀、氧化数或电荷数。

在有些情况下，化合物可视为由若干组分构成，而这些组分本身可以取若干类型名称中的任一种（包括计量名称）；化合物的整体名称随即由各组分的名称组合而成，以表示其比例。这类组成名称的一个类别是*广义计量名称*（见第 IR-5.4 节），其中各部分本身可以是单原子离子和多原子离子的名称。为此，专门论述离子命名的第 IR-5.3 节被纳入本章。另一个类别是为加合化合物设计的名称，其格式自成一体，见第 IR-5.5 节。

## IR-5.2 元素和二元化合物的计量名称（Stoichiometric names of elements and binary compounds）

纯计量名称不携带关于被命名物种结构的任何信息。

最简单的情形是，被命名的物种只由一种元素组成，其名称是在元素名称上加上相应的倍数前缀（*例如* S₈，octasulfur）。第 IR-3.4.3 节给出了这类情形的示例。

为二元化合物构造计量名称时，把一种元素指定为电正性组分，另一种指定为电负性组分。按*惯例*，电正性组分是在表 VI* 序列中靠后的元素，其名称就是未经修饰的元素名称（表 I）。电负性组分的名称则通过在元素名称上加词尾 ‘ide’ 得到，第 IR-5.3.3.2 节对单原子阴离子有详细说明。所有这样加上 ‘ide’ 词尾的元素名称列于表 IX。

随后，化合物的计量名称由电正性组分的名称（先引用）与电负性组分的名称组合而成，两者都按需用必要的倍数前缀（‘mono’、‘di’、‘tri’、‘tetra’、‘penta’ *等*，见表 IV）适当限定。倍数前缀置于其所修饰的名称之前，并与该名称直接相连，不加空格或连字符。倍数前缀的末尾元音不应省略（不过由于一般用法，‘monoxide’ 而非 ‘monooxide’ 是允许的例外）。在英语中，名称的两部分用一个空格分隔。

计量名称可以与经验式相对应，也可以与不同于经验式的分子式相对应（比较下面的示例 3 和示例 4）。

**示例：**

|  |  |
|---|---|
| 1. HCl | hydrogen chloride |
| 2. NO | nitrogen oxide, 或 nitrogen monooxide, 或 nitrogen monoxide |
| 3. NO₂ | nitrogen dioxide |
| 4. N₂O₄ | dinitrogen tetraoxide |
| 5. OCl₂ | oxygen dichloride |
| 6. O₂Cl | dioxygen chloride |
| 7. Fe₃O₄ | triiron tetraoxide |
| 8. SiC | silicon carbide |
| 9. SiCl₄ | silicon tetrachloride |
| 10. Ca₃P₂ | tricalcium diphosphide, 或 calcium phosphide |
| 11. NiSn | nickel stannide |
| 12. Cu₅Zn₈ | pentacopper octazincide |
| 13. Cr₂₃C₆ | tricosachromium hexacarbide |

> 原书脚注：* 用罗马数字编号的表汇集于本书末尾。

如果在化合物的计量组成上没有歧义，二元名称中不必使用倍数前缀（如上面的示例 10）。严格说来，前缀 ‘mono’ 是多余的，只有在讨论组成上相关的物质时需要强调计量组成时才用到，如上面的示例 2、3 和 4。

或者，组分的比例也可以用氧化数或电荷数表示（第 IR-5.4.2 节）。

对于含两种以上元素的化合物，构造组成名称还需要进一步的约定（见第 IR-5.4 和 IR-5.5 节）。

## IR-5.3 离子与自由基的名称（Names of ions and radicals）

### IR-5.3.1 总则（General）

计量名称中不必指明原子的电荷。然而在许多情况下，已知原子或原子团带有特定的电荷。在组成命名法内，化合物的名称可以包含各个离子的名称，这些离子名称按计量名称构造，或按下述其他原则构造。

### IR-5.3.2 阳离子（Cations）

#### IR-5.3.2.1 总则（General）

阳离子（cation）是带有一个或多个正电荷的单原子或多原子物种。阳离子的电荷在名称中可以用电荷数表示；对于按加成法命名的阳离子，则用中心原子的氧化数表示。氧化数与电荷数在第 IR-5.4.2.2 节讨论。

#### IR-5.3.2.2 单原子阳离子（Monoatomic cations）

单原子阳离子的名称是元素名称后接置于括号内的适当电荷数。单原子阳离子中的未成对电子可用自由基点表示，*即*置于电荷之前的一个居中圆点，必要时在其前加数字。

**示例：**

|  |  |
|---|---|
| 1. Na⁺ | sodium(1+) |
| 2. Cr³⁺ | chromium(3+) |
| 3. Cu⁺ | copper(1+) |
| 4. Cu²⁺ | copper(2+) |
| 5. I⁺ | iodine(1+) |
| 6. H⁺ | hydrogen(1+), hydron |
| 7. ¹H⁺ | protium(1+), proton |
| 8. ²H⁺ | deuterium(1+), deuteron |
| 9. ³H⁺ | tritium(1+), triton |
| 10. He<sup>•</sup>⁺ | helium(<sup>•</sup>1+) |
| 11. O<sup>•</sup>⁺ | oxygen(<sup>•</sup>1+) |
| 12. N₂⁽²<sup>•</sup>⁾²⁺ | dinitrogen(2<sup>•</sup>2+) |

氢的同位素名称在第 IR-3.3.2 节讨论。

#### IR-5.3.2.3 同多原子阳离子（Homopolyatomic cations）

同多原子阳离子通过把电荷数加到相应中性物种的计量名称上来命名，*即*元素名称加上适当的倍数前缀。可以加上自由基点以表示未成对电子的存在。

**示例：**

|  |  |
|---|---|
| 1. O₂⁺ 或 O₂<sup>•</sup>⁺ | dioxygen(1+) 或 dioxygen(<sup>•</sup>1+) |
| 2. S₄²⁺ | tetrasulfur(2+) |
| 3. Hg₂²⁺ | dimercury(2+) |
| 4. Bi₅⁴⁺ | pentabismuth(4+) |
| 5. H₃⁺ | trihydrogen(1+) |

#### IR-5.3.2.4 杂多原子阳离子（Heteropolyatomic cations）

杂多原子阳离子通常按取代法（见第 IR-6.4 节）或加成法（见第 IR-7 章）命名。取代名称不需要电荷数，因为名称本身已隐含电荷（下面示例 2 和 4）。加成名称中可以加上自由基点以表示未成对电子的存在。

少数阳离子有已确立且仍可接受的非系统名称。

**示例：**

|  |  |
|---|---|
| 1. NH₄⁺ | azanium（取代法）, 或 ammonium（可接受的非系统名称） |
| 2. H₃O⁺ | oxidanium（取代法）, 或 oxonium（可接受的非系统名称；*不*是 hydronium） |
| 3. PH₄⁺ | phosphanium（取代法） |
| 4. H₄O²⁺ | oxidanediium（取代法） |

5. SbF₄⁺　tetrafluorostibanium（取代法），或 tetrafluoridoantimony(1+) 或 tetrafluoridoantimony(V)（两者均为加成法）

6. BH₃<sup>•</sup>⁺　boraniumyl（取代法）或 trihydridoboron(<sup>•</sup>1+)（加成法）

更多示例见表 IX。

### IR-5.3.3 阴离子（Anions）

#### IR-5.3.3.1 概览（Overview）

阴离子（anion）是带有一个或多个负电荷的单原子或多原子物种。阴离子的电荷在名称中可以用电荷数表示；对于按加成法命名的阴离子，则用中心原子的氧化数表示。氧化数与电荷数在第 IR-5.4.2.2 节讨论。

阴离子名称的词尾有 ‘ide’（单原子或同多原子物种、由母体氢化物命名的杂多原子物种）、‘ate’（按加成法命名的杂多原子物种），以及 ‘ite’（用于少数仍可接受、但并非源自现行系统命名法的名称）。没有歧义时，电荷数可以省略，如下面的示例 1。基于母体氢化物的名称不带电荷数，因为名称本身已隐含电荷（下面示例 3 和 4）。

**示例：**

|  |  |
|---|---|
| 1. Cl⁻ | chloride(1−), 或 chloride |
| 2. S₂²⁻ | disulfide(2−) |
| 3. PH₂⁻ | phosphanide |
| 4. PH²⁻ | phosphanediide |
| 5. [CoCl₄]²⁻ | tetrachloridocobaltate(2−), 或 tetrachloridocobaltate(II) |
| 6. NO₂⁻ | dioxidonitrate(1−), 或 nitrite |

#### IR-5.3.3.2 单原子阴离子（Monoatomic anions）

单原子阴离子的名称是元素名称（表 I）经修饰而带上阴离子指示词尾 ‘ide’：或把元素名称的词尾（‘en’、‘ese’、‘ic’、‘ine’、‘ium’、‘ogen’、‘on’、‘orus’、‘um’、‘ur’、‘y’ 或 ‘ygen’）替换为 ‘ide’，或把 ‘ide’ 直接加在元素名称之后作为词尾。

**示例：**

1. chlorine, chloride

2. carbon, carbide

3. xenon, xenonide

4. tungsten, tungstide

5. bismuth, bismuthide

6. sodium, sodide

7. potassium, potasside

有一种情形必须选用缩略的名称：germanium, germide。系统名称 ‘germanide’ 指的是阴离子 GeH₃⁻。

有些单原子阴离子的名称基于拉丁语元素名的词根。在这类名称中，词尾 ‘um’ 或 ‘ium’ 被替换为 ‘ide’。

**示例：**

8. silver, argentum, argentide

9. gold, aurum, auride

10. copper, cuprum, cupride

11. iron, ferrum, ferride

12. lead, plumbum, plumbide

13. tin, stannum, stannide

所有这样修饰的元素名称都收在表 IX 中。

电荷数和自由基点可以按需加上，以完整地指定阴离子。

**示例：**

|  |  |
|---|---|
| 14. O²⁻ | oxide(2−), 或 oxide |
| 15. O<sup>•</sup>⁻ | oxide(<sup>•</sup>1−) |
| 16. N³⁻ | nitride(3−), 或 nitride |

#### IR-5.3.3.3 同多原子阴离子（Homopolyatomic anions）

同多原子阴离子通过把电荷数加到相应中性物种的计量名称上来命名，*即*元素名称加上适当的倍数前缀。同样，可以按需加上自由基点。

在少数情况下，非系统名称仍是可接受的替代名称。

**示例：**

| 1. O₂⁻ 或 O₂<sup>•</sup>⁻ | dioxide(1−) 或 dioxide(<sup>•</sup>1−) | superoxide |
| 2. O₂²⁻ | dioxide(2−) | peroxide |
| 3. O₃⁻ | trioxide(1−) | ozonide |
| 4. I₃⁻ | triiodide(1−) |  |
| 5. Cl₂<sup>•</sup>⁻ | dichloride(<sup>•</sup>1−) |  |
| 6. C₂²⁻ | dicarbide(2−) | acetylide |
| 7. N₃⁻ | trinitride(1−) | azide |

|  |  |
|---|---|
| 8. S₂²⁻ | disulfide(2−) |
| 9. Sn₅²⁻ | pentastannide(2−) |
| 10. Pb₉⁴⁻ | nonaplumbide(4−) |

在某些情况下，同多原子阴离子可视为由母体氢化物脱去氢离子（hydron）而得（见第 IR-6.4 节）。

**示例：**

|  |  |
|---|---|
| 11. O₂²⁻ | dioxidanediide |
| 12. S₂²⁻ | disulfanediide |

#### IR-5.3.3.4 杂多原子阴离子（Heteropolyatomic anions）

杂多原子阴离子通常按取代法（见第 IR-6.4.4 节）或加成法（见第 IR-7 章和第 IR-9.2.2 节）命名。加成名称中可以加上自由基点以表示未成对电子的存在。

## IR-5.4 广义计量名称（Generalized stoichiometric names）

### IR-5.4.1 电正性和电负性组分的引用次序（Order of citation of electropositive and electronegative constituents）

被命名化合物的组分划分为形式电正性组分与形式电负性组分。至少要有一个电正性组分和一个电负性组分。按定义，阳离子是电正性的，阴离子是电负性的。按惯例，电正性元素在表 VI 中比电负性元素出现得更靠后。

原则上，若化合物含两种以上元素，划分为电正性组分与电负性组分是任意的。但在实践中，确定分界线在何处通常不成问题。

在整体名称中，电正性组分的名称位于电负性组分的名称之前。在每一类组分内，引用次序按字母顺序（忽略倍数前缀），但若氢确实被划为电正性组分，则在电正性组分中氢总是最后引用。

这一构造广义计量名称的原则，与第 IR-4.4.3.4 节构造‘广义盐式’的原则相对应。然而，如下面示例 4、5 和 7 所示，广义计量名称中的引用次序不一定与相应广义盐式中符号的次序相同。

下列广义计量名称仅基于单元素组分，不携带关于结构的信息。

**示例：**

|  |  |
|---|---|
| 1. IBr | iodine bromide |
| 2. PBrClI | phosphorus bromide chloride iodide |
| 3. ArHF 或 ArFH | argon hydrogen fluoride, 或 argon fluoride hydride |

4. ClOF 或 OClF　chlorine oxygen fluoride 或 oxygen chloride fluoride

5. CuK₅Sb₂ 或 K₅CuSb₂　copper pentapotassium diantimonide,

或 pentapotassium cupride diantimonide

从这些示例可见，名称中任意两种元素的先后取决于把元素划分为电正性组分与电负性组分的任意性。（第 IR-4.4.3.4 节所示的化合物式中元素符号的次序也是如此。）表示示例 3 和 4 中化合物实际结构（分别为 FArH 和 FClO）的加成名称见第 IR-7.2 节。

在某些情况下，由于缺少结构信息，用取代命名法或加成命名法为离子命名不可能或不可取。这时最好给出计量名称并加上电荷数。需要加括号以明确该电荷数表示离子的整体电荷。

*示例：*

6. O₂Cl₂⁺　(dioxygen dichloride)(1+)

当多原子离子的名称作为组分出现在广义计量名称中时，该名称常常隐含一定量的结构信息。

*示例：*

7. NaNH₄[HPO₄]　ammonium sodium hydrogenphosphate

### IR-5.4.2 组分比例的表示（Indication of proportions of constituents）

#### IR-5.4.2.1 使用倍数前缀（Use of multiplicative prefixes）

组分（无论单原子还是多原子）的比例，在广义计量名称中可以用倍数前缀表示，与二元化合物组分的情形（第 IR-5.2 节）相同。

**示例：**

|  |  |
|---|---|
| 1. Na₂CO₃ | disodium trioxidocarbonate, 或 sodium carbonate |
| 2. K₄[Fe(CN)₆] | tetrapotassium hexacyanidoferrate |
| 3. PCl₃O | phosphorus trichloride oxide |
| 4. KMgCl₃ | magnesium potassium trichloride |

当组分名称本身以倍数前缀开头时（如 disulfate、dichromate、triphosphate、tetraborate *等*），或在其他情况下可能出现歧义时，使用另一些倍数前缀 ‘bis’、‘tris’、‘tetrakis’、‘pentakis’ *等*（表 IV），并把受该替代前缀作用的基团名称置于括号中。

**示例：**

|  |  |
|---|---|
| 5. Ca(NO₃)₂ | calcium bis(trioxidonitrate), 或 calcium nitrate |
| 6. (UO₂)₂SO₄ | bis(dioxidouranium) tetraoxidosulfate |
| 7. Ba(BrF₄)₂ | barium bis(tetrafluoridobromate) |
| 8. U(S₂O₇)₂ | uranium bis(disulfate) |
| 9. Ca₃(PO₄)₂ | tricalcium bis(phosphate) |
| 10. Ca₂P₂O₇ | calcium diphosphate |
| 11. Ca(HCO₃)₂ | calcium bis(hydrogencarbonate) |

#### IR-5.4.2.2 使用电荷数与氧化数（Use of charge and oxidation numbers）

名称中可以用另外两种手段之一来提供组分比例的信息：电荷数（charge number），它表示离子电荷；以及氧化数（oxidation number），它表示氧化态。在命名法中，优先使用电荷数，因为氧化数的确定有时含混且主观。只有当氧化数的指定毫无不确定性时，才宜使用氧化数。

*电荷数*是一个数值大小等于离子电荷的数。它写在离子名称之后，置于括号中，不留空格。电荷用阿拉伯数字书写，后接电荷的正负号。注意，与（用于化学式的）上标电荷标示不同，这里总是把 1 写出来。中性物种的名称之后不使用电荷数。

**示例：**

|  |  |
|---|---|
| 1. FeSO₄ | iron(2+) sulfate |
| 2. Fe₂(SO₄)₃ | iron(3+) sulfate |
| 3. (UO₂)₂SO₄ | dioxidouranium(1+) sulfate |
| 4. UO₂SO₄ | dioxidouranium(2+) sulfate |
| 5. K₄[Fe(CN)₆] | potassium hexacyanidoferrate(4−) |
| 6. [Co(NH₃)₆]Cl(SO₄) | hexaamminecobalt(3+) chloride sulfate |

元素的*氧化数*（见第 IR-4.6.1 和 IR-9.1.2.8 节）用置于括号中的罗马数字表示，紧跟在它所指向的元素的名称（必要时已加词尾 ‘ate’ 修饰）之后。氧化数可以是正的、负的或零（用数字 0 表示）。除非明确使用负号，氧化数总是非负的（正号从不使用）。命名法不使用非整数氧化数。

**示例：**

|  |  |
|---|---|
| 7. PCl₅ | phosphorus(V) chloride |
| 8. Na[Mn(CO)₅] | sodium pentacarbonylmanganate(−I) |
| 9. [Fe(CO)₅] | pentacarbonyliron(0) |

推断氧化数时遵循若干约定，其用法在过渡元素化合物的名称中尤为常见。氢与非金属元素结合时视为正（氧化数 I），与金属元素结合时视为负（氧化数 −I）。与金属原子结合的有机基团有时当作阴离子处理（例如甲基配体通常视为 methanide 离子 CH₃⁻），有时当作中性处理（*例如* carbon monooxide）。同种原子之间的键对氧化数没有贡献。

**示例：**

|  |  |
|---|---|
| 10. N₂O | nitrogen(I) oxide |
| 11. NO₂ | nitrogen(IV) oxide |
| 12. Fe₃O₄ | iron(II) diiron(III) oxide |
| 13. MnO₂ | manganese(IV) oxide |
| 14. CO | carbon(II) oxide |
| 15. FeSO₄ | iron(II) sulfate |
| 16. Fe₂(SO₄)₃ | iron(III) sulfate |
| 17. SF₆ | sulfur(VI) fluoride |
| 18. (UO₂)₂SO₄ | dioxidouranium(V) sulfate |
| 19. UO₂SO₄ | dioxidouranium(VI) sulfate |
| 20. K₄[Fe(CN)₆] | potassium hexacyanidoferrate(II), 或 potassium hexacyanidoferrate(4−) |
| 21. K₄[Ni(CN)₄] | potassium tetracyanidonickelate(0), 或 potassium tetracyanidonickelate(4−) |
| 22. Na₂[Fe(CO)₄] | sodium tetracarbonylferrate(−II), 或 sodium tetracarbonylferrate(2−) |
| 23. [Co(NH₃)₆]Cl(SO₄) | hexaamminecobalt(III) chloride sulfate, 或 hexaamminecobalt(3+) chloride sulfate |
| 24. Fe₄[Fe(CN)₆]₃ | iron(III) hexacyanidoferrate(II), 或 iron(3+) hexacyanidoferrate(4−) |

注意，命名同多原子离子时不再推荐使用氧化数。这是为了避免歧义。氧化数指的是所涉元素中各个单个原子，即使它被附加到含有倍数前缀的名称上，比较上面的示例 12。为符合这一做法，dimercury(2+)（见第 IR-5.3.2.3 节）将不得不命名为 dimercury(I)；dioxide(2−)（见第 IR-5.3.3.3 节）将成为 dioxide(−I)；而像 pentabismuth(4+)（见第 IR-5.3.2.3 节）和 dioxide(1−)（见第 IR-5.3.3.3 节）这些具有分数形式氧化数的离子则根本无法命名。

#### IR-5.4.2.3 多个单原子组分与同多原子组分（Multiple monoatomic constituents vs. homopolyatomic constituents）

应注意区分多个单原子组分与多原子组分。这一区别往往不能从化学式看出，而是隐含其中。

**示例：**

1. TlI₃　thallium tris(iodide), 或 thallium(III) iodide,

或 thallium(3+) iodide

2. Tl(I₃)　thallium triiodide(1−), 或 thallium(I) (triiodide),

或 thallium(1+) (triiodide)

示例 1 和 2 中的两种化合物总式都是 TlI₃，两者都可以用简单的计量名称 thallium triiodide 命名。然而，在名称中传达更多信息是可能的，而且通常也是合意的。

示例 1 中的化合物由碘化物 I⁻ 与铊按 3:1 的比例组成，而示例 2 中的化合物由 triiodide(1−) I₃⁻ 与铊按 1:1 的比例组成。因此，第一种化合物的第一个名称使用倍数前缀 ‘tris’，以完全清楚地表明涉及三个碘离子而不是一个三碘离子。替代的名称分别用铊的氧化数 III 和电荷数 3+ 来间接传达组分的比例。

在示例 2 的第一个名称中，可以看出电负性组分是一个带 −1 电荷的同多原子实体。其后的两个名称通过把氧化数或电荷数加到 thallium 这一名称上来间接传达这一点；在电负性部分的名称外加括号，强化了它是一个同多原子实体。

对这两种化合物，即使部分冗余，给出包括铊离子电荷数在内的完全明确的名称也是可以接受的。因此在索引和登录这类系统场合，示例 1 和示例 2 分别用 thallium(3+) tris(iodide) 和 thallium(1+) triiodide(1−) 可能更为可取。

**示例：**

3. HgCl₂　mercury dichloride, 或 mercury(II) chloride,

或 mercury(2+) chloride

4. Hg₂Cl₂　dimercury dichloride, 或 (dimercury) dichloride,

或 dimercury(2+) chloride

在示例 4 中，第一个名称纯粹是计量的，而第二个名称包含更多信息，指出该化合物含有一个同双原子阳离子。在最后一个名称中，由于指定了双正离子的电荷，氯化物前的 ‘di’ 前缀没有必要。

**示例：**

5. Na₂S₃　disodium (trisulfide)（这表明存在多原子阴离子）,

或 sodium trisulfide(2−)（已指明阴离子的电荷时，阳离子名称上的倍数前缀没有必要）

6. Fe₂S₃　diiron tris(sulfide), 或 iron(III) sulfide

含有 S<sub>n</sub>²⁻ 链阴离子的盐，以及含有多个 S²⁻ 阴离子的盐，都被称为 ‘polysulfides’（多硫化物），但如所演示，可以给出能区分这些情形的名称。

**示例：**

|  |  |
|---|---|
| 7. K₂O | dipotassium oxide |
| 8. K₂O₂ | dipotassium (dioxide), 或 potassium dioxide(2−) |
| 9. KO₂ | monopotassium (dioxide), 或 potassium dioxide(1−) |
| 10. KO₃ | potassium (trioxide), 或 potassium trioxide(1−) |

显然，像 ‘potassium dioxide’ 这样的简单计量名称，虽然严格说来没有歧义（所指为示例 9 中的化合物），却很容易被误解。在其他情况下，基于化学知识，实际上不存在误解的可能，此时最常用的是简单的计量名称，如下面的示例 11 和 12。

**示例：**

11. BaO₂　barium dioxide（简单计量名称）, 或 barium (dioxide) 或 barium dioxide(2−)（指明双原子阴离子）, 或 barium peroxide（使用该阴离子可接受的替代名称）

12. MnO₂　manganese dioxide（简单计量名称）, 或 manganese bis(oxide)（指明两个氧化物离子而非一个双原子阴离子）, 或 manganese(IV) oxide

## IR-5.5 （形式）加合化合物的名称（Names of (formal) addition compounds）

*加合化合物*（addition compounds）一词涵盖给体-受体配合物（加合物）以及多种晶格化合物。然而，此处所述方法不仅与这类化合物有关，也与复盐、某些结构不确定的化合物、或无需传达其完整结构的化合物有关。

这类广义加合化合物中各个组分的名称，各自用适当的命名体系构造，无论是组成命名法、取代命名法还是加成命名法。化合物的整体名称随即由各组分的名称用 ‘em’ 破折号（—）连接而成；各组分的比例在名称之后用一个计量描述符表示，该描述符由阿拉伯数字组成，数字之间以斜线分隔。描述符置于括号中，与化合物名称之间隔一个空格。各组分名称的次序，首先按组分数目递增，其次按字母顺序。唯一的例外是，组分名称 ‘water’ 总是最后引用。（注意这与文献 2 中的规则不同，按该规则组分的名称必须遵循化学式给出的次序。）描述符中的数字与相应组分名称的次序一致。

对于以水为组分的加合化合物，由于长期确立的用法，类名 ‘hydrates’（水合物）可以接受，尽管词尾 ‘ate’ 看来可能表示一个阴离子组分。对于计量组成简单的水合物，经典 ‘hydrate’ 类型的名称可以接受，但对于像下面示例 12 那样的非整数计量组成，尚未制订规则。此外，由于含义含混，‘deuterate’ 与 tritiate’ 二词不能用于 ²H₂O 和 ³H₂O 或其他同位素修饰的水物种的加合化合物。示例 3 给出了一种带同位素修饰的本类化合物的化学式和名称。在此情形下，修饰后的组分化学式和名称按文献 3 第 II-2.3.3 节的规则给出。

> 原书脚注：术语 ‘deuterate’ 与 ‘tritiate’ 不能用于 ²H₂O 与 ³H₂O 的加合化合物。

（译注：底稿受 PDF 分页影响，把该脚注标记处的正文断成两段，并把脚注排到第 IR-5.6 节之后；此处按原书第 80 页的脚注标记位置复原。原文引 tritiate 时缺前引号，照录。）

**示例：**

|  |  |
|---|---|
| 1. BF₃·2H₂O | boron trifluoride—water (1/2) |
| 2. 8Kr·46H₂O | krypton—water (8/46) |
| 3. 8Kr·46³H₂O | krypton—(³H₂)water (8/46) |
| 4. CaCl₂·8NH₃ | calcium chloride—ammonia (1/8) |
| 5. AlCl₃·4EtOH | aluminium chloride—ethanol (1/4) |
| 6. BiCl₃·3PCl₅ | bismuth(III) chloride— phosphorus(V) chloride (1/3) |
| 7. 2Na₂CO₃·3H₂O₂ | sodium carbonate—hydrogen peroxide (2/3) |
| 8. Co₂O₃·*n*H₂O | cobalt(III) oxide—water (1/*n*) |
| 9. Na₂SO₄·10H₂O | sodium sulfate—water (1/10), 或 sodium sulfate decahydrate |
| 10. Al₂(SO₄)₃·K₂SO₄·24H₂O | aluminium sulfate—potassium sulfate—water (1/1/24) |
| 11. AlK(SO₄)₂·12H₂O | aluminium potassium bis(sulfate) dodecahydrate |
| 12. 3CdSO₄·8H₂O | cadmium sulfate—water (3/8) |

从命名法的角度看，给体-受体配合物与配位化合物之间没有差别。因此对这类体系可以给出如第 IR-7.1 至 IR-7.3 节和第 IR-9 章所述的加成名称。

*示例：*

13. BH₃·(C₂H₅)₂O 或 [B{(C₂H₅)₂O}H₃]　borane—ethoxyethane (1/1),

或 (ethoxyethane)trihydridoboron

文献 4 第 P-68.1 节对有机给体-受体配合物给出了略有不同的命名法。

## IR-5.6 小结（Summary）

组成名称或是计量类型（此外，除同原子物种外，这类名称又属二元类型），或是加合化合物类型。当名称所要传达的结构信息很少或没有时，使用组成命名法。然而，对于整体以组成命名法命名的化合物，可以用取代命名法或加成命名法来表示其组分的结构。取代命名法见第 IR-6 章，加成命名法见第 IR-7、IR-8 和 IR-9 章。
