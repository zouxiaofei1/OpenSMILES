## IR-3.1 原子的名称与符号（Names and symbols of atoms）

某些化学元素（例如锑（antimony））名称的由来已湮没于古代。过去三百年间被确认（或发现）的其他元素，则依其来源、物理或化学性质等各种关联命名，*等等*，而更晚近则用以纪念杰出科学家的名字。

过去，有些元素被赋予两个名称，因为有两个研究组宣称发现了它们。为避免这种混乱，1947 年决定：在新元素的存在被证明到无可置疑之后，发现者有权向 IUPAC *建议*一个名称，但只有无机化学命名委员会（Commission on Nomenclature of Inorganic Chemistry，CNIC）才能向 IUPAC 理事会提出推荐，以作出最终决定。

按现行程序，¹ 对新元素发现的宣称首先由 IUPAC-IUPAP（国际纯粹与应用物理联合会）联合委员会审查，该委员会随后确定优先权。被认可的发现者随之受邀向无机化学部 *建议*一个名称，该部再向 IUPAC 理事会提出正式推荐。需要强调，按上述程序产生的任何新元素名称，一经理事会批准，并不意图带有任何关于发现优先权的含义。对 IUPAC 过去批准的名称同样如此理解，无论其前史如何。

IUPAC 批准的原子序数 1–111 的原子名称（供英语使用）按字母顺序列于表 I*。显然期望任何语言中使用的名称尽可能与这些名称相近，但也承认，对于过去命名的元素，其他语言中常有根深蒂固且迥然不同的名称。表 I 的脚注中引用了一些现在英语中已不使用的名称，但它们或是原子符号的基础，或是命名法中所用某些词缀的基础。

> 原书脚注：* 用罗马数字编号的表集中收录于本书末尾。

在化学式中使用，每个原子由表 I 所示正体（upright type）的唯一符号表示。此外，符号 D 和 T 可分别用于质量数为二和三的氢同位素（见 IR-3.3.2 节）。

### IR-3.1.1 新元素的系统命名法与符号（Systematic nomenclature and symbols for new elements）

新发现的元素可在科学文献中提及，但在它们从 IUPAC 获得永久名称和符号之前，需要有临时指称。这类元素可用其原子序数指称，例如「元素 120」，但 IUPAC 已批准了一套系统命名法及一系列三字母符号（见表 II）。²

名称直接用元素的原子序数由下列数词词根导出：

| 0 = nil | 3 = tri | 6 = hex | 9 = enn |
|---|---|---|---|
| 1 = un | 4 = quad | 7 = sept |  |
| 2 = bi | 5 = pent | 8 = oct |  |

词根按构成原子序数的数字的顺序组合，并以「ium」结尾拼出名称。「enn」的末尾「n」出现在「nil」之前时省略，「bi」和「tri」的末尾「i」出现在「ium」之前时省略。

元素的符号由构成名称的各数词词根的首字母组成。

**示例：**

- 1. 元素 113 —— ununtrium，符号 Uut

## IR-3.2 用位标（下标和上标）表示质量数、电荷和原子序数（Indication of mass, charge and atomic number using indexes (subscripts and superscripts)）

核素的质量数、电荷和原子序数由置于符号周围的三个位标（下标和上标）表示。各位置占用如下：

| 位标 | 含义 |
|---|---|
| 左上位标 | 质量数 |
| 左下位标 | 原子序数 |
| 右上位标 | 电荷 |

置于符号为 A 的原子上的电荷表示为 Aⁿ⁺ 或 Aⁿ⁻，而非 A⁺ⁿ 或 A⁻ⁿ。

原子符号的右下位置留给表示化学式中该原子数目的位标（下标）。例如，S₈ 是含八个硫原子的分子的化学式（见 IR-3.4 节）。对于同时表示氧化态或电荷的形式体系，见 IR-4.6.1 节。

**示例：**

- 1. ³²₁₆S²⁺ 表示原子序数 16、质量数 32 的双电离硫原子。

²⁶₁₂Mg 与 ⁴₂He 核反应生成 ²⁹₁₃Al 与 ¹₁H 核，写作³：

²⁶Mg(α, p)²⁹Al

关于用原子符号在化学式中表示同位素改性，以及同位素改性化合物的命名，分别见 IR-4.5 节与文献 4 的第 II-2 章。

## IR-3.3 同位素（Isotopes）

### IR-3.3.1 元素的同位素（Isotopes of an element）

一元素的同位素都带相同的名称（但见 IR-3.3.2 节），并以质量数标示（见 IR-3.2 节）。例如，原子序数 8、质量数 18 的原子命名为 oxygen-18，符号为 ¹⁸O。

### IR-3.3.2 氢的同位素（Isotopes of hydrogen）

氢是 IR-3.3.1 节规则的一个例外，因为三种同位素 ¹H、²H 和 ³H 可分别有替代名称 protium（氕）、deuterium（氘）和 tritium（氚）。符号 D 和 T 可用于 deuterium 和 tritium，但 ²H 和 ³H 更受推荐，因为 D 和 T 会打乱化学式中的字母顺序（见 IR-4.5 节）。一个 μ 子与一个电子的组合表现如同氢的轻同位素，命名为 muonium（μ 子素），符号 Mu。⁵

由这些名称分别衍生出阳离子 ¹H⁺、²H⁺、³H⁺ 和 Mu⁺ 的名称：proton（质子）、deuteron（氘核）、triton（氚核）和 muon（μ 子）。由于 proton 这一名称常在互相矛盾的意义上使用，*即*，一方面指同位素纯的 ¹H⁺ 离子，另一方面指天然存在的未区分的同位素混合物，故建议未区分的混合物一般用由 hydrogen 导出的名称 hydron（氢离子）指称。

## IR-3.4 元素（或单质）（Elements (or elementary substances)）

### IR-3.4.1 分子式或结构未确定的元素的名称（Name of an element of indefinite molecular formula or structure）

化学式未定义、或为同素异形体混合物的元素试样（见 IR-3.4.2 至 IR-3.4.5 节），与原子同名。

### IR-3.4.2 元素的同素异形体（同素异形改性体）（Allotropes (allotropic modifications) of elements）

元素的同素异形改性体带有其所派生自的原子的名称，并加一个描述符以指明该改性体。常见的描述符有希腊字母（α、β、γ、*等等*）、颜色，以及在适当情况下用矿物名（*例如*碳的众所周知的形式：石墨（graphite）和金刚石（diamond））。这类名称应视为暂用，仅在结构确立之前使用；结构确立之后，推荐采用基于分子式（见 IR-3.4.3 节）或晶体结构（见 IR-3.4.4 节）的合理体系。对于元素的非晶改性体，以及在其常见形式下为密切相关结构的混合物（如石墨（graphite））或具有定义不清的无序结构（如红磷（red phosphorus））的那些同素异形体，通用名称将继续使用（见 IR-3.4.5 节）。

### IR-3.4.3 具有确定分子式的同素异形体的名称（Names of allotropes of definite molecular formula）

系统名称基于分子中原子数目，由表 IV 的倍数前缀表示。前缀「mono」仅在该元素通常不以单原子状态存在时使用。若数目大且未知，如在长链或大环中，可用前缀「poly」。在需要处，可用适当前缀（表 V）表示结构。当需要指明具有确定结构的元素的特定多晶型物（例如 S₈ 的 α-、β- 或 γ- 型）时，应使用 IR-3.4.4 节的方法（见 IR-3.4.4 节中的示例 13–15）。

**示例：**

|  | *Formula* | *Systematic name* | *Acceptable alternative name* |
|---|---|---|---|
| 1. | Ar | argon |  |
| 2. | H | monohydrogen |  |
| 3. | N | mononitrogen |  |
| 4. | N₂ | dinitrogen |  |
| 5. | N₃<sup>•</sup> | trinitrogen(<sup>•</sup>) |  |
| 6. | O₂ | dioxygen | oxygen（氧） |
| 7. | O₃ | trioxygen | ozone（臭氧） |
| 8. | P₄ | tetraphosphorus | white phosphorus（白磷） |
| 9. | S₆ | hexasulfur | ε-sulfur（ε-硫） |
| 10. | S₈ | *cyclo*-octasulfur | α-sulfur（α-硫）、β-sulfur（β-硫）、γ-sulfur（γ-硫） |
| 11. | Sₙ | polysulfur | μ-sulfur（μ-硫，或称 plastic sulfur 塑性硫） |
| 12. | C₆₀ | hexacontacarbon | [60]fullerene（[60]富勒烯） |

在示例 12 中，名称 [60]fullerene 应视为某特定 C₆₀ 结构的可接受的非系统名称。更多细节见文献 6 的 P-27 节。

### IR-3.4.4 元素的晶态同素异形改性体（Crystalline allotropic modifications of an element）

晶态同素异形改性体是元素的多晶型物。每一个都可通过在原子名称之后的括号中加上 Pearson 符号（见 IR-11.5.2 节）⁷ 来命名。该符号以其布拉维点阵（晶类和晶胞类型，见表 IR-3.1）以及晶胞中原子数目来定义该同素异形体的结构。因此，iron(*cF*4) 是 iron 的同素异形改性体（γ-iron），具有立方（*c*）、全面心（*F*）点阵，晶胞中含四个铁原子。

**表 IR-3.1 用于十四种布拉维点阵的 Pearson 符号**

| *System* | *Lattice symbol*ᵃ | *Pearson symbol* |
|---|---|---|
| Triclinic | *P* | *aP* |
| Monoclinic | *P* | *mP* |
|  | *S*ᵇ | *mS* |
| Orthorhombic | *P* | *oP* |
|  | *S* | *oS* |
|  | *F* | *oF* |
|  | *I* | *oI* |
| Tetragonal | *P* | *tP* |
|  | *I* | *tI* |
| Hexagonal (and trigonal *P*) | P | *hP* |
| Rhombohedral | *R* | *hR* |
| Cubic | *P* | *cP* |
|  | *F* | *cF* |
|  | *I* | *cI* |

ᵃ *P*、*S*、*F*、*I* 和 *R* 分别为原始（primitive）、侧面心（side-face-centred）、全面心（all-face-centred）、体心（body-centred）和菱面体（rhombohedral）点阵。字母 *C* 以前曾用来代替 *S*。

ᵇ 第二种设置（second setting），*y* 轴唯一。

**示例：**

|  | *Symbol* | *Systematic name* | *Acceptable alternative name* |
|---|---|---|---|
| 1. | Pₙ | phosphorus(*oS*8) | black phosphorus（黑磷） |
| 2. | Cₙ | carbon(*cF*8) | diamond（金刚石） |
| 3. | Cₙ | carbon(*hP*4) | graphite（石墨，常见形式） |
| 4. | Cₙ | carbon(*hR*6) | graphite（石墨，较不常见形式） |
| 5. | Feₙ | iron(*cI*2) | α-iron（α-铁） |
| 6. | Feₙ | iron(*cF*4) | γ-iron（γ-铁） |
| 7. | Snₙ | tin(*cF*8) | α- 或 grey tin（灰锡） |
| 8. | Snₙ | tin(*tI*4) | β- 或 white tin（白锡） |
| 9. | Mnₙ | manganese(*cI*58) | α-manganese（α-锰） |
| 10. | Mnₙ | manganese(*cP*20) | β-manganese（β-锰） |
| 11. | Mnₙ | manganese(*cF*4) | γ-manganese（γ-锰） |
| 12. | Mnₙ | manganese(*cI*2) | δ-manganese（δ-锰） |
| 13. | S₈ | sulfur(*oF*128) | α-sulfur（α-硫） |
| 14. | S₈ | sulfur(*mP*48) | β-sulfur（β-硫） |
| 15. | S₈ | sulfur(*mP*32) | γ-sulfur（γ-硫） |

在少数情况下，Pearson 符号不能区分元素的两种晶态同素异形体。遇此情形，将空间群加入括号中。若这仍不能区分各同素异形体，则须引用特征性不同的点阵参数。涉及化合物类型的另一种记法也可能有用（见 IR-4.2.5 节与第 IR-11 章）。

### IR-3.4.5 固态非晶改性体与结构未确定但通常被认可的同素异形体（Solid amorphous modifications and commonly recognized allotropes of indefinite structure）

固态非晶改性体与结构未确定但通常被认可的同素异形体，用语如希腊字母、基于物理性质的名称或矿物名等惯用描述符区分。

**示例：**

|  |  |  |
|---|---|---|
| 1. | Cₙ | vitreous carbon（玻璃碳） |
| 2. | Cₙ | graphitic carbon（石墨碳，即呈石墨形式的碳，不论结构缺陷） |
| 3. | Pₙ | red phosphorus（红磷）［一种无序结构，含部分 phosphorus(*oS*8) 与部分 tetraphosphorus］ |
| 4. | Asₙ | amorphous arsenic（无定形砷） |

## IR-3.5 周期表中的元素（Elements in the periodic table）

周期表中元素的族（见封二）编号为 1 至 18。第 1、2 和 13–18 族的元素（氢除外）称为主族元素，且除第 18 族外，各主族的前两个元素称为典型元素。任选地，可用字母 s、p、d 和 f 区分不同区的元素。例如，第 3–12 族的元素是 d 区元素。这些元素也常被称为过渡元素，尽管第 12 族的元素并非总被包括在内；f 区元素有时被称为内过渡元素。若对特定目的适宜，各族可以其第一个元素命名，例如硼族（boron group）元素（B, Al, Ga, In, Tl）、钛族（titanium group）元素（Ti, Zr, Hf, Rf），*等等*。

下列同类元素的集合名称是 IUPAC 批准的：碱金属（alkali metals）（Li, Na, K, Rb, Cs, Fr）、碱土金属（alkaline earth metals）（Be, Mg, Ca, Sr, Ba, Ra）、氮族元素（pnictogens）⁸（N, P, As, Sb, Bi）、氧族元素（chalcogens）（O, S, Se, Te, Po）、卤素（halogens）（F, Cl, Br, I, At）、稀有气体（noble gases）（He, Ne, Ar, Kr, Xe, Rn）、镧系元素（lanthanoids）（La, Ce, Pr, Nd, Pm, Sm, Eu, Gd, Tb, Dy, Ho, Er, Tm, Yb, Lu）、稀土金属（rare earth metals）（Sc、Y 及镧系元素）以及锕系元素（actinoids）（Ac, Th, Pa, U, Np, Pu, Am, Cm, Bk, Cf, Es, Fm, Md, No, Lr）。

通用术语 pnictide、chalcogenide 和 halogenide（或 halide）常用于命名氮族、氧族和卤素的化合物。

尽管 lanthanoid 意为「似镧」，因而不应包含镧，但镧已因惯用而被包含在内。actinoid 同理。词尾「ide」通常表示负离子，因此 lanthanoid 和 actinoid 优于 lanthanide 和 actinide。
