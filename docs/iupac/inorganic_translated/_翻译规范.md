- 原文的表格转为 markdown 表格，表格标题译为 `**表 IR-5.1 ……**`

## 三、术语处理

1. 术语首次出现用「中文（English）」，此后只用中文。
   例：取代命名法（substitutive nomenclature）、母体氢化物（parent hydride）。
2. **化学名称、化学式、位标、立体描述符一律保留原文**，不译、不改写：
   `hexaaquaaluminium(3+)`、`[CoCl₄]²⁻`、`1,2-`、`R`/`S`、`D`/`L`、`Δ`/`Λ`、
   `κ`、`μ`、`η`、`closo`/`nido`/`arachno` 等。
3. 元素名、常见俗名用通行中文名：hydrogen 氢、sulfur 硫、phosphane 膦、
   silane 硅烷、borane 硼烷、ammonia 氨、water 水、hydron 氢离子等。
4. 化学式中的上下标必须保留：`Fe₃O₄`、`SO₄²⁻`、`η⁵`、`V<sub>M</sub><sup>x</sup>`。

## 四、忠实度要求

- **完整翻译**，不省略、不概括、不合并段落，不添加原文没有的内容。
- 原文的斜体强调用 `*…*`，粗体用 `**…**`，与底稿一致。
- 原文中的插图引用要保留：底稿写作 `![IR-5-p7-fig1.png](images/IR-5-p7-fig1.png)`，
  译文中路径改为 `../inorganic/images/IR-5-p7-fig1.png`（译文在 `inorganic_translated/`，
  图片在 `inorganic/`），并配一行斜体图注说明该图在原书中的性质（结构式 / 流程图 /
  旋转排版的表格整页图 / 带框线的结构式表格图）。
- 数字、页码、参考文献条目照译，参考文献中的人名与刊名保留原文。
- 不确定的译法在译文后加 `（译注：…）` 说明，不要臆造规则。

## 五、写作口吻

- 学术规范中文，陈述句为主，不出现「本文」「我们」。
- 不写工作过程、不写「以下是翻译」之类的话。
- 中文与英文/数字之间不加空格（如 `IUPAC 命名法` 可保留空格，与 cn_translated 一致：
  中英文之间留一个半角空格）。
