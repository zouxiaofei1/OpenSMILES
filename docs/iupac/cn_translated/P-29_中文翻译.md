## P-29.0 引言

本节包含由第 P-21 至 P-28 节所述的母体氢化物衍生的、在取代命名法中用作前缀的取代基团的名称。本节完整描述了形成系统前缀的方法；同时给出了优选的 IUPAC 前缀以及预选前缀。

## P-29.1 定义

由母体氢化物衍生的取代基团在有机化合物命名中有多种用途，可分为简单取代基团、复合取代基团和复杂取代基团。

下面给出的由母体氢化物衍生的取代基团的定义与先前推荐的（见 ref. 1 中的 A-2.3 和 ref. 2 中的 R-4.1）有所不同。

### P-29.1.1 简单取代基团

简单取代基团是一个原子或原子团，作为具有一个或多个自由价的单元来考虑。此类基团的命名方法在 P-29.2 中描述。基本倍增前缀 'di'、'tri'、'tetra' 等表示化合物或复杂取代基团中存在两个以上相同的简单取代基团，但派生倍增前缀（如 'bis'、'tris'、'tetrakis'）的使用见 P-29.1.2 和 P-29.1.3。

### P-29.1.2 复合取代基团

复合取代基团由一个简单取代基团（**母体取代基团**）以及连接在其上的一个或多个简单取代基团组成。复合取代基团名称通过组合两个或多个简单取代基团的名称而形成。有三种实现方式：

(1) 通过取代操作；
(2) 通过加成操作；
(3) 通过取代操作和加成操作相结合。

复合取代基团通过取代操作而非加成操作形成，除非简单母体取代基团不适合取代，即它没有可取代的氢原子。通过取代形成的复合取代基团在名称中以前缀引用，通常称为"取代基前缀"（substituent prefixes）。通过加成形成的复合取代基团在名称中以前缀引用，通常称为"级联前缀"（concatenated prefixes）。派生倍增前缀 'bis'、'tris'、'tetrakis' 等用于倍增复合前缀，并避免基本倍增前缀已成为取代基团名称一部分时产生歧义（见 P-16.3）。

示例：
- `-CH₂` → `chloromethyl`（氯甲基）(preferred prefix)（一个取代前缀；见 P-13.1）
- `-CO-Cl` → `carbonochloridoyl`（碳氯酰基）(preferred prefix)（一个级联前缀；见 P-13.3.4）

混合级联取代基团通过取代操作形成，即将取代基团引入其一个或多个组分中。

示例：
- `(chloroazanediyl)bis(methylene)` (preferred prefix)［(氯氮烷二基)双(亚甲基)］

### P-29.1.3 复杂取代基团

复杂取代基团由一个母体取代基团组成，通过取代或级联在其上连接至少一个复合取代基团。在复杂取代基团中，组分复合取代基团的母体取代基团称为**次级母体取代基团**。用作倍增命名法中心部分的倍增前缀（见 P-15.3.2）通过加成操作形成，当这些前缀由三个或更多部分组成时，被视为"复杂级联前缀"（complex concatenated prefixes）。派生倍增前缀 'bis'、'tris'、'tetrakis' 等用于倍增复杂前缀，并避免基本倍增前缀已成为取代基团名称一部分时产生歧义（见 P-16.3）。

示例：
- `2-bromo-2-(bromomethyl)butyl` (preferred prefix)（一个复杂取代前缀）
- `>N-CH₂-O-CH₂-N<` → `oxybis(methylenenitrilo)` (preferred prefix)（一个复杂级联前缀）

级联和取代可以结合，形成被取代的级联复杂取代基团。

示例：
- `-CHCl-O-CH₂-CH₂-O-CHCl-` → `ethane-1,2-diylbis[oxy(chloromethylene)]` (preferred prefix)

## P-29.2 命名取代基团的一般方法

由母体氢化物失去一个或多个氢原子而形式化地产生的自由价的存在，由后缀 'yl'、'ylidene' 和 'ylidyne' 连同表示自由价数目的倍增前缀表示；最低位次作为一个集合分配给所有自由价，然后按 'yl'、'ylidene'、'ylidyne' 的顺序。在名称中，后缀按 'yl'、'ylidene'、'ylidyne' 的顺序引用。后缀 'ylidene' 和 'ylidyne' 仅分别用于表示取代基通过双键或三键连接到母体氢化物或母体取代基上。

| 一价 | 二价 | 三价 | 四价等 |
|------|------|------|--------|
| -yl | -diyl | -triyl | -tetrayl 等 |
| | -ylidene | -ylidyne | -ylylidyne 等 |
| | -ylylidene | -diylidene 等 | |
| | -diylylidene 等 | | |

系统名称通过使用后缀 'yl'、'ylidene' 和 'ylidyne' 形成，当母体氢化物名称的末尾字母 'e' 存在时省略之，按两种方法：

(1) 后缀 'yl'、'ylidene' 和 'ylidyne' 替换母体氢化物名称的结尾 'ane'。带自由价的原子终止链，并始终具有位次 '1'，其在名称中被省略。此方法主要推荐用于饱和无环和单环烃取代基团，以及硅、锗、锡和铅的单核氢化物。由此方法形成的取代基团称为"烷基型取代基团"（'alkyl-type' substituent groups）；

(2) 后缀 'yl'、'ylidene' 和 'ylidyne' 加在母体氢化物名称之后，当其后紧跟字母 'y' 时省略末尾字母 'e'（如存在）。自由价原子的位次在与母体氢化物任何既定编号一致的情况下尽可能低；除单核母体氢化物或后缀 'ylidyne' 外，必须引用位次 '1'。此方法用于生成"烷烴基型取代基团"（'alkanyl-type' substituent groups）的名称，即在 '1' 位以外位置具有自由价的简单取代基团。

方法 (1) 不再适用于硼前缀。

关于这些方法在生成优选 IUPAC 名称中的应用，见 P-57.1.1.1。

示例：
- `CH₃-` → `methyl`（甲基）(preferred prefix)、`methanyl`
- `SiH₃-` → `silyl`（硅烷基）(preselected prefix)
- `CH₂=` → `methylidene`（亚甲基）(preferred prefix)、`methanylidene`
- `CH₃C≡` → `ethylidyne`（次乙基）(preferred prefix)、`ethanylidyne`
- `trisilan-1-yl` (preselected prefix)
- `propan-2-yl`（丙-2-基）(preferred prefix)、`1-methylethyl`
- `C₆H₁₁-` → `cyclohexyl`（环己基）(preferred prefix)
- `bicyclo[2.2.1]heptan-2-yl`（二环[2.2.1]庚-2-基）(preferred prefix)、`bicyclo[2.2.1]hept-2-yl`
- `spiro[4.4]nonan-2-ylidene`（螺[4.4]壬-2-亚基）(preferred prefix)、`spiro[4.4]non-2-ylidene`

### P-29.3.1 由单核母体氢化物衍生的取代基前缀

由单核母体氢化物（不再包括硼）衍生的取代基前缀传统上按 P-29.2 中的方法 (1) 命名。其他单核母体氢化物，即由 O、F、Cl、Br、I、S、Se、Te、N、P、As、Sb、Bi、B、Al、Ga、In 和 Tl 衍生的，按 P-29.2 中的方法 (2) 命名。前缀 'amino' 保留为 -NH₂ 的预选前缀，前缀 phosphino、arsino 和 stibino 可用于一般命名法。由经 λ-约定修饰的单核母体氢化物衍生的取代基团，对第 15 族元素在 P-68.3.2 中讨论，对第 16 族元素在 P-68.4.3 中讨论，对第 17 族元素在 P-68.5.1 中讨论。

由 borane 衍生的前缀现在仅按 P-29.2 中的方法 (2) 命名，例如 'boranyl'、'boranylidene' 和 'boranylidyne'。

示例：
- `CH₃-` → `methyl`（甲基）(preferred prefix)、`methanyl` [见 P-29.2 (2)]
- `GeH₃-` → `germyl`（锗烷基）(preselected prefix)
- `BH₂-` → `boranyl`（硼烷基）(preselected prefix)（非 boryl）
- `CH₂=` → `methylidene`（亚甲基）(preferred prefix)、`methanylidene` [见 P-29.2 (2)]
- `SnH₂=` → `stannylidene`（锡烷亚基）(preselected prefix)
- `BH=` → `boranylidene`（硼烷亚基）(preselected prefix)（非 borylidene）
- `HS-` → `sulfanyl`（硫烷基）(preselected prefix)（不再是 mercapto）
- `H₂P-` → `phosphanyl`（磷烷基）(preselected prefix)、`phosphino`
- `HAs=` → `arsanylidene`（砷烷亚基）(preselected prefix)（非 arsinidine）
- `H₂Al-` → `alumanyl`（铝烷基）(preselected prefix)
- `HAl=` → `alumanylidene`（铝烷亚基）(preselected prefix)
- `S=` → `sulfanylidene`（硫烷亚基）(preselected prefix)、`thioxo`（硫代）
- `HSi≡` → `silylidyne`（硅烷次基）(preselected prefix)
- `P≡` → `phosphanylidyne`（磷烷次基）(preselected prefix)（非 phosphinidyne）

### P-29.3.2 由无环母体氢化物衍生的取代基前缀

由无环母体氢化物名称衍生的简单取代基团的名称通过 P-29.2 中描述的两种方法形成。

#### P-29.3.2.1

由在最长链末端具有单个自由价的无环烃衍生的简单取代基团的名称传统上按 P-29.2 的方法 (1) 形成。它们通称为 'alkyl'、'alkylidene' 和 'alkylidyne' 取代基团。自由价被赋予位次 1，其在名称中省略。

示例：
- `ethyl`（乙基）(preferred prefix)
- `propyl`（丙基）(preferred prefix)
- `butyl`（丁基）(preferred prefix)
- `propylidene`（亚丙基）(preferred prefix)
- `butylidyne`（次丁基）(preferred prefix)

#### P-29.3.2.2

除 P-29.3.2.1 所述以外的简单取代基团的名称按 P-29.2 的方法 (2) 形成。对于烃基团，这些取代基团通称为 'alkanyl'、'alkanylidene'、'alkanylidyne'、'alkanediyl'、'alkanylylidene' 等取代基团。根据链的编号，最低位次作为一个集合分配给自由价。如果有选择，则按顺序将低位次分配给后缀 'yl'、'ylidene' 和 'ylidyne'。在名称中，后缀按 'yl'、'ylidene' 和 'ylidyne' 的顺序引用。

示例：
- `propan-1-yl`（丙-1-基）、`propyl` (preferred prefix)
- `propan-2-yl`（丙-2-基）(preferred prefix)（非 prop-2-yl）
- `butan-2-yl`（丁-2-基）(preferred prefix)（非 but-2-yl）
- `butanylidyne`、`butylidyne`（次丁基）(preferred prefix)
- `propan-2-ylidene`（丙-2-亚基）(preferred prefix)
- `pentan-3-ylidene`（戊-3-亚基）(preferred prefix)
- `propane-1,3-diyl`（丙烷-1,3-二基）(preferred prefix)（非 trimethylene）
- `ethane-1,1-diyl`（乙烷-1,1-二基）(preferred prefix)（非 ethylidene）
- `butane-1,3-diyl`（丁烷-1,3-二基）(preferred prefix)、`1-methylpropane-1,3-diyl`（1-甲基丙烷-1,3-二基）
- `ethan-1-yl-2-ylidene`（乙烷-1-基-2-亚基）(preferred prefix)
- `propan-1-yl-1-ylidene`（丙烷-1-基-1-亚基）(preferred prefix)
- `butan-3-yl-1-ylidene`（丁烷-3-基-1-亚基）(preferred prefix)
- `butan-2-yl-3-ylidene`（丁烷-2-基-3-亚基）(preferred prefix)
- `AsH₂-AsH-` → `diarsanyl`（联砷烷基）(preselected prefix)
- `SiH₃-SiH₂-` → `disilanyl`（联硅烷基）(preselected prefix)
- `triazan-1-yl`（三氮烷-1-基）(preselected prefix)
- `trisilan-2-yl`（三硅烷-2-基）(preselected prefix)
- `disiloxanyl`（二硅氧烷基）(preselected prefix)
- `SiH₃-NH-SiH₂-` → `(silylamino)silyl`（(硅烷基氨基)硅烷基）(preselected prefix)（非 disilazan-1-yl；disilazane 不是推荐的母体氢化物，见 P-21.2.3.1）
- `(SiH₃)₂N-` → `disilylamino`（二(硅烷基)氨基）(preselected prefix)（非 disilazan-2-yl；disilazane 不是推荐的母体氢化物，见 P-21.2.3.1）
- `bis(silylamino)silyl`（双(硅烷基氨基)硅烷基）(preselected prefix)（非 trisilazan-3-yl；trisilazane 不是推荐的母体氢化物，见 P-21.2.3.1）
- `H₂N-NH-` → `hydrazinyl`（肼基）(preselected prefix)、`diazanyl`（二氮烷基）
- `H₂N-N=` → `hydrazinylidene`（肼亚基）(preselected prefix)、`diazanylidene`（二氮烷亚基）
- `2,5,8,11-tetraoxatetradecan-14-yl`（2,5,8,11-四氧杂十四烷-14-基）(preferred prefix)

### P-29.3.3 由饱和环状母体氢化物衍生的取代基前缀

由环烷烃衍生的一价取代基团的名称传统上按 P-29.2 中的方法 (1) 形成。由饱和环状母体氢化物衍生的所有其他取代基团按 P-29.2 中的方法 (2) 命名。根据母体氢化物的编号，为自由价 'yl'、'ylidene' 和 'ylidyne' 分配最低位次。如果有选择，则按该顺序为后缀分配低位次。后缀按 'yl'、'ylidene' 和 'ylidyne' 的顺序引用。关于优选名称，见 P-57.1.5.1。

示例：
- `cyclohexyl`（环己基）(preferred prefix)、`cyclohexanyl`（环己烷基）
- `cyclopentylidene`（亚环戊基）(preferred prefix)、`cyclopentanylidene`（环戊烷亚基）
- `cyclohexan-1-yl-2-ylidene`（环己烷-1-基-2-亚基）(preferred prefix)
- `cyclopentane-1,3-diyl`（环戊烷-1,3-二基）(preferred prefix)
- `phosphinane-3,5-diyl`（膦杂环己烷-3,5-二基）(preferred prefix)
- `oxolan-3-yl-4-ylidene`（氧杂环戊烷-3-基-4-亚基）(preferred prefix)
- `1-oxacyclododecan-7-yl`（1-氧杂环十二烷-7-基）(preferred prefix)
- `2-thiabicyclo[2.2.2]octan-3-yl`（2-硫杂二环[2.2.2]辛-3-基）(preferred prefix)
- `2-phosphaspiro[4.5]decan-8-yl`（2-磷杂螺[4.5]癸-8-基）(preferred prefix)

### P-29.3.4 由 mancude 母体氢化物衍生的取代基前缀

#### P-29.3.4.1

所有 mancude 环和环系按 P-29.2 中的方法 (2) 命名。当存在一个氢原子时，衍生一价取代基没有困难。当不存在氢原子或需要 'ylidene' 型取代基团时，必须使用"加合指示氢"（added indicated hydrogen）（见 P-14.7）。形式上，此方法涉及将一个氢原子加到衍生取代基团的原子之上，并将另一个氢原子加到环或环系的任何原子上。这个"加合指示氢原子"由符号 H 表示，前面加上表示其位置的位次。

示例：
- `naphthalen-2-yl`（萘-2-基）(preferred prefix)
- `pyridin-2-yl`（吡啶-2-基）(preferred prefix)
- `pyridin-1(4H)-yl`（吡啶-1(4H)-基）(preferred prefix)
- `imidazo[1,2-b][1,2,4]triazin-1(2H)-yl`（咪唑并[1,2-b][1,2,4]三嗪-1(2H)-基）(preferred prefix)
- `azulen-2(1H)-ylidene`（薁-2(1H)-亚基）(preferred prefix)
- `naphthalen-1(2H)-ylidene`（萘-1(2H)-亚基）(preferred prefix)
- `(C₆₀-Iₕ)[5,6]fulleren-1(9H)-yl`（(C₆₀-Iₕ)[5,6]富勒烯-1(9H)-基）(preferred prefix)

#### P-29.3.4.2

由 mancude 化合物通过将两个 H 原子转化为自由价、并对双键进行任何必要的重排成醌型结构而衍生的 'diylidene' 取代基团，通过将两个 'ylidene' 后缀，即 'diylidene'，加到母体氢化物上来命名；无需加合氢。此外，当自由价位于稠合原子上时，形成 'diyl' 取代基团的情况也无需加合氢。

示例：
- `naphthalene-2,3-diylidene`（萘-2,3-二亚基）(preferred prefix)
- `naphthalene-4a,8a-diyl`（萘-4a,8a-二基）(preferred prefix)

当引入自由价不会产生醌型结构时，必须在名称中引用加合氢原子。它们获得尽可能低的位次。当 'yl' 型自由价存在于稠合原子上时，也必须在名称中引用加合氢。

示例：
- `naphthalene-1,3(2H,4H)-diylidene`（萘-1,3(2H,4H)-二亚基）(preferred prefix)
- `naphthalen-4a(2H)-yl`（萘-4a(2H)-基）(preferred prefix)

### P-29.3.5 由环集合体衍生的取代基前缀

由两个相同环或环系组成的环集合体的名称按第 P-28.2 节所述形成，由三个至六个相同环或环系组成的环集合体衍生的名称在 P-28.3 中描述。由六个以上环组成的环集合体或环集合体按 P-28.5 所述的 phane 命名法命名。最低位次分配给环连接点，然后分配给自由价。

由环集合体衍生的取代基团的名称以两种方式书写：

(1) 后缀 'yl' 加到名称 biphenyl 上；
(2) 由位次表示的名称置于方括号中；后缀 'yl' 和 'ylidene' 在省略母体氢化物名称的末尾字母 'e' 后加上。

示例：
- `[1,1′-biphenyl]-4-yl`（[1,1′-联苯]-4-基）(preferred prefix)
- `[1,1′-biphenyl]-2,4′-diyl`（[1,1′-联苯]-2,4′-二基）(preferred prefix)
- `[1,1′-bi(cyclohexan)]-4-yl-4′-ylidene`（[1,1′-联(环己烷)]-4-基-4′-亚基）(preferred prefix)、`[1,1′-bi(cyclohexyl)]-4-yl-4′-ylidene`（[1,1′-联(环己基)]-4-基-4′-亚基）
- `[2,2′-bipyridin]-5-yl`（[2,2′-联吡啶]-5-基）(preferred prefix)、`[2,2′-bipyridyl]-5-yl`（[2,2′-联吡啶基]-5-基）
- `[11,21:23,31-terphenyl]-14,24-diyl`（[11,21:23,31-三联苯]-14,24-二基）(preferred prefix)、`[1,1′:3′,1′′-terphenyl]-4,4′-diyl`（[1,1′:3′,1′′-三联苯]-4,4′-二基）
- `[11,21:24,31-terphenyl]-14,23-diyl`（[11,21:24,31-三联苯]-14,23-二基）(preferred prefix)、`[1,1′:4′,1′′-terphenyl]-3′,4-diyl`（[1,1′:4′,1′′-三联苯]-3′,4-二基）
- `[1,2′-binaphthalene]-1′,5-diyl`（[1,2′-联萘]-1′,5-二基）(preferred prefix)、`[1,2′-binaphthyl]-1′,5-diyl`（[1,2′-联萘基]-1′,5-二基）
- `[1,2′-binaphthalen]-4(1H)-ylidene`（[1,2′-联萘]-4(1H)-亚基）(preferred prefix)、`1,2′-binaphthyl]-4(1H)-ylidene`（1,2′-联萘基]-4(1H)-亚基）

示例：
- `1,3,5,7(2,6)-tetrapyridinacyclooctaphan-2-ylidene`（1,3,5,7(2,6)-四吡啶并环辛番-2-亚基）(preferred prefix)
- `1,3,5,7(2,6)-tetrapyridinacyclooctaphan-14(11H)-ylidene`（1,3,5,7(2,6)-四吡啶并环辛番-14(11H)-亚基）(preferred prefix)

## P-29.4 复合取代基团

### P-29.4.1 复合取代取代基团

复合取代取代基团通过将一个或多个简单取代基取代到被视为主链的另一个简单取代基中而形成。主链的选择在第 P-44.3 节中充分讨论。要应用的首要标准是主链为最长链；在以下无环复合取代基团示例中将应用该标准。

由均链（homogeneous chains）衍生的一价、二价和多价取代基团，通过将侧链的标识加在具有尽可能最长链的无支链取代基团名称之前来命名。当可以选择时，将最低位次分配给侧链。相同简单取代基团的存在由适当的倍增前缀 'di'、'tri'、'tetra' 等表示。

取代基团的名称按 P-29.3 形成。复合取代基团的取代基团必须按第 P-5 章所述的优选 IUPAC 名称或预选名称命名。

示例：
- `1-methylbutyl`（1-甲基丁基）、`pentan-2-yl`（戊-2-基）[preferred prefix，见 P-29.2 (2)]
- `2-methylbutyl`（2-甲基丁基）(preferred prefix)
- `3-silyltetrasilan-1-yl`（3-硅烷基四硅烷-1-基）(preselected prefix)
- `1-methyltetrasilan-1-yl`（1-甲基四硅烷-1-基）(preferred prefix)
- `1-methylethylidene`（1-甲基亚乙基）、`propan-2-ylidene`（丙-2-亚基）(preferred prefix)
- `1,1-dimethylethyl`（1,1-二甲基乙基，已给出编号）、`2-methylpropan-2-yl`（2-甲基丙-2-基）、`tert-butyl`（叔丁基）(preferred prefix，见 P-29.6)
- `2-methylpentan-3-yl`（2-甲基戊-3-基）(preferred prefix)（非 4-methylpentan-3-yl；位次 '2' 低于 '4'）
- `1-methylbutane-1,4-diyl`（1-甲基丁烷-1,4-二基）、`pentane-1,4-diyl`（戊烷-1,4-二基）(preferred prefix)
- `2-ethylethane-1,1,2-triyl`（2-乙基乙烷-1,1,2-三基）、`butane-1,1,2-triyl`（丁烷-1,1,2-三基）(preferred prefix)
- `2-methylcyclopentyl`（2-甲基环戊基）(preferred prefix)
- `2,6-di(butan-2-yl)cyclohexyl`（2,6-二(丁-2-基)环己基）(preferred prefix)
- `7-methylnaphthalen-2-yl`（7-甲基萘-2-基）(preferred prefix)
- `6-disiloxanylpyridin-2-yl`（6-二硅氧烷基吡啶-2-基）(preferred prefix)

### P-29.4.2 复合级联取代基团

复合级联取代基团仅用于倍增命名法（见 P-15.3）。名称通过将二价或多价取代基团彼此相加形成，具体而言，按倍增命名法的规定（见 P-15.3），将外围取代基团的名称加到中心取代基团的名称上。当整个取代基团的对称性得以保持时，允许对组分进行取代。

示例：
- `silanediyldi(ethane-2,1-diyl)`（硅烷二基二(乙烷-2,1-二基)）(preferred prefix)、`silanediyldiethylene`
- `methylenebis(disilane-2,1-diyl)`（亚甲基双(二硅烷-2,1-二基)）(preferred prefix)
- `1,4-phenylenebis(methylene)`（1,4-亚苯基双(亚甲基)）(preferred prefix；1,4-phenylene 和 methylene 是优选的保留 IUPAC 前缀，见 P-29.6.1)
- `cyclohexane-1,4-diylbis(sulfanediyl)`（环己烷-1,4-二基双(硫烷二基)）(preferred prefix)、`cyclohexane-1,4-diylbis(thio)`（环己烷-1,4-二基双(硫代)）
- `silanediylbis(1-fluoroethane-2,1-diyl)`（硅烷二基双(1-氟乙烷-2,1-二基)）(preferred prefix)［非 silanediylbis(1-fluoroethylene)］

## P-29.5 复杂取代基团

### P-29.5.1 复杂取代取代基团

复杂取代取代基团通过根据链、环和环系的优先顺序（P-44），将无环复合取代取代基团取代到无环取代基团或环状取代基团中而形成。

示例：
- `6-(3-methylbutyl)undecyl`（6-(3-甲基丁基)十一烷基）(preferred prefix)
- `2-(germylmethyl)cyclohexyl`（2-(锗烷基甲基)环己基）(preferred prefix)

### P-29.5.2 级联复杂取代基团

级联取代基团在由三个或更多组分组成时是复杂取代基团。只要保持基团的对称性，就允许取代。

示例：
- `-O-CH₂-S-CH₂-O-` → `sulfanediylbis(methyleneoxy)`（硫烷二基双(亚甲氧基)）(preferred prefix)
- `(methylphosphanediyl)bis(oxyethane-2,1-diyl)`（(甲基磷烷二基)双(氧杂乙烷-2,1-二基)）(preferred prefix)

## P-29.6 由第 P-2 章所述母体氢化物衍生的简单取代基团前缀的保留名

本节讨论具有保留名的简单取代基团在命名中使用的三个方面：

- **P-29.6.1** — 作为优选前缀的保留前缀；
- **P-29.6.2** — 不作为优选前缀使用的保留前缀；
- **P-29.6.3** — 不再推荐作为批准前缀的保留前缀。

### P-29.6.1 作为优选前缀的保留前缀

传统前缀 benzyl、benzylidene、benzylidyne 是保留的优选前缀，但不可被取代；然而，见 P-29.6.2。

在 1993 版指南（ref. 2）中，名称 'benzyl'、'benzylidene' 和 'benzylidyne' 只能在环上被取代。然而，在这些建议中，对于优选前缀，不允许在环上或侧链上进行取代，但对于一般命名法，允许受限的取代（见 P-29.6.2）。

示例：
- `2-benzylpyridine` (PIN)（2-苄基吡啶）
- `2-(phenylmethyl)pyridine`（2-(苯基甲基)吡啶）
- `2-(4-bromobenzyl)pyridine`（2-(4-溴苄基)吡啶）
- `2-[(4-bromophenyl)methyl]pyridine` (PIN)（2-[(4-溴苯基)甲基]吡啶）

保留名 'tert-butyl' 从未被推荐用于进一步取代；这些建议中维持了这一做法。从未为此名称采用过可接受的位次。名称 'methanediyl' 和 'benzene-1,2-diyl' 不推荐分别代替 'methylene' 和 '1,2-phenylene'。名称 'trimethylene'、'tetramethylene' 等不推荐使用。

示例：
- `tert-butyldi(methyl)phosphane` (PIN)（叔丁基二(甲基)膦）
- `(1,1-dimethylethyl)di(methyl)phosphane`（(1,1-二甲基乙基)二(甲基)膦）
- `(1-chloro-2-methylpropan-2-yl)silane` (PIN)（(1-氯-2-甲基丙-2-基)硅烷）
- `(2-chloro-1,1-dimethylethyl)silane`（(2-氯-1,1-二甲基乙基)硅烷）

保留前缀 'methylene'、'phenyl' 和 '1,2-、1,3- 和 1,4-phenylene' 已被用作完全可取代的取代基团；这些建议中对简单、复合和复杂取代基团维持了这一做法。

示例：
- `-CHBr-` → `bromomethylene`（溴亚甲基）(preferred prefix)
- `4-methylphenyl`（4-甲基苯基）(preferred prefix)
- `2,6-dimethyl-1,4-phenylene`（2,6-二甲基-1,4-亚苯基）(preferred prefix)

### P-29.6.2 不作为优选前缀使用的保留前缀

#### P-29.6.2.1

前缀 benzyl、benzylidene 和 benzylidyne 在未被取代时是优选前缀。然而，这些前缀可在一般命名法中按如下方式被取代时使用：

(1) 无限的环上取代；
(2) 在 α-位上被作为强制取代基的特征原子或基团（见表 5.1）或不延伸链的取代基团取代。

示例：
- `bromo(4-methylphenyl)methyl`（溴(4-甲基苯基)甲基）(preferred prefix)、`α-bromo-4-methylbenzyl`（α-溴-4-甲基苄基）
- `1-(4-methylphenyl)propyl`（1-(4-甲基苯基)丙基）(preferred prefix)（非 α-ethyl-4-methylbenzyl）
- `α,4-dicarboxybenzylidene`（α,4-二羧基苄亚基）、`carboxy(4-carboxyphenyl)methylidene`（羧基(4-羧基苯基)亚甲基）(preferred prefix)
- `3,4,5-trimethylbenzylidyne`（3,4,5-三甲基苄次基）、`(3,4,5-trimethylphenyl)methylidyne`（(3,4,5-三甲基苯基)次甲基）(preferred prefix)

#### P-29.6.2.2

前缀 isopropyl、isopropylidene 和 trityl 保留用于一般命名法，但不允许任何形式的取代。

示例：
- `1,3-dibromo-2-(bromomethyl)propan-2-yl`（1,3-二溴-2-(溴甲基)丙-2-基）(preferred prefix)、`2-bromo-1,1-bis(bromomethyl)ethyl`（2-溴-1,1-双(溴甲基)乙基）
- `1-hydroxypropan-2-ylidene`（1-羟基丙-2-亚基）(preferred prefix)、`2-hydroxy-1-methylethylidene`（2-羟基-1-甲基亚乙基）
- `propan-2-ylidene`（丙-2-亚基）(preferred prefix)、`1-methylethylidene`（1-甲基亚乙基）、`isopropylidene`（亚异丙基，不允许取代）
- `(C₆H₅)₃C-` → `trityl`（三苯甲基，不允许取代）、`triphenylmethyl`（三苯基甲基）(preferred prefix)
- `(4-methylphenyl)di(phenyl)methyl`（(4-甲基苯基)二(苯基)甲基）(preferred prefix)

#### P-29.6.2.3

前缀 ethylene 以及下列环取代基的传统前缀被保留，但仅用于一般命名法，且完全可取代。

示例：
- `-CH₂-CH₂-` → `ethylene`（亚乙基）、`ethane-1,2-diyl`（乙烷-1,2-二基）(preferred prefix)
- `-CHCl-CHCl-` → `1,2-dichloroethylene`（1,2-二氯亚乙基）、`1,2-dichloroethane-1,2-diyl`（1,2-二氯乙烷-1,2-二基）(preferred prefix)
- `2-adamantyl`（2-金刚烷基，也有 1-异构体）、`adamantan-2-yl`（金刚烷-2-基）(preferred prefix)、`tricyclo[3.3.1.1³,⁷]decan-2-yl`（三环[3.3.1.1³,⁷]癸-2-基）
- `2-anthryl`（2-蒽基，也有 1- 和 9-异构体）、`anthracen-2-yl`（蒽-2-基）(preferred prefix)
- `3-furyl`（3-呋喃基，也有 2-异构体）、`furan-3-yl`（呋喃-3-基，也有 2-异构体；preferred prefixes）
- `7-isoquinolyl`（7-异喹啉基，也有 1-、3-、4-、5-、6- 和 8-异构体）、`isoquinolin-7-yl`（异喹啉-7-基，也有 1-、3-、4-、5-、6- 和 8-异构体；preferred prefixes）
- `2-naphthyl`（2-萘基，也有 1-异构体）、`naphthalen-2-yl`（萘-2-基，也有 1-异构体；preferred prefixes）
- `9-phenanthryl`（9-菲基，也有 1-、2-、3- 和 4-异构体）、`phenanthren-9-yl`（菲-9-基，也有 1-、2-、3- 和 4-异构体；preferred prefixes）
- `2-piperidyl`（2-哌啶基，也有 1-、3- 和 4-异构体）、`piperidin-2-yl`（哌啶-2-基，也有 1-、3- 和 4-异构体；preferred prefixes）
- `2-pyridyl`（2-吡啶基，也有 3- 和 4-异构体）、`pyridin-2-yl`（吡啶-2-基，也有 3- 和 4-异构体；preferred prefixes）
- `2-quinolyl`（2-喹啉基，也有 3-、4-、5-、6-、7- 和 8-异构体）、`quinolin-2-yl`（喹啉-2-基，也有 3-、4-、5-、6-、7- 和 8-异构体；preferred prefixes）
- `2-thienyl`（2-噻吩基，也有 3-异构体）、`thiophen-2-yl`（噻吩-2-基，也有 3-异构体；preferred prefixes）
- `o-tolyl`（邻甲苯基，也有 m- 和 p-异构体；不允许取代）、`2-methylphenyl`（2-甲基苯基，也有 3- 和 4-异构体；preferred prefixes）

### P-29.6.3 不再推荐作为批准前缀的保留前缀

平凡名、通用名和传统前缀一直是有机命名法不可分割的一部分。然而，随着系统命名法的发展并被广泛使用，其中许多前缀被弃用。相应地，每一套 IUPAC 建议都包含更少的这些传统前缀。这些建议也不例外。以下前缀仍包含在 1993 版建议（ref. 2）中，但在这些建议中**不推荐**使用；基于这些建议的系统前缀被给出为"优选前缀"。

示例：
- `C₆H₅-CH₂-CH₂-` → `2-phenylethyl`（2-苯基乙基）(preferred prefix)（非 phenethyl）
- `(C₆H₅)₂CH-` → `diphenylmethyl`（二苯基甲基）(preferred prefix)（非 benzhydryl）
- `(CH₃)₂CH-CH₂-` → `2-methylpropyl`（2-甲基丙基）(preferred prefix)（非 isobutyl）
- `CH₃-CH₂-CH(CH₃)-` → `butan-2-yl`（丁-2-基）(preferred prefix)、`1-methylpropyl`（1-甲基丙基）（非 sec-butyl）
- `(CH₃)₂CH-CH₂-CH₂-` → `3-methylbutyl`（3-甲基丁基）(preferred prefix)（非 isopentyl）
- `CH₃-CH₂-C(CH₃)₂-` → `2-methylbutan-2-yl`（2-甲基丁-2-基）(preferred prefix)、`1,1-dimethylpropyl`（1,1-二甲基丙基）（非 tert-pentyl）
- `(CH₃)₃C-CH₂-` → `2,2-dimethylpropyl`（2,2-二甲基丙基）(preferred prefix)（非 neopentyl）
- `(furan-2-yl)methyl`（(呋喃-2-基)甲基）(preferred prefix)［非 furfuryl（仅 2-异构体）］
- `(thiophen-2-yl)methyl`（(噻吩-2-基)甲基）(preferred prefix)、`2-thienylmethyl`（2-噻吩基甲基）［非 thenyl（仅 2-异构体）］
