## P-15.0 引言

在化学中，'命名法'（nomenclature）是这样一种体系：依据一组原理、规则和约定，通过多种命名操作来构造名称。从根本上讲，命名法有两种类型：（1）**取代命名**（substitutive nomenclature），这是有机化学中使用的主要命名法，也是 IUPAC 优选有机名称的基础；（2）**加合命名**（additive nomenclature），用于无机化学中生成配位名称。这两种类型被用于命名有机化合物和无机化合物，从而使命名成为在这两者之间进行选择的问题。例如，SiCl₄ 可命名为 `silicon tetrachloride`（四氯化硅，二元名称）、`tetrachloridosilicon`（四氯合硅，配位名称）和 `tetrachlorosilane`（四氯硅烷，取代名称）。虽然配位命名不在本建议的讨论范围内，但它用于第 1 族和第 2 族有机金属化合物的命名，例如 `dimethylmagnesium`（二甲基镁）。二元名称用于由阴离子或阳离子有机部分组成的盐，例如 `sodium acetate`（乙酸钠）和 `methanaminium chloride`（氯化甲铵）。当在有机化合物命名的范围内存在选择时，推荐使用优选 IUPAC 名称，例如在两个取代名称之间选择（`acetic acid` 和 `ethanoic acid`）、在倍增名称和取代名称之间选择（`2,2′-oxydiacetic acid` 和 `[(carboxymethyl)oxy]acetic acid`）、或在取代名称和官能类名称之间选择（`bromomethane` 和 `methyl bromide`），但不在配位名称或二元名称与有机名称之间选择，例如当选择可能发生在取代名称和配位名称之间时（`tetrachlorosilane` 和 `tetrachloridosilicon`）。

有机化合物的命名法被视为基于 P-13 所述的各种操作的一组不同类型的命名法。术语"命名法"通常与不止一种操作相关。取代命名可被视为基于取代、加合和消去操作。官能类命名基本上基于加合操作，但包括由取代命名形成的取代基名称。倍增命名是取代命名的子集，基于环状母体氢化物（官能化与否）、官能化开链母体氢化物和杂开链母体氢化物。骨架置换命名通常指用 'a' 词进行置换，因此常简称为 'a' 命名。类似地，缀合命名局限于涉及环或环系的缀合操作，这些环或环系被带有主基团的链所取代，主基团以取代方式命名或具有保留名。最后，官能置换命名定义了使用前缀和中缀来表示将氧原子或含氧基团置换为氮原子、含氮基团、硫族原子、卤素原子、过氧基团等的规则（见 P-15.5）。

因此，术语"命名法"通常不仅与单一类型的操作相关，命名系统内的名称形成由一系列不同类型的操作组成，例如在形成双键时的消去操作，以及在将氧原子置换为硫族原子或氮原子时的官能置换操作。

术语"命名法"也适用于化合物的族或类，例如"自由基和离子的命名"、"Phane 命名"（用于命名由链和/或环系组成的化合物）以及"富勒烯命名"（用于描述命名多环碳笼化合物及其衍生物所必需的所有操作）。该术语还用于描述天然来源的化合物族，例如"天然产物命名"基于立体母体（stereoparent）的概念。碳水化合物、α-氨基酸、肽、脂质以及其他一些具有生化意义的化合物的命名通常被视为"生化命名"（Biochemical Nomenclature），因此另行全面出版。

## P-15.1 取代命名

取代命名基于选择具有可取代氢原子的母体结构（见 P-15.1.5），这些氢原子被具有命名学意义的结构片段取代，这些片段以前缀和/或后缀表示，或仅以前缀表示。在取代命名中有三种母体结构：母体氢化物、官能化母体氢化物和官能母体化合物。

### P-15.1.1 母体氢化物

母体氢化物是无支链开链结构、环状结构或开链/环状结构，只连接氢原子。它们可以具有如第 P-2 章和第 P-3 章所述的保留名、天然产物的半系统名（见 P-101），或由第 P-2 章和第 P-3 章所述的系统方法衍生的名称。

示例：
- `methane` (PIN；保留名，P-21.1.1.1) — 甲烷
- `cyclohexane` (PIN；P-22.1.1) — 环己烷
- `styrene` (保留名，P-31.1.3.4) — 苯乙烯；`ethenylbenzene` (PIN) — 乙烯基苯
- `pyridine` (保留名，PIN；P-22.2.1) — 吡啶
- `cholestane` (保留名，表 10.1，b) — 胆甾烷

母体氢化物可以被前缀和/或后缀取代。完整的取代名称可以用图 1.1 示意性地描述。

### P-15.1.2 官能母体化合物

#### P-15.1.2.1

用于系统有机命名的官能母体化合物是具有保留名的结构，这些保留名暗示至少存在一个特征基团，并且其至少一个骨架原子上连接有一个或多个氢原子，或者其至少一个特征基团可以形成至少一种官能修饰。这些官能母体化合物的修饰是有限的，只能添加可分离前缀和累积后缀。此外，优选的 IUPAC 官能母体化合物名称不能通过使用 hydro/dehydro 前缀改变氢化程度、不能通过将词尾 'ane' 改为 'ene' 或 'yne'、也不能通过不可分离前缀（如 'cyclo'）修改结构。

示例：
- `acetic acid` (PIN；P-65.1.1) — 乙酸
- `aniline` (PIN；P-62.2.1.1.1) — 苯胺
- `phosphonic acid` (预选名；P-67.1.1) — 膦酸

#### P-15.1.2.2

第二组官能母体化合物广泛用于天然产物命名，其中不可分离前缀（如 'cyclo'、'nor'、'homo'）、hydro/dehydro 前缀以及词尾 'ene'、'yne' 等按第 P-10 章规定使用。

示例：
- `D-glucose` (表 10.2) — D-葡萄糖
- `alanine` (表 10.4) — 丙氨酸

基于官能母体化合物的完整优选 IUPAC 取代名称可以如图 1.2 所示示意性地描述。

**图 1.2** 基于官能母体化合物的取代名称中各组成部分的顺序

```

```

#### P-15.1.2.3

官能化母体氢化物是被特征基团后缀取代的母体氢化物，例如 `ethanamine`（乙胺，见 P-62.2.1.2）和 `cyclohexanol`（环己醇，见 P-63.1.2），不应与官能母体化合物混淆。

### P-15.1.3 后缀（另见 P-33）

一般来说，有两种后缀：**官能后缀**（functional suffixes）和**累积后缀**（cumulative suffixes）。

（1）官能后缀通常是用于描述表示类别的特征基团的简单后缀。例如，酮类、酸类、胺类和酯类分别由后缀 -one、-carboxylic acid、-amine 和 -carboxylate 表示。官能后缀是排他性后缀，因为一个表示主特征基团的后缀的存在，排除所有其他描述其他特征基团的后缀，这些其他特征基团必须表示为前缀。

（2）累积后缀用于表示自由基、离子、自由基离子及相关物种，例如 -yl、-ium、-ide，以及取代基。累积后缀不是排他性的。它们可以相互组合，也可以与官能后缀组合，例如 -aminyl、-nitrilium、-sulfaniumyl。

示例：

| 结构 | 名称 | 说明 |
|------|------|------|
| `CH4` | `methane` (PIN) | 母体氢化物 |
| `CH4•+` | `methaniumyl` (PIN) | 'iumyl' 是累积后缀 |
| `CH3-CH3` | `ethane` (PIN) | 母体氢化物 |
| `CH3-CH2-NH2` | `ethanamine` (PIN) | 'amine' 是官能后缀 |
| `CH3-CH2-NH3+` | `ethanaminium` (PIN) | 'ium' 是累积后缀 |

### P-15.1.4 词尾 'ane'、'ene' 和 'yne' 的位置

在开链、环状和多环母体氢化物中将词尾 'ane' 改为 'ene' 或 'yne'，用于描述将双键和三键插入饱和母体氢化物的消去操作。这些词尾是累积性的，可以与官能后缀组合。

### P-15.1.5 前缀及其在名称中的顺序

有两种前缀：**不可分离前缀**（nondetachable prefixes）和**可分离前缀**（detachable prefixes）。不可分离前缀描述对母体结构产生新母体结构的结构修饰，例如置换前缀，其可以是骨架置换（'a'）前缀（见 P-15.4）或'官能置换前缀'（见 P-15.5）。可分离前缀有两种类型：描述饱和或不饱和的前缀（'hydro' 和 'dehydro'）；以及描述取代的前缀，也称为**可按字母排序前缀**（alphabetizable prefixes）。

#### P-15.1.5.1 不可分离前缀

不可分离前缀以给定的顺序永久连接到母体结构的名称上，该顺序通常与用于修饰母体结构的操作顺序相匹配。描述第一次操作的前缀直接连接到母体结构的名称上；第二次操作产生的前缀放在已引入的前缀之前，依此类推（这种技术可称为从母体结构名称'向后推进'）。每一类别的顺序都精确规定，如下所示：

##### P-15.1.5.1.1 产生新母体结构的不可分离前缀

(a) 脂环和环系，通过诸如 'cyclo'、'bicyclo'、'tricyclo' 等前缀；'spiro'、'dispiro' 等前缀；
(b) 稠环系，通过稠合前缀：'benzo'、'naphtho'、'imidazo' 等；
(c) 桥稠环系，通过添加桥前缀：'methano'、'epoxy' 等；
(d) 螺环化合物，通过组合（a）、（b）和/或（c）中环状化合物的名称形成。

##### P-15.1.5.1.2 氢以外的原子被其他原子置换

这种类型的置换称为'骨架置换'，本质上是用杂原子置换碳原子；它发生在开链和环状烃中，通过使用骨架置换（'a'）前缀（即 'oxa'、'aza'、'thia' 等）产生新的母体结构。

##### P-15.1.5.1.3 指示氢

指示氢（见 P-14.7）也是一种不可分离前缀，被放在所有其他不可分离前缀之前。

#### P-15.1.5.2 可分离 hydro/dehydro 前缀

这两个前缀通过加成或消去操作引入名称中；因此，它们不属于描述取代的可分离可按字母排序前缀（P-15.1.5.3）类别。在名称中，它们占据不可分离前缀和可分离可按字母排序前缀之间的位置。这些前缀表示对具有最大数量非累积双键（mancude 结构）的环或环系的氢化程度的修饰，并按编号处理，类似于实现相同功能的词尾 'ene' 和 'yne'。在名称中，当 'dehydro' 和 'hydro' 同时存在时，前缀 'dehydro' 位于 'hydro' 之前。简单的数字词，如 'di-'、'tri-'、'tetra-' 等，与 'hydro' 和 'dehydro' 一起使用。

#### P-15.1.5.3 可分离可按字母排序前缀

这些前缀描述表示不作为主特征基团引用的取代基，这些特征基团衍生自母体氢化物，并在 'hydro-dehydro' 前缀（如果存在，见 P-31.2）或不可分离前缀（如果存在）之前引用，如图 1.1 所示。它们按照 P-14.5 按字母顺序排列。

### P-15.1.6 取代名称的其他组成部分

除上述组成部分外，根据需要添加以下命名指示符：

#### P-15.1.6.1 倍增前缀

倍增前缀置于后缀和前缀之前，表示多次出现。

#### P-15.1.6.2 位次

位次用于表示后缀、前缀和词尾所表示的修饰在母体结构上发生的位置。

#### P-15.1.6.3 立体描述符

立体描述符置于完整名称或其所适用的名称片段的前面（见第 P-9 章）。

### P-15.1.7 取代名称的构建

本小节描述取代名称的形成，以及四组通用规则的运用，这些规则涉及编号（P-14.4）、位次（P-14.3）、倍增前缀（P-14.2）和字母数字顺序（P-14.5）。这四组规则用于构建大多数有机化合物的名称。第一组示例使用烷烃和支链烷烃。第二组中，编号的通用规则通过用后缀表示的饱和和不饱和开链化合物来举例说明。名称构建的全部问题在 P-45 中讨论。

#### P-15.1.7.1 烷烃和支链烷烃的命名

##### P-15.1.7.1.1

烷烃的名称要么是保留名 methane、ethane、propane 和 butane；要么是通过将词尾 'ane' 加到基本倍增前缀上系统形成的名称，同时省略倍增词的末尾字母 'a'（见第 P-2 章）。

示例：
- `CH4` → `methane` (PIN) — 甲烷
- `CH3-CH3` → `ethane` (PIN) — 乙烷
- `CH3-CH2-CH3` → `propane` (PIN) — 丙烷
- `CH3-CH2-CH2-CH3` → `butane` (PIN) — 丁烷
- `CH3-CH2-CH2-CH2-CH3` → `pentane` (PIN) — 戊烷
- `CH3-[CH2]8-CH3` → `decane` (PIN) — 癸烷

##### P-15.1.7.1.2

通过从端位碳原子（消去操作）去除一个氢原子而衍生自无支链开链烃（烷烃）的一价简单取代基，其名称通过将烃名称的词尾 'ane' 改为 'yl' 来命名（见 P-29.3.2.1）；或者，如果从链的非端位碳原子去除一个氢原子，则将烃名称的末尾字母 'e' 改为 'yl'（见 P-29.3.2.2）（'yl' 是累积后缀，见图 1.1，P-15.1.1）。

示例：
- `CH3-CH2-CH2-CH2-` → `butyl` (优选前缀) — 丁基
- `CH3-CH2-CH2-CH2-CH2-` → `pentyl` (优选前缀) — 戊基
- `butan-2-yl` (优选前缀) — 丁-2-基

##### P-15.1.7.1.3

通过将一个或多个取代基（按 P-15.1.7.1.2 所述形成）引入结构中存在的最长链（取代操作），形成饱和支链开链烃；其名称通过将侧链的命名（按 P-15.1.7.1.2 形成）加在最长链名称之前（编号见 P-15.1.7.1.4）。

示例：
- `3-methylpentane` (PIN) — 3-甲基戊烷

##### P-15.1.7.1.4

最长链用阿拉伯数字从一端到另一端编号，方向的选择使取代基（侧链）得到较低位次 [见 P-14.4 (f)]。较低位次集合定义为：与其他按数值递增顺序引用的位次集合逐项比较时，在第一个差异点具有较低项的那个集合（见 P-14.3.5）。位次紧置于其所指的名称部分之前。相同的简单取代基用倍增前缀表示，如 'di'、'tri' 等 [P-16.3.3 (b)]。对于复合或复杂取代基（见 P-29.4 和 P-29.5），使用倍增前缀 'bis'、'tris'、'tetrakis-' 等（P-14.2.2），如 P-16.3.5 (a) 所述。

示例：
- `2-methylpentane` (PIN) — 2-甲基戊烷（附：错误编号/正确编号）
- `2,3,5-trimethylhexane` (PIN) — 2,3,5-三甲基己烷（不是 2,4,5-trimethylhexane；位次集合 2,3,5 低于 2,4,5）

##### P-15.1.7.1.5

如果存在两个或多个不同的取代基，它们在名称中按字母数字顺序引用（见 P-14.5）。当两个或多个取代基占据等价位置时，被分配较低位次的是在名称中最先引用的那个。

示例：
- `4-ethyl-2-methylhexane` (PIN) — 4-乙基-2-甲基己烷（不是 3-ethyl-5-methylhexane；位次集合 2,4 低于 3,5）
- `3-ethyl-5-methylheptane` (PIN) — 3-乙基-5-甲基庚烷（不是 5-ethyl-3-methylheptane；较低位次必须分配给最先引用的取代基）

#### P-15.1.7.2 编号规则

以下示例说明了 P-14.4 中描述的编号规则。该规则为尽可能分配最低位次而在不同命名特征之间建立了优先顺序。

##### P-15.1.7.2.1

醇的名称通过将后缀 'ol' 附加到母体氢化物的名称上来命名，如有必要省略母体氢化物末尾的字母 'e'。当特征基团在结构中单独存在时，必须给予尽可能低的位置位次，紧置于后缀之前引用（见 P-14.3.2）。

示例：
- `propan-1-ol` (PIN) — 丙-1-醇

##### P-15.1.7.2.2

烯烃是具有一个双键的开链支链或无支链烃。当存在一个双键时，无支链烯烃的名称通过将具有相同碳原子数的烷烃名称中的词尾 'ane' 改为 'ene' 来命名（见 P-31.1）。双键被分配尽可能低的位次，紧置于词尾 'ene' 之前（见 P-14.3.2）。

示例：
- `but-1-ene` (PIN) — 丁-1-烯

##### P-15.1.7.2.3

当结构中存在几个命名特征时，按 P-14.4 分配最低位次。例如，在具有一个取代基的不饱和醇中，按以下顺序分配最低位次：
(a) 作为后缀引用的特征基团（-ol）；
(b) 不饱和度（例如 'ene' 词尾）；
(c) 可分离的按字母排序前缀（例如甲基）。

以下示例说明此规则的运用：
- `but-3-en-1-ol` (PIN) — 丁-3-烯-1-醇
- `3-methylbut-1-ene` (PIN) — 3-甲基丁-1-烯
- `6-methylhept-2-en-4-ol` (PIN) — 6-甲基庚-2-烯-4-醇（不是 2-methylhept-5-en-4-ol）

### P-15.1.8 具有保留名的母体结构的取代规则

以下规则描述了在 P-22.1.2、P-22.1.3、表 2.2、2.3、2.7、2.8、表 3.1、3.2 中出现的具有保留名的母体结构，以及 P-34 中给出的官能母体化合物的可取代性。这些规则不适用于天然产物命名中使用的官能母体化合物（见第 P-10 章），那里适用特定规则。

#### P-15.1.8.1 类型 1：不受限制的取代

由以后缀或前缀引用的取代基进行不受限制的取代；这主要适用于母体氢化物。

#### P-15.1.8.2 类型 2：受限制的取代

受限制的取代，概括如下：
- **类型 2a** — 取代仅限于根据官能母体化合物名称中明确表达或暗示的官能团的优先顺序，以前缀引用的取代基；
- **类型 2b** — 取代仅限于强制前缀（compulsory prefixes，见表 5.1）；
- **类型 2c** — 类型 2a 或 2b 未涵盖的母体结构的取代。

#### P-15.1.8.3 类型 3：不允许取代

不允许任何种类的取代。

#### P-15.1.8.1 类型 1 保留名的取代规则

第 P-2 章和第 P-3 章所述母体氢化物的类型 1 保留名，可被以后缀或前缀引用的取代基不受限制地取代。

示例：
- `2-fluoro-3-nitrobutanedioic acid` (PIN)（butane 是保留名）
- `5-aminoazulen-2-ol` (PIN；azulene 是保留名)（不是 2-hydroxyazulen-5-amine）
- `indane-1,2,3-trione`
- `1H-indene-1,2,3-trione` (PIN)

#### P-15.1.8.2 类型 2 保留名的取代规则

具有保留名的母体氢化物和官能母体化合物，其保留名明确或暗示地表达通常以后缀（如 '-one'）或官能类（如 'ether' 醚）表示的特征基团的存在，其取代以下列小节描述的不同方式受到限制。用作官能母体和母体结构的无机含氧酸的取代规则在 P-67 中描述。

##### P-15.1.8.2.1 类型 2a 保留名的取代规则

类型 2a 保留名包括名称表达或暗示以系统名称中的后缀表示的特征基团的官能母体化合物。

###### P-15.1.8.2.1.1

允许以表示为前缀的取代基进行取代，这些取代基具有比后缀所表示的优先顺序更低的优先级。

示例：
- `H2N-CH2-CO-CH3` → `aminoacetone`；`1-aminopropan-2-one` (PIN)
- `HS-CH2-COOH` → `sulfanylacetic acid` (PIN)

明确或暗示存在的后缀不能表示为前缀；

示例：
- `HOOC-CH2-COOH` → `propanedioic acid` (PIN)；`malonic acid`（不是 2-carboxyacetic acid）
- `benzene-1,2-dicarboxylic acid` (PIN)；`phthalic acid`（不是 2-carboxybenzoic acid）
- `benzene-1,2,4-tricarboxylic acid` (PIN)（不是 2,4-dicarboxybenzoic acid；不是 4-carboxyphthalic acid）

###### P-15.1.8.2.1.2

优先特征基团或官能类名称必须在名称中表达。

示例：
- `2-hydroxybenzoic acid` (PIN)（不是 2-carboxyphenol）
- `phenylnitrous amide` (PIN)；`N-nitrosoaniline`

##### P-15.1.8.2.2 类型 2b 保留名的取代规则

类型 2b 保留名包括明确或暗示地没有后缀的母体化合物；`acetylene`（乙炔，PIN）和 `allene`（丙二烯）是例子。这些母体化合物的取代只能使用专门指定的前缀。以下列出的特征基团可用于取代类型 2b 的母体结构（环和如有需要的侧链）：卤化物 -Br、-Cl、-F、-I；拟卤化物 -N₃、-NCO（以及硫族类似物）、-NC；衍生自卤素含氧酸的取代基 -ClO、-ClO₂、-ClO₃（Cl 被 Br 或 I 取代的基团类似）；-NO₂ 和 -NO；以及 -OR（R = 烷基）及其硫族类似物；以及 -SO-R 和 -SO₂-R 及其 Se 和 Te 类似物（见表 5.1）。

示例：
- `Br-C≡C-H` → `bromoacetylene`；`bromoethyne` (PIN)
- `1,3-dichloroallene`；`1,3-dichloropropa-1,2-diene` (PIN)

##### P-15.1.8.2.3 类型 2c 保留名的取代规则

类型 2c 保留名是不包括在类型 2b 中的官能母体化合物，例如 `hydroxylamine`（羟胺，见 P-68.3.1.1.1）、`formic acid`（甲酸，见 P-65.1.8）和 `anisole`（苯甲醚，见 P-34.1.1.4）。

示例：
- `H2N-O-CH3` → `O-methylhydroxylamine` (PIN) [不是 methoxyamine（见 P-68.3.1.1.1.2）]
- `HS-CO-OH` → `carbonothioic S-acid` (PIN) [不是 sulfanylformic acid（见 P-65.1.8.1）]

#### P-15.1.8.3 类型 3 保留名的取代规则

对于类型 3 的母体氢化物和官能母体化合物的保留名，不允许任何种类的取代。然而，允许特征基团的官能化，例如形成酯、酸酐和盐。

示例：
- `Cl-CH2-CH2-COOH` → `3-chloropropanoic acid` (PIN)（不是 3-chloropropionic acid）
- `CH3-CH2-CO-O-CH2-CH3` → `ethyl propanoate` (PIN)；`ethyl propionate`

## P-15.2 官能类命名

### P-15.2.0 引言

官能类命名在有机化学早期相当重要，当时许多化合物使用类名来命名。其程序与取代命名相同，只是从不使用后缀。取代基（早期命名中称为'基'，radicals）与表示类别的名称连用；这种命名被称为'基-官能命名'（radicofunctional nomenclature）。随着时间推移，取代命名在除少数情况外的所有情形中取代了官能类命名。在 IUPAC 优选名称的语境中，取代命名是命名有机化合物的主要方式；官能类命名被缩减到严格的最低限度。

官能类命名的概念也适用于使用类名命名的化合物，但不一定以取代基名称开头。为此，使用'官能修饰词'（functional modifiers）来表示官能变化，例如将酸变为酸酐（如 `acetic anhydride` 乙酸酐），或形成酮的衍生物（例如 `butan-2-one oxime` 丁-2-酮肟）。

方便起见，官能类命名所涉及的主要操作被归类为加合操作，如 P-13.3.3.2 所述。然而，也可以（并且从历史观点看可能更相关）将该过程视为指定存在于给定类名化合物中的取代基（'基'）。例如，名称 'methyl alcohol'（用于 CH₃-OH）由取代基 CH₃- 的名称 'methyl' 和类名 'alcohol'（用于 R-OH）组成。

官能类命名与取代基名称的传统使用和官能修饰词的使用相关进行讨论。有些名称基于类名形成，但不被视为属于官能类命名。它们被称为'描述性名称'（descriptive names），例如 'propanoic acid methyl ester'，并且从不被视为 IUPAC 优选名称。类别的优先顺序（见 P-41）在优选 IUPAC 名称的语境中给出。

- **P-15.2.1** — 使用取代基名称的官能类命名
- **P-15.2.2** — 使用官能修饰词的官能类命名
- **P-15.2.3** — 官能类的优先顺序
- **P-15.2.4** — 多官能化合物

### P-15.2.1 使用取代基名称的官能类命名

#### P-15.2.1.1

官能类名称的形成方式为：将化合物的官能类名称作为一个词表达，分子的其余部分作为一价基名称以单独的词放在类名之前。优选的 IUPAC 官能类名称仅限于酯（P-65.6.3.2）、酰卤（P-65.5.1）和拟卤化物（见 P-65.5.2）。烷基糖苷也获得官能类名称，在碳水化合物命名中被归类为认可名称（见 P-102.5.6.2）。

示例：
- `CH3-CH2-CO-O-CH3` → `methyl propanoate` (PIN) — 丙酸甲酯
- `CH3-CO-Cl` → `acetyl chloride` (PIN) — 乙酰氯
- `C6H5-CO-CN` → `benzoyl cyanide` (PIN) — 苯甲酰氰
- `C6H5-CH2-NCS` → `benzyl isothiocyanate`；`(isothiocyanatomethyl)benzene` (PIN)
- `C6H5-NC` → `phenyl isocyanide`；`isocyanobenzene` (PIN)
- `CH3-OH` → `methyl alcohol`；`methanol` (PIN) — 甲醇
- `phenyl azide`；`azidobenzene` (PIN) — 叠氮苯
- `methyl α-D-gulofuranoside` — 甲基 α-D-呋喃古洛糖苷

#### P-15.2.1.2

当官能类名称指二价特征基团时，与之连接的两个取代基都要表达。当它们相同时，使用适当的数字前缀。当不同时，它们作为单独的词按字母数字顺序书写，并按需添加位次。

示例：
- `CH3-O-CO-CH2-CH2-CO-O-CH3` → `dimethyl butanedioate` (PIN) — 丁二酸二甲酯；`dimethyl succinate`
- `CH3-CO-O-CH2-CH2-O-CO-CH3` → `ethane-1,2-diyl diacetate` (PIN)；`ethylene diacetate`
- `ethyl methyl benzene-1,3-dicarboxylate` (PIN)
- `CH3-CH2-CO-CH2-CH3` → `diethyl ketone`；`pentan-3-one` (PIN)
- `CH3-CH2-CO-CH3` → `ethyl methyl ketone`（不是 methyl ethyl ketone）；`butan-2-one` (PIN)

### P-15.2.2 使用官能修饰词的官能类命名

主特征基团或官能母体化合物（见 P-34）的许多衍生物可以用修饰词命名，这些修饰词由置于母体结构名称之后的一个或多个单独词组成。这种方法在索引环境中最为有用，但它是命名开链酸酐（见 P-65.7.1）、N-氧化物、N-硫化物、N-硒化物和 N-碲化物（见 P-62.5）在优选 IUPAC 名称语境中使用的唯一方法。

示例：
- `CH3-CO-O-CO-CH3` → `acetic anhydride` (PIN) — 乙酸酐（'acid' 一词被 'anhydride' 替换）
- `(CH3)3NO` → `N,N-dimethylmethanamine N-oxide` (PIN)；`trimethylazane N-oxide`；`trimethylamine N-oxide`（传统名，但不能被取代）

官能修饰词对于一般命名目的仍然可以接受，但对于腙（azines）、肟（oximes）、腙类（hydrazones）、缩氨基脲（semicarbazones）、卡巴肼（carbohydrazones）、缩醛（acetals）和半缩醛（hemiacetals），优选 IUPAC 名称是取代名称。

示例：
- `CH3-CH2-CH=N-OH` → `propanal oxime`（'oxime' 一词加到羰基化合物的名称之后）；`N-propylidenehydroxylamine`；`N-hydroxypropan-1-imine` (PIN)
- `CH3-CH2-CH=N-NH2` → `propanal hydrazone`；`propylidenehydrazine` (PIN)
- `(CH3)2C=N-NH-CO-NH2` → `acetone semicarbazone`；`2-(propan-2-ylidene)hydrazine-1-carboxamide` (PIN)
- `CH3-CH2-CH(O-CH3)2` → `propanal dimethyl acetal`；`1,1-dimethoxypropane` (PIN)
- `CH3-CH2-CH2-CO-OCH3` → `butanoic acid methyl ester`；`methyl butanoate` (PIN)

### P-15.2.3 官能类的优先顺序

当存在两个类并且两者都通过官能类命名命名时，必须按照类别的优先顺序（见 P-41）选择优先类。与优选 IUPAC 名称相关的顺序是酸酐、酯、酰卤。卤化物和拟卤化物的优先顺序在 P-65.5 中讨论。优先类通过官能类命名表达，较低级别的类按惯例在名称中由取代命名构造的部分中以前缀表达。

示例：
- `methyl 4-chloro-4-oxobutanoate` (PIN)
- `methyl 3-(chlorocarbonyl)propanoate`
- `methyl 3-carbonochloridoylpropanoate`
- `Cl-CH2-OH` → `chloromethyl alcohol`；`chloromethanol` (PIN)（醇优先于卤化物）
- `cyanoacetyl chloride` (PIN)（酰氯优先于腈）
- `methyl 4-methoxybutanoate` (PIN)（酯优先于醚）

### P-15.2.4 多官能化合物

不建议对多官能化合物使用官能类名称。优选取代命名。

- `HO-CH2-CH2-CO-CH3` → `4-hydroxybutan-2-one` (PIN；取代名称)；`2-hydroxyethyl methyl ketone`（官能类名称）

## P-15.3 倍增命名

### P-15.3.0 引言

倍增命名用于命名相同母体结构的集合。倍增命名有两个子集：

（1）取代命名的子集，其中相同的结构单元由二价或多价取代基连接（见 P-15.3.1）；

（2）官能类命名的子集，其中相同的结构单元由二价或多价非酸性残基连接（该子集仅用于命名酯，见 P-65.6.3.2，并产生诸如 `ethane-1,2-diyl diacetate` 之类的名称，用于 CH₃COO-CH₂-CH₂-OCOCH₃）。

在作为取代命名子集的倍增命名字集中，两个或多个相同单元（例如母体结构）由二价或多价取代基（称为'倍增原子或基团'或'连接原子或基团'）连接，可以用两种方式命名：

(a) 通过倍增命名，其中两个或多个母体结构由对称或不对称的单个或级联取代基连接；和

(b) 通过取代命名（见 P-15.1），其中选择一个母体结构作为优先母体结构，结构的其余部分用取代前缀表达。

例如，以下化合物可以用倍增命名命名为 `4,4′-sulfanediyldibenzoic acid` (PIN) [编号如（I）所示]，该名称在母体结构名称中包含两个苯甲酸基团。（结构式 (I) 见原书；此处省略）或者，它可以用取代命名命名为 `4-[(4-carboxyphenyl)sulfanyl]benzoic acid` [编号如（II）所示]，该名称在母体结构名称中只包含一个苯甲酸基团；另一个苯甲酸基团表达为前缀。

本节讨论倍增名称构建的一般原理。在构建优选 IUPAC 名称时使用倍增命名的规则在 P-51.3 中给出。

倍增命名现在扩展到有或没有特征基团的环状结构；仅由碳原子组成的链继续被排除在外。在过去的建议中，倍增命名仅限于具有以后缀表达的特征基团或由保留名暗示的特征基团的化合物，以及杂环母体氢化物。现在该系统也已扩展，允许在倍增基团的中心单元上取代（P-15.3.1.2.1.2），以及在特定条件下使用非对称中心单元（P-15.3.3.1）。

### P-15.3.1 通用方法

#### P-15.3.1.1 相同母体结构

倍增命名中有四种类型的相同母体结构：

(a) 环状母体氢化物，mancude 或饱和的；

(b) 单核或多核开链母体氢化物，饱和或不饱和的开链烃除外；

(c) 被以后缀表达的特征基团取代的环状或开链母体氢化物，即官能化母体氢化物（见 P-15.1.2.3）；

(d) 具有可取代氢原子的官能母体化合物，例如 `acetic acid` 或 `phosphonic acid`（见 P-15.1.2.1）。

相同母体结构必须通过相同的键（单键、双键或三键）连接到倍增取代基上，并且被相同地取代。

#### P-15.3.1.2 倍增取代基

倍增取代基有两种类型：

- **P-15.3.1.2.1** 简单倍增原子或基团
- **P-15.3.1.2.2** 级联倍增基团

##### P-15.3.1.2.1 简单倍增原子或基团

###### P-15.3.1.2.1.1

任何简单的多价取代基（定义见 P-29.1）在连接到两个或多个相同结构单元时，都可以用作倍增取代基。

示例：
- `-CH2-` → `methylene` (优选前缀) — 亚甲基（不是 methanediyl）
- `-O-` → `oxy` (预选前缀) — 氧
- `-S-` → `sulfanediyl` (预选前缀)；`thio` — 硫
- `-OO-` → `peroxy` (预选前缀) — 过氧（不再推荐 dioxy）
- `-SS-` → `disulfanediyl` (预选前缀)；`dithio` — 二硫
- `-N<` → `nitrilo` (预选前缀) — 次氮基

前缀 'nitrilo'，-N<，仅当三个键连接到不同原子时才用作预选前缀；它不再用于结构 -N=，后者现在命名为预选前缀 'azanylylidene'。

- `1,4-phenylene`（还有 1,2- 和 1,3- 异构体；优选前缀）— 1,4-亚苯基
- `-OC-CH2-CH2-CO-` → `butanedioyl` (优选前缀)；`succinyl` — 丁二酰
- `ethane-1,1,2-triyl` (优选前缀) — 乙烷-1,1,2-三基
- `prop-1-ene-1,3-diyl` (优选前缀) — 丙-1-烯-1,3-二基

###### P-15.3.1.2.1.2

允许在简单倍增基团（对称或不对称）上进行以前缀表达或暗示的取代，产生取代的复合或复杂（定义见 P-29.1）倍增基团。

示例：
- `ClCH<` → `chloromethylene` (优选前缀；复合倍增基团)；`chloromethanylylidene` (优选前缀；复合倍增基团)
- `1-chloroethane-1,2-diyl` (优选前缀；复合倍增基团)
- `CH3-N<` → `methylazanediyl` (优选前缀；复合倍增基团)（不再用 methylimino）

名称 `azanediyl`（预选前缀）衍生自预选母体氢化物名称 'azane'，推荐用于倍增取代基 -NH-；名称 `imino`（也是预选前缀）仅用于 =NH 作为取代基。

- `ClCH2-P<` → `(chloromethyl)phosphanediyl` (优选前缀；复杂倍增基团)
- `2-methylpropane-1,3-diyl` (优选前缀)
- `butane-1,3-diyl` (优选前缀；见 P-29.3.2.2)
- `1-methylpropane-1,3-diyl`（见 P-29.4.1）
- `2-(dimethylamino)propane-1,3-diyl` (优选前缀)

##### P-15.3.1.2.2 级联倍增基团

###### P-15.3.1.2.2.1

级联（concatenation）是用于形成多部分二价和多价倍增取代基的方法。级联倍增基团的形成方式是：首先引用中心倍增取代基，然后跟一个倍增前缀（如 'di'、'tri' 等或 'bis'、'tris' 等），然后按顺序、朝着相同母体结构的方向，依次引用相继的二价或多价取代基的名称。

示例：
- `-O-CH2-O-` → `methylenebis(oxy)` (优选前缀)（不是 methylenedioxy；dioxy 可能有歧义，因为它可能是 'peroxy' 或两倍 'oxy' [见 P-15.3.1.2.1.1、P-16.3.6 (b)]）
- `-CH2-O-CH2-` → `oxybis(methylene)` (优选前缀)
- `benzene-1,2,4-triyltris(oxy)` (优选前缀)
- `ethane-1,1,2-triyltrinitrilo` (优选前缀)
- `-CH2-NH-CO-CH2-CO-NH-CH2-` → `propanedioylbis(azanediylmethylene)` (优选前缀)

注：当中心倍增基团后跟两个或多个连续的倍增基团时，它们不用单独的倍增前缀。因此，上面示例的优选 IUPAC 名称不是 propanedioylbis(azanediyl)bis(methylene)。

###### P-15.3.1.2.2.2

当使用 'yl/ylidene' 类型的多价取代基（没有位次并以规定顺序引用）于多部分倍增取代基时，级联通过将 'yl' 类型的一价自由价添加到另一个 'yl' 类型的一价自由价上来发生，'ylidene' 类型的自由价也是如此。

示例：
- `-CH=N-O-N=CH-` → `oxybis(azanylylidenemethanylylidene)` (优选前缀) [不是 oxybis(nitrilomethanylylidene)]
- `-O-N=CH-CH=N-O-` → `ethane-1,2-diylidenebis(azanylylideneoxy)` (优选前缀)
- `-O-N=C=N-O-` → `methanediylidenebis(azanylylideneoxy)` (优选前缀)
- `=CH-N=C=N-CH=` → `methanediylidenebis(azanylylidenemethanylylidene)` (优选前缀) [不是 methanediylidenebis(nitrilomethanylylidene)]

###### P-15.3.1.2.2.3

允许在级联倍增取代基的中心取代基和相继取代基上进行取代，前提是从中心取代基开始的原子和键的序列在每个分支中都相同。

示例：
- `oxybis(methylazanediyl)` (优选前缀)
- `ethane-1,2-diylbis[azanylylidene(chloromethanylylidene)]` (优选前缀)
- `oxybis(cyclopropylidenemethylene)` (优选前缀)

注：如果后缀 'ylidene' 不限于表示双键（见 P-29.2），这里给出的优选前缀将是有歧义的；它可能指环丙烷键以单键连接到 CH₂ 基团和氧原子的结构；然而，后一种结构将具有优选 IUPAC 前缀 `oxybis(cyclopropane-1,1-diylmethylene)`。

###### P-15.3.1.2.2.4

多部分二价或三价倍增取代基的组成部分的编号，在必要时，通过将最低位次赋予最靠近被倍增母体结构的组件末端的原子来实现，除非该组件具有固定编号。连接到被倍增母体结构的位次最后引用。当没有选择余地时，位次按数值递增顺序引用。

示例：
- `oxybis(1-chloroethane-2,1-diyl)` (优选前缀)；`oxybis(1-chloroethylene)`
- `oxybis(2-chloroethane-2,1-diyl)` (优选前缀)；`oxybis(2-chloroethylene)`
- `peroxydi(4,1-phenylene)` (优选前缀) [不是 dioxydi(4,1-phenylene)]
- `methylenebis(1,3,5-triazine-6,2,4-triyl)` (优选前缀)
- `oxybis[(1-chloroethane-2,1-diyl)phosphanylylideneethan-1-yl-2-ylidene]` (优选前缀；ethan-1-yl-2-ylidene 的编号是固定的)
- `ethane-1,2-diylbis(oxyethane-2,1-diyl)` (优选前缀)
- `oxydi(propan-1-yl-3-ylidene)` (优选前缀)
- `hydrazinediylidenedi(propan-1-yl-3-ylidene)` (优选前缀；propan-1-yl-3-ylidene 的编号是固定的)

#### P-15.3.1.3 倍增名称的形成

倍增名称根据 P-15.3.1.1 定义的相同结构单元出现的次数，以及连接倍增取代基与相同结构单元的关系来形成。

当化合物含有 P-15.3.1.1 定义的由对称简单、复合、复杂或级联倍增基团（二价或多价取代基）连接的相同结构单元时，其命名依次说明：

(a) 连接倍增取代基原子或基团与相同母体结构单元的取代位置的位次（单核母体氢化物名称中单独存在时省略位次 1）；

(b) 连接倍增取代基原子或基团的名称；

(c) 数字前缀 'di'、'tri' 等；和/或 'bis-'、'tris-' 等，在相同母体结构单元名称之前不省略末尾元音；

(d) 一个相同结构单元的名称，包括主特征基团和取代基（如果有），用适当的括号括起来（见 P-16.5）。

相同母体结构单元的编号被保留，当有选择时，连接倍增取代基在相同母体结构上的取代位置的位次尽可能低。

### P-15.3.2 倍增名称的构建

#### P-15.3.2.1 相同结构单元的集合（见 P-15.3.1.1）

保留名和系统名可以用作相同母体结构单元。撇号、双撇号等用于区分相同母体结构单元的位次。当官能化母体氢化物，即被以后缀表达的基团取代的母体结构（见 P-15.1.2），有位次时，它们用括号括起来，前面加数字前缀 'di-'、'tri-' 等。未取代的官能母体化合物前加数字前缀 'di-'、'tri-' 等，但不加括号，只要没有 P-15.3.2.3 中描述的歧义。复合和复杂倍增取代基按要求用括号、方括号或花括号括起来（见 P-16.5）。

示例：
- `1,1′-peroxydibenzene` (PIN)（不是 dioxydibenzene）
- `1,1′-methylenebis(disilane)` (PIN)
- `1,1′-methylenebis(1-azacyclododecane)` (PIN)
- `2,2′-sulfanediyldi(ethan-1-ol)` (PIN)；`2,2′-thiodi(ethan-1-ol)`
- `8,8′-oxydi(spiro[4.5]decane)` (PIN)
- `[oxydi(tetradecane-14,1-diyl)]bis(silane)` (PIN)
- `4,4′-oxydi(cyclohexane-1-carboxylic acid)` (PIN)
- `4,4′-oxydi(benzene-1-sulfonic acid)` (PIN)
- `4,4′-[(2-methylpropane-1,3-diyl)bis(oxy)]diphenol` (PIN)
- `2,2′-[ethane-1,2-diylbis(oxymethylene)]di(cyclohexane-1-carboxylic acid)` (PIN)
- `2,2′-[oxybis(ethane-2,1-diyloxy)]diacetic acid` (PIN)
- `4,4′-[oxydi(tetradecane-14,1-diyl)]diphenol` (PIN)
- `4,4′-[oxybis(1-fluoroethane-2,1-diyl)]di(cyclohexane-1-sulfonic acid)` (PIN)
- `2,2′-oxydiacetic acid` (PIN)
- `3,3′-oxydipropanoic acid` (PIN)
- `2,2′,2′′-phosphanetriyltriacetic acid` (PIN)
- `(HO)2P(O)-CH2-NH-CH2-P(O)(OH)2` → `[azanediylbis(methylene)]bis(phosphonic acid)` (PIN)
- `[oxydi(pyridazine-4,3,5-triyl)]tetramethanol` (PIN)（位次集合 '3,4,5' 低于 '4,5,6'，且位次集合 '3,5' 是分配给连接到被倍增母体结构的哒嗪最低位次集合）
- `[oxydi(pyridazine-5,3,4-triyl)]tetramethanol` (PIN)（位次集合 '3,4,5' 低于 '4,5,6'；位次集合 '3,4' 是分配给连接到被倍增母体结构的哒嗪最低位次集合）
- `H2N-CH2-CH2-O-CH2-CH2-NH2` → `2,2′-oxydi(ethan-1-amine)` (PIN)
- `2,2′,2′′-nitrilotri(ethan-1-ol)` (PIN)
- `10,10′-[[1,1′-biphenyl]-4,4′-diylbis(oxy)]di(decanoic acid)` (PIN)

> 注：上述名称中出现双重的方括号，因为环集合体名称衍生的取代基名称需要方括号（见 P-16.5.2.1），而括住倍增取代名称又需要括号。

- `2,2′,2′′,2′′′-(ethane-1,2-diyldinitrilo)tetraacetic acid`
- `N,N′-(ethane-1,2-diyl)bis[N-(carboxymethyl)glycine]`

##### P-15.3.2.1.1

如果有选择，较多的撇号给予连接到倍增取代基的位次编号较高的母体结构的位次。这样的名称不能作为优选 IUPAC 名称接受，但可以在一般命名中使用；在这些情况下，优选 IUPAC 名称由取代命名原理生成（见 P-51.3.3）。

示例：
- `2,4′-methylenedi(cyclohexane-1-carboxylic acid)`（倍增名称）；`2-[(4-carboxycyclohexyl)methyl]cyclohexane-1-carboxylic acid` (PIN) [不是 4-[(2-carboxycyclohexyl)methyl]cyclohexane-1-carboxylic acid；取代基位次 '2' 低于 '4'（见 P-45.2.2）]
- `2,3′-oxydipropanoic acid`（倍增名称）；`2-(2-carboxyethoxy)propanoic acid` (PIN) [不是 3-(1-carboxyethoxy)propanoic acid；取代基位次 '2' 低于 '3'（见 P-45.2.2）]

#### P-15.3.2.2 相同母体结构中氮原子的位次

##### P-15.3.2.2.1

在倍增命名中，斜体字母 N 上使用撇号来区分含有带一个或多个氮原子的特征基团的相同结构单元的氮原子。

示例：
- `N,N′-methylenediethanamine`
- `N′,N′′′-methylenediacetohydrazide` (PIN)

##### P-15.3.2.2.2

在倍增命名中，使用上标阿拉伯数字表示特征基团所连接的母体结构的位置位次，以及适当数量的撇号，例如 N1、N2′、N4′′ 等，来区分含有两个或多个带一个或多个氮原子的特征基团的相同结构单元的氮原子。

示例：
- `N1,N1′-methylenedi(benzene-1,4-diamine)` (PIN)
- `N1,N1′-methylenedi(pentane-1,3,4-triamine)` (PIN)

> 注：第二个相同母体结构的连接位次是 N1；这是加撇号的位次。

对于具有多个氮原子的母体结构，例如二或三甲亚胺酰胺（P-66.4.1.4）和环番胺（见 P-62.2.5.3），需要更复杂的位次结构，例如带上了标数字或上标上标数字的加撇号字母位次。

#### P-15.3.2.3 倍增前缀 'bis'、'tris' 等的使用

对于因潜在歧义而不能使用数字前缀 'di-'、'tri-' 等（见 P-16.3.6）的相同母体结构，按要求用括号或方括号括起来，前面加数字词 'bis-'、'tris-' 等。

示例：
- `(benzene-1,3,5-triyl)tris(silane)` (PIN)（不是 benzene-1,3-5-triyltrisilane；trisilane 是 H₃Si-SiH₂-SiH₃）
- `H3Si-[CH2]14-O-[CH2]14-SiH3` → `[oxydi(tetradecane-14,1-diyl)]bis(silane)` (PIN) [关于 'di' 在 'tetradecane-14,1-diyl' 之前，见 P-16.3.4 (c)]

#### P-15.3.2.4 被取代的相同母体结构（见 P-15.3.2.1）

当由对称倍增基团连接的相同母体结构在相同母体结构上含有主特征基团（如果有）以外的取代基时，这些取代基以两种方式之一作为前缀引用。

##### P-15.3.2.4.1

当满足以下两个条件时，相同母体结构上除主特征基团（如果有）以外的取代基作为与该相同母体结构相关联的前缀引用：

（1）倍增基团的中心取代基与所有后续结构单元之间的连接键（单键或多重键）相同；且

（2）相同母体结构上所有取代基（包括后缀）的位次相同。

相同母体结构连同其前缀和后缀（如果有）被视为复合或复杂基团，按 P-16.5 给出的嵌套顺序用括号、方括号或花括号括起来，并用适当的数字前缀 'bis'、'tris'、'tetrakis' 等表示。

示例：
- `1,1′-oxybis(4-bromobenzene)` (PIN)
- `4,4′-oxybis(2-bromobenzoic acid)` (PIN)
- `1,1′-methylenebis(pentafluorodisilane)` (PIN)
- `N,N′-oxybis(N-methylmethanamine)` (PIN)
- `N,N′-[ethenyl(methyl)silanediyl]bis(N-methylacetamide)` (PIN)
- `1,1′-methylenebis[3-bromo-4-(chloromethyl)benzene]` (PIN)
- `3,3′-oxybis[5-(1-chloroethyl)pyridine]` (PIN)
- `(benzene-1,3,5-triyl)tris(trimethylsilane)` (PIN)
- `3,3′-sulfanediylbis(N,N-dimethylpropanamide)` (PIN)
- `bis(phenyldiazenyl)methanone` (PIN) [不是 1,1′-carbonylbis(2-phenyldiazene)]

##### P-15.3.2.4.2

当不满足上述 P-15.3.2.4.1 定义的条件（1）和（2）时，后缀（如果有）识别的取代基以外的取代基作为前缀引用在集合名称的前面。这些前缀在优先给予主特征基团和连接倍增取代基之后，被分配可用最低位次。这样的名称不能作为优选 IUPAC 名称接受，但可以在一般命名中使用；在这些情况下，优选 IUPAC 名称由取代命名原理生成（见 P-51.3.3）。

示例：
- `4-chloro-2,3′-methylenedibenzonitrile`（倍增名称；编号如所示）；`4-chloro-2-[(3-cyanophenyl)methyl]benzonitrile` (PIN) [不是 3-[(5-chloro-2-cyanophenyl)methyl]benzonitrile；PIN 有更多取代基；见 P-45.2.1]
- `4,6′-dichloro-2,3′-(ethane-1,2-diyl)diphenol`（倍增名称；编号如所示）；`4-chloro-2-[2-(4-chloro-3-hydroxyphenyl)ethyl]phenol` (PIN) [不是 2-chloro-5-[2-(5-chloro-2-hydroxyphenyl)ethyl]phenol；PIN 中取代基的位次集合 '2,4' 低于 '2,5'；见 P-14.4 (f)、P-45.2.2]
- `1-chloro-1,1′-(ethane-1,2-diyl)bis(silane)`（倍增名称；编号如所示）；`chloro(2-silylethyl)silane` (PIN) [不是 [2-(chlorosilyl)ethyl]silane；PIN 的母体硅烷有更多取代基；见 P-45.2.1]
- `2,2,2-trimethyl-1,1′-(disulfanediyl)bis(disilane)`（倍增名称；编号如所示）；`2-(disilanyldisulfanyl)-1,1,1-trimethyldisilane` (PIN) [不是 [2-(2,2,2-trimethyldisilan-1-yl)disulfanyl]disilane；PIN 中的母体二硅烷有更多取代基；见 P-45.2.1] [不是 6,6-dimethyl-3,4-dithia-1,2,5,6-tetrasilaheptane；骨架置换名称需要四个杂单元（见 P-51.4）]
- `2′,5-dichloro-2,4′-oxydipyridine`（倍增名称；编号如所示）；`2-chloro-4-[(5-chloropyridin-2-yl)oxy]pyridine` (PIN) [不是 5-chloro-2-[(2-chloropyridin-4-yl)oxy]pyridine；PIN 中取代基的位次集合 '2,4' 低于 '2,5'；见 P-45.2.2]

##### P-15.3.2.4.3

当有选择时，不带撇号的位次分配给在字母数字顺序中最先引用的取代基所在的相同母体结构。

示例：
- `3-bromo-3′-chloro-1,1′-methylenedibenzene`（倍增名称；编号如所示）；`1-bromo-3-[(3-chlorophenyl)methyl]benzene` (PIN) [不是 1-[(3-bromophenyl)methyl]-3-chlorobenzene；'bromochloro' 在字母数字顺序上优于 'bromophenyl'；见 P-45.5]
- `5-bromo-5′-fluoro-2,2′-oxydibenzoic acid`（倍增名称；编号如所示）；`2-(4-bromo-2-carboxyphenoxy)-5-fluorobenzoic acid` (PIN) [不是 5-bromo-2-(2-carboxy-4-fluorophenoxy)benzoic acid；'2,5' 优于 '5,2'；见 P-45.2.3]

### P-15.3.3 由不对称倍增基团连接的相同单元

#### P-15.3.3.1

允许不对称中心倍增取代基，前提是它们由多价取代基形成，后续基团通过相同的键（单键或多重键）连接到该多价取代基上。用作倍增器的完整中心取代基中单个基团的数量没有限制。

示例：
- `(propane-1,2-diyl)bis(trimethylsilane)` (PIN)；`trimethyl[1-(trimethylsilyl)propan-2-yl]silane`
- `1,1′-(prop-1-ene-1,3-diyl)bis(4-bromobenzene)` (PIN)；`1-bromo-4-[3-(4-bromophenyl)prop-1-en-1-yl]benzene` [不是 1-bromo-4-[3-(4-bromophenyl)prop-2-en-1-yl]benzene；正确的取代名称在母体取代基中有较低位次]

#### P-15.3.3.2 倍增名称之间的选择

##### P-15.3.3.2.1

优选名称倍增最多的相同母体结构。

示例：
- `4,4′,4′′-(ethane-1,1,2-triyl)tribenzoic acid` (PIN)；`4,4′-[2-(4-carboxyphenyl)ethane-1,1-diyl]dibenzoic acid`（优选 IUPAC 名称倍增更多相同的母体结构。'3' 对 '2'）
- `1,1′,1′′-({[diphenyl(triphenylmethoxy)methyl]sulfanyl}methanetriyl)tribenzene` (PIN) [不是 1,1′-{(triphenylmethoxy)[(triphenylmethyl)sulfanyl]methylene}dibenzene；不是 1,1′,1′′-({diphenyl[(triphenylmethyl)sulfanyl]methoxy}methanetriyl)tribenzene；优选 IUPAC 名称在字母数字顺序上更低；'diphenyltriphenylmethoxy' 低于 'diphenyltriphenylmethyl']

##### P-15.3.3.2.2

当必须在母体结构和倍增基团的组件之间做出选择时，使用类别的优先顺序（见 P-41）。

示例：
- `bis(phenyldiazenyl)methanone` (PIN) [不是 1,1′-carbonylbis(2-phenyldiazene)；不是 1,1′-[carbonylbis(diazenediyl)]dibenzene；酮优先于 'diazene'，'diazene' 优先于碳环 'benzene'，见 P-41]

### P-15.3.4 倍增命名的限制

在以下情况下不使用倍增命名。当倍增命名不可能时，使用取代命名生成优选 IUPAC 名称。

#### P-15.3.4.1 不允许的倍增取代基

有三种不同类型的倍增取代基不允许在倍增命名中使用。

##### P-15.3.4.1.1 由两个或多个不同组件组成的不对称取代基

示例：
（1）`-CH2-OO-`，如 H₃Si-SiH₂-CH₂-OO-SiH₂-SiH₃ 中 → `[(disilanylmethyl)peroxy]disilane` (PIN) [不是 [(disilanylperoxy)methyl]disilane；'disilanylmethylperoxy' 在字母数字顺序上先于 'disilanylperoxymethyl'（见 P-14.5）] [不是 3,4-dioxa-1,2,6,7-tetrasilaheptane；骨架置换名称需要四个杂单元（见 P-51.4）]

（2）`-CH2-NH-`，如在下列结构中 → `4-[(4-hydroxyanilino)methyl]phenol` (PIN) [不是 4-{[(4-hydroxyphenyl)methyl]amino}phenol；'hydroxyanilinomethyl' 在字母数字顺序上先于 'hydroxyphenylmethylamino'（见 P-14.5）]

（3）`-O-CH2-CH2-S-`，如 H₃Si-SiH₂-O-CH₂-CH₂-S-SiH₂-SiH₃ 中 → `3-oxa-6-thia-1,2,7,8-tetrasilaoctane` (PIN)；`{[2-(disilanyloxy)ethyl]sulfanyl}disilane` [不是 [2-(disilanylsulfanyl)ethoxy]disilane；'disilanyloxy' 在字母数字顺序上先于 'disilanylsulfanyl'；见 P-14.5]

##### P-15.3.4.1.2 具有不同类型自由价端原子的不对称取代基

示例：
（1）`-CH=`，如在下列结构中 → `(cyclohexylidenemethyl)benzene` (PIN) [不是 (phenylmethylidene)cyclohexane；苯优先于环己烷（见 P-44.4.1.1）]

（2）`-CH2-CH=N-CH2-CH=`，如在下列结构中 → `4-(2-{[2-(4-hydroxycyclohexyl)ethylidene]amino}ethylidene)cyclohexan-1-ol` (PIN) [不是 4-(2-{[2-(4-hydroxycyclohexylidene)ethyl]imino}ethyl)cyclohexan-1-ol；'(hydroxycyclohexyl)ethylidene' 在字母数字顺序上先于 '(hydroxycyclohexylidene)ethyl'；见 P-14.5]

##### P-15.3.4.1.3 不对称取代的组件单元

示例：
（1）如在下列结构中 → `4-{2-[2-(4-carboxyphenyl)-1-chloroethoxy]-1-chloroethyl}benzoic acid` (PIN) [不是 4-{2-[2-(4-carboxyphenyl)-2-chloroethoxy]-2-chloroethyl}benzoic acid；'1-chloroethoxy' 在字母数字顺序上先于 '2-chloroethoxy'；见 P-45.5]

#### P-15.3.4.2 不允许的相同单元

开链烃，饱和或不饱和，不允许作为倍增命名中的母体结构 [见 P-15.3.1.1 (b)]。

示例：
- `1-{[2-(ethylsulfanyl)-1-(propylsulfanyl)ethen-1-yl]sulfanyl}propane` (PIN；取代名称)（不是 1,1′-{[2-(ethylsulfanyl)ethene-1,1-diyl]bis(sulfanyl)}dipropane；烷烃仍然不允许作为相同单元）

## P-15.4 骨架置换（'a'）命名

### P-15.4.0 引言

骨架置换（'a'）命名是置换命名的子集，置换命名还包括官能置换命名（见 P-13.2）。官能置换命名在 P-15.5 中讨论。正如官能置换被视为一种命名，骨架置换也被视为一种命名。在有机化合物的命名中，基于将碳原子置换为有机化合物命名一般范围内包含的其他原子的骨架置换，在'骨架置换（'a'）命名'的标题下描述，因为置换碳原子的杂原子由以 'a' 结尾的不可分离前缀表示。骨架置换（'a'）命名还包括将硼原子置换为其他原子（包括碳）（见 P-68.1.1.3.1），以及将杂原子置换为其他原子（包括碳），以修饰天然产物的基本结构，如 P-101.4 所述。对于某些杂环中氮原子被磷和砷原子置换（见表 2.9），以及其他特定杂环中氧原子被硫、硒和碲原子置换（见表 2.8），描述了用 'a' 前缀以外的方法表示的骨架置换。

本节主要讨论烃母体氢化物中的骨架置换。骨架置换（'a'）命名以两种方式使用：

(a) 通过在相应环状烃中置换碳原子，生成杂环母体氢化物的名称；以及

(b) 通过置换相应开链烃中的碳原子，生成比遵循取代命名原理形成的更简单的杂开链结构名称，例如在命名多胺、多醚等时。

在以前的建议中，杂开链链必须以碳原子终止（1993 年指南中的规则 R-2.2.3.1）；但在本建议中，杂环链现在可以以下任何杂原子终止：P、As、Sb、Bi、Si、Ge、Sn、Pb、B、Al、Ga、In、Tl 和 C（见 P-15.4.3.1）。

涉及骨架置换（'a'）命名的优选 IUPAC 名称的选择在 P-51.4 中讨论。

### P-15.4.1 通用规则

#### P-15.4.1.1

称为 'a' 前缀的不可分离前缀用于表示带其标准键数的置换骨架原子。与本建议相关的前缀列于表 1.5。

**表 1.5** 骨架置换（'a'）前缀

| 标准键数 | 3 | 4 | 3 | 2 | 1 |
|---|---|---|---|---|---|
|  | B bora | C carba | N aza | O oxa | F fluora |
|  | Al alumina | Si sila | P phospha | S thia | Cl chlora |
|  | Ga galla | Ge germa | As arsa | Se selena | Br broma |
|  | In inda | Sn stanna | Sb stiba | Te tellura | I ioda |
|  | Tl thalla | Pb plumba | Bi bisma | Po polona | At astata |

#### P-15.4.1.2

出于命名和编号的目的，遵循以下元素优先顺序递减：**F > Cl > Br > I > At > O > S > Se > Te > Po > N > P > As > Sb > Bi > C > Si > Ge > Sn > Pb > B > Al > Ga > In > Tl**（见附录 1）。一旦经骨架置换（'a'）前缀修饰的结构被命名和编号，它就被视为新的母体氢化物。由于分配给杂原子的位次是必不可少的，所有位次必须按 P-14.3.3 的规定引用。

#### P-15.4.1.3

符号 λn 用于描述具有非标准键数的杂原子（P-14.1.3）。在名称中，它紧置于表示杂原子的位次之后（中间没有连字符）。

示例：
- `6λ5-phosphaspiro[4.5]decane` (PIN)

#### P-15.4.1.4

用于表示阴离子和阳离子杂原子的阴离子和阳离子骨架置换（'a'）前缀衍生自表 1.5 中给出的中性前缀。这些骨架置换前缀都是预选的。

示例：
- `phosphanida` — 磷烷基阴离子
- `boranuida` — 硼烷基阴离子
- `sulfanuida` — 硫烷基阴离子
- `λ4-sulfanuida` — λ4-硫烷基阴离子
- `azanylia` — 氮烷鎓阳离子（azaniumyl）
- `iodonia` — 碘鎓（iodonium）
- `thionia` — 硫鎓（thionium）

涉及离子骨架置换（'a'）前缀的优选 IUPAC 名称的选择在 P-72.4 和 P-73.4 中全面讨论。

### P-15.4.2 杂环母体氢化物的命名

骨架置换（'a'）命名以三种方式应用于命名杂环母体氢化物。

#### P-15.4.2.1

骨架置换（'a'）命名简单地应用于生成单个杂单环母体氢化物（见 P-22.2.3）、杂环 von Baeyer 母体氢化物（见 P-23.3）、仅由单环组成的杂环螺环母体氢化物（见 P-24.2.4.1）和富勒烯（见 P-27.5）。这些杂环化合物用作倍增命名中的相同母体结构，但不作为稠合命名或环集合体中的组件。

#### P-15.4.2.2

当单个杂环是上述 P-15.4.2.1 未涵盖的杂环螺环系 [见 P-24.3.4、P-24.4.3（部分）和 P-24.5.2（部分）]、杂环 phane 系（见 P-26.5.2）或杂环环集合体（见 P-28.4）的组件时，骨架置换（'a'）命名以两步程序应用。首先将结构命名为全部或部分烃系。然后添加骨架置换（'a'）前缀并引用在名称的前面。由此方法形成的名称用作倍增命名中的相同母体结构。

#### P-15.4.2.3

由骨架置换（'a'）命名命名的杂单环 mancude 组件，在用作稠合命名中的组件环时被修饰 [见 P-25.2.2.1、P-25.2.2.4（部分）和 P-25.3.2.1.2]。

### P-15.4.3 开链母体氢化物的骨架置换（'a'）命名

#### P-15.4.3.1

骨架置换名称的形成方式为：按照 P-15.4.1.2 给出的优先顺序，将骨架置换（'a'）前缀放在无支链母体结构名称的前面。倍增前缀 'di'、'tri'、'tetra' 等表示相同杂原子的多重性，位次用于表示它们的位置。链必须以 C 原子或以下杂原子之一终止：P、As、Sb、Bi、Si、Ge、Sn、Pb、B、Al、Ga、In 或 Tl。杂开链链以 P、As、Sb、Bi、Si、Ge、Sn、Pb、B、Al、Ga、In 或 Tl 终止是相对于早期建议（链只能以碳原子终止）的一个变化。

示例：
- `2,8-dioxa-4,5-dithia-11-selenadodecane` (PIN)
- `2-oxa-4-thia-1,5-disilapentane` (PIN)

#### P-15.4.3.2 杂开链母体氢化物的编号

##### P-15.4.3.2.1

无支链链从一端到另一端连续编号，以便将较低的位次集合给予被视为一个整体而不考虑种类的杂原子，然后，如果有选择，给予在 P-15.4.1.2 给出的优先顺序中最先引用的杂原子。在本建议中，骨架置换（'a'）命名生成编号固定的新开链母体氢化物，就像环和环系一样；这是对规则 C-0.6（ref. 1）的重大修改。然后根据这个固定编号添加后缀、词尾和前缀。

示例：
- `8-thia-2,4,6-trisiladecane` (PIN)（位次集合 '2,4,6,8' 低于 '3,5,7,9'；见 P-14.3.5）
- `2-oxa-4,6,8-trisilanonane` (PIN)（杂原子位次集合 '2,4,6,8' 相同；因此，低位次给予 'O' 而非 'Si'；见附录 1）

##### P-15.4.3.2.2

取代基的自由价根据杂链的固定编号接收位次。

示例：
- `2,4,6,8-tetrasiladecan-10-yl` (优选前缀) [注意使用 'decan-10-yl' 而非 'dec-10-yl'；见 P-29.3.2.2]
- `2,4,6,8-tetrasiladecan-5-yl` (优选前缀)
- `2,4,6,8-tetrasilaundecan-11-yl` (优选前缀)

##### P-15.4.3.2.3

作为后缀引用的特征基团根据杂链的固定编号接收位次。

示例：
- `2,4,6,8-tetrasilanonan-1-oic acid` (PIN)（位次 1 不省略，依据 P-15.4.3.2.1）
- `2,4,6,8-tetrasiladecan-10-ol` (PIN)
- `2,4,6,8-tetrasiladecan-10-oic acid` (PIN)

##### P-15.4.3.2.4

双键和三键根据杂链的固定编号接收位次，如果有选择，则根据多重键的一般优先级（见 P-31.1.2.2.2）。

示例：
- `2,4,6,8-tetrasiladec-9-ene` (PIN)

##### P-15.4.3.2.5 具有非标准化合价的杂原子

(a) 母体氢化物中中性骨架杂原子的非标准键数由符号 λn 表示，其中 'n' 是跟随相应位次的键数（见 P-14.1.3）。

示例：
- `2,5,8-trioxa-11λ4-thiadodecane` (PIN)（'O' 优于 'S' 获得低位次；见附录 1）

(b) 当有选择时，低位次分配给具有较高键数的杂原子。

示例：
- `2λ4,5,8,11-tetrathiadodecane` (PIN)

#### P-15.4.3.3

阴离子和阳离子骨架置换（'a'）前缀的使用分别在 P-72.4 和 P-73.4 中全面讨论。

## P-15.5 官能置换命名

### P-15.5.1 定义

官能置换命名是这样一种方法，通过它，特征基团的氧原子和官能母体化合物中的氧原子被卤素、硫族和/或氮原子置换。

### P-15.5.2 通用方法

氧原子或羟基被其他原子或基团置换，可以通过附加到具有保留名或系统名的特征基团、母体氢化物和官能母体化合物名称上的不可分离前缀，或插入其中的中缀来描述。前缀和中缀的列表见表 1.6。前缀和中缀用于表示置换原子 -OO-、-S-、-Se-、-Te- 等。例如，thio 表示后缀 sulfonothioyl 和 carbothioyl 以及官能母体 `thioacetic acid` 中氧原子被硫置换。类似地，peroxo 或 peroxy 表示后缀 `peroxoic acid` 和名称 `peroxyacetic acid` 中氧原子被 -OO- 基团置换。当存在两个或多个前缀或中缀表示两个或多个不同的置换基团时，它们在名称中按字母顺序引用，例如 `cyclohexanecarboselenothioic Se-acid`（见 P-65.1.5.1）和 `3-amido-2-imidodiphosphonic chloride`（见 P-67.2.3）。

### P-15.5.3 官能置换命名的范围

表 1.6 中给出的前缀和中缀根据描述以下置换的特定规则使用：

- **P-15.5.3.1** — 杂环母体氢化物中的置换
- **P-15.5.3.2** — 取代命名中作为后缀表达的特征基团中的置换
- **P-15.5.3.3** — 取代命名中作为前缀表达的特征基团中的置换
- **P-15.5.3.4** — 官能母体化合物中的置换

#### P-15.5.3.1 杂环母体氢化物中的置换

前缀用于修饰有限的一组母体氢化物，如下所示。pyran 见表 2.2，morpholine 见表 2.3，chromene、isochromene 和 xanthene 见表 2.8，chromane 和 isochromane 见表 3.1。

示例：
- `4H-thiopyran` (PIN)
- `4H-thiine`

#### P-15.5.3.2 取代命名中作为后缀表达的特征基团中的置换

后缀中的置换仅限于 -OO-、=S 和 -S-、=Se 和 -Se-、=Te 和 -Te-、=NH 和 =NNH₂ 以及这些词缀的任何组合（见表 1.6）。包含碳原子的后缀以及对应于磺酸和亚磺酸及其类似物的后缀通过中缀修饰。其他后缀通过前缀修饰。经官能置换修饰的后缀的示例和优先顺序分别见表 4.2 和 4.3（第 P-4 章）。

示例：
- `-C{O/S}H` → `thiocarboxy`（优选前缀）
- `=S` → `thioxo`；`sulfanylidene`（预选前缀）

#### P-15.5.3.4 官能母体化合物中的置换

官能置换用于通过下述 P-15.5.3.4.1 和 P-15.5.3.4.2 中的特定规则，以前缀和后缀修饰羧酸和含氧酸。它也用于修饰两个表示官能母体结构的保留名 urea 和 semicarbazone，如下述 P-15.5.3.4.3 所述。官能置换不用于置换酮、醇或衍生物（如缩醛和缩酮等）中的氧原子；建议改用系统名。

示例：
- `CH3-CS-CH3` → `propane-2-thione` (PIN)（不是 thioacetone）
- `C6H5-SH` → `benzenethiol` (PIN)（不是 thiophenol）

##### P-15.5.3.4.1

在一般命名中，一元羧酸的保留名可以通过前缀 peroxy、thio、seleno 和 telluro 修饰，以表示氧原子被置换原子 -OO-、-S- 或 =S、-Se- 或 =Se、-Te- 或 =Te 置换（见 P-65.1.4.1 和 P-65.1.5.2）。

示例：
- `CH3-CO-SH` → `thioacetic S-acid`；`ethanethioic S-acid` (PIN)
- `CH3-CH2-CS-OH` → `thiopropionic O-acid`；`propanethioic O-acid` (PIN)
- `C6H5-CS-SH` → `dithiobenzoic acid`；`benzenecarbodithioic acid` (PIN)

##### P-15.5.3.4.2

单核和多核含氧酸的名称根据 P-67 中描述的规则，用表 1.6 中列出的前缀和中缀修饰。

示例：
- `CH3-P(=NH)(OH)(SH)` → `P-methylphosphonimidothioic acid` (PIN)

##### P-15.5.3.4.3

P-66.1.6 和 P-68.3.1 中描述的开链多氮官能母体化合物的保留名通过前缀 'thio'、'seleno' 和 'telluro' 修饰。

示例：
- `H2N-CS-NH2` → `thiourea` (PIN；P-66.1.6.1.3)；`carbonothioic diamide`
- `H2N-NH-CSe-NH2` → `selenosemicarbazide`；`hydrazinecarboselenoamide` (PIN，见 P-68.3.1.2.4)

## P-15.6 缀合命名

### P-15.6.0 引言

缀合命名基本上基于缀合操作，通过该操作，通过在每个连接位点从每个组件减去相同数量的氢原子，形式上构造一个化合物。它传统上保留用于命名具有连接到开链组件的主基团的化合物，该开链组件也通过碳-碳键直接连接到环状组件。此方法可以在一般命名中用作取代命名的替代方法，但不推荐用于生成优选 IUPAC 名称（见 P-51.5）。名称已被修改（ref. 2），使缀合名称中位次的放置与本建议中建立的名称中位次的放置一致（见 P-14.3.2）。此处简要讨论 CAS 索引命名中使用的缀合命名的其他方面，包括其局限性（P-15.6.2）。

### P-15.6.1 名称的形成

#### P-15.6.1.1

名称通过组件名称的并置形成。环状组件的名称首先引用，后跟主特征基团所连接组件的系统名或保留名。

（原书注）当取代基存在于 ylmethanol 的环部分时，需要使用括号：
- 例如：`(2-chlorophenyl)methanol`（不是 2-chlorophenylmethanol）
- 例如：`(2,7-dimethoxynaphthalen-1-yl)methanol`

示例：
- `cyclohexanemethanol`；`cyclohexylmethanol` (PIN)
- `benzeneacetic acid`；`phenylacetic acid` (PIN)

#### P-15.6.1.2

必要时，侧链连接到环状组件的位置由放在环状组件名称之前的适当位次给出，除非引用环状组件的结构特征的位次（如杂原子和指示氢）已经存在；在这种情况下，位次跟在环状组件名称之后。由于开链组件必须在环状组件处终止，因此不需要给出其连接位次。侧链的碳原子用希腊字母表示，从主特征基团向环状组件方向；这些位次在名称中仅用于定位侧链上的其他取代基。特征基团的碳原子（在酸、醛、腈等中）在分配希腊字母位次时被省略。

示例：
- `naphthalene-2-propanol`；`3-(naphthalen-2-yl)propan-1-ol` (PIN)；`3-(2-naphthyl)propan-1-ol`
- `1,3-thiazole-2-acetic acid`；`(1,3-thiazol-2-yl)acetic acid` (PIN)
- `β-chloronaphthalene-2-propanol`；`2-chloro-3-(naphthalen-2-yl)propan-1-ol` (PIN)
- `5,6-dimethyl-2H-isoindole-2-acetic acid`；`(5,6-dimethyl-2H-isoindol-2-yl)acetic acid` (PIN)

#### P-15.6.1.3

在缀合命名中，对于所有目的，侧链被视为仅从主基团延伸到环状组件。任何其他链成员，即使是末端延伸侧链的，都作为取代基命名，适当的前缀和位次放在环状组件名称之前。

示例：
- `γ-methylnaphthalene-2-propanol`；`3-(naphthalen-2-yl)butan-1-ol` (PIN)；`3-(2-naphthyl)butan-1-ol`
- `α-propylbenzenepropanol`；`1-phenylhexan-3-ol` (PIN)

#### P-15.6.1.4

当环状组件带有至少两个相同的侧链时，倍增前缀 'di'、'tri' 等用于表示其数量；这些前缀放在侧链名称之前，侧链上的所有位次使用上标阿拉伯数字而不是撇号。

示例：
- `naphthalene-2,3-diacetic acid`；`2,2′-(naphthalene-2,3-diyl)diacetic acid` (PIN)
- `benzene-1,3,5-triacetic acid`；`2,2′,2′′-(benzene-1,3,5-triyl)triacetic acid` (PIN)
- `pyridine-2,3-di(decanoic acid)`；`10,10′-(pyridine-2,3-diyl)di(decanoic acid)` (PIN)

#### P-15.6.1.5

当不同的侧链连接到环状组件时：

(a) 选择包含主特征基团的链用于缀合法命名；或

(b) 如果存在多个含主特征基团的侧链，选择表达更多主特征基团数目的缀合名称。必要时，通过应用选择主链的优先顺序（见 P-44.3）来选择侧链。

示例：
- `2-(3-hydroxypropyl)quinoline-3-acetic acid`；`[2-(3-hydroxypropyl)quinolin-3-yl]acetic acid` (PIN)（羧酸优先于醇）
- `1-(2-carboxyethyl)naphthalene-2,3-diacetic acid`；`3-[2,3-bis(carboxymethyl)naphthalen-1-yl]propanoic acid` (PIN)

#### P-15.6.1.6

当侧链连接到两个不同的环状组件时，根据环和环系的优先顺序（见 P-44.2）选择优先环或环系。

示例：
- `β-cyclohexylnaphthalene-2-ethanol`（萘优先于环己烷）；`2-cyclohexyl-2-(naphthalen-2-yl)ethan-1-ol` (PIN)

### P-15.6.2 缀合命名的限制

在以下情况下不使用缀合命名：

(a) 双键连接开链组件与环系；

(b) 侧链中存在双键或杂原子；

(c) 侧链上有两个相同的特征基团，前提是不违反最大主特征基团数条件；

(d) 具有较高优先引用为主基团优先顺序的特征基团直接连接到环状组件；

(e) 与主基团相同种类的两个或多个特征基团位于环或环系上。

在上述情况下，必须使用正常的取代命名。

示例：
- `cyclopentylideneacetic acid` (PIN)
- `phenylcarbamic acid` (PIN)
- `2-cyclohexylhexanedioic acid` (PIN)
- `2-(hydroxymethyl)benzene-1,4-diol` (PIN)
- `β1,5-dihydroxybenzene-1,3-diethanol`
- `1-[3-hydroxy-5-(2-hydroxyethyl)phenyl]ethane-1,2-diol` (PIN)

### P-15.6.3 缀合名称构建的分析

> 注：PIN 是取代名称。

**示例 1：**

分析：
- 主基团：-OH → ol
- 母体：
  - 环：C₆H₆ → benzene（苯）
  - 链：CH₃-CH₂-CH₃ → propane（丙烷）
- 包括后缀的缀合母体：benzenepropanol
- 前缀：-CH₂-CH₂-OH
  - 前缀 -OH → hydroxy（羟基）
  - 组件：-CH₂-CH₃ → ethyl（乙基）
  - 前缀名称：2-hydroxyethyl

结合其他规则，此分析得出缀合名称：
- `4-(2-hydroxyethyl)benzenepropanol`
- `3-[4-(2-hydroxyethyl)phenyl]propan-1-ol` (PIN)

**示例 2：**

分析：
- 主基团：-CHO → carbaldehyde 或 al
- 母体：
  - 环：benzene（苯）
  - 链：heptane（庚烷）
- 包括后缀的缀合母体：benzeneheptanal
- 前缀：-CHO → formyl（甲酰基）

结合其他规则，此分析得出缀合名称：
- `3-formylbenzeneheptanal`
- `3-(7-oxoheptyl)benzaldehyde` (PIN)
