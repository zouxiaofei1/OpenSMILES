# P-67 单核和多核非碳酸及其官能置换类似物作为命名有机化合物的官能母体（完整中文翻译）

> 译自 IUPAC Blue Book 2013, "Nomenclature of Organic Chemistry: IUPAC Recommendations and Preferred Names 2013"
> Chapter P-6, Section P-67: Mononuclear and Polynuclear Noncarbon Acids and their Functional Replacement Analogues as Functional Parents for Naming Organic Compounds
> 原文页码: 697–730

**非碳酸含氧酸（noncarbon oxoacid）**中具有保留名的单核、双核和多核非碳酸含氧酸及其硫族（chalcogen）类似物，被用作母体结构来产生含碳化合物的名称。在本推荐中，这些化合物的名称均为**预选名（preselected name）**（见 P-12.2）。

## P-67.0 引言

具有保留名的单核、双核和多核非碳酸含氧酸及其硫族类似物，被用作母体结构来产生含碳化合物的名称。在本推荐中，这些化合物的名称均为预选名（见 P-12.2）。

非碳酸含氧酸的硫族类似物名称由**官能置换命名法（functional replacement nomenclature）**形成。这类命名法也用于创建衍生类别，例如酰卤（acid halide）和拟卤化物（pseudohalide）、酰胺（amide）、酰肼（hydrazide）和脒（amidine）。就官能置换而言，单核、双核和多核非碳酸并不构成一个均一组。单核含氧酸的名称由**中缀（infix）**修饰，但硅酸（silicic acid）、亚硝酸（nitrous acid）、硝酸（nitric acid）和卤素酸（halogen acid）除外。双核和多核非碳酸含氧酸的名称由**前缀（prefix）**修饰。

**官能类别命名法（functional class nomenclature）**用于产生酯、有机酸酐、含碳拟卤化物（如氰化物和异氰酸酯）以及酰胺、亚胺（imide）和酰肼的有机衍生物的名称。

首先讨论单核非碳酸含氧酸，然后讨论双核和多核非碳酸含氧酸，例如 `diphosphoric acid`（焦磷酸），(HO)₂P(O)–O–P(O)(OH)₂，其命名为酸而非酸酐，以及 `hypodiphosphoric acid`（连二磷酸），(HO)₂P(O)–P(O)(OH)₂。

考虑到无机化合物命名法（ref. 12），已实现系统化，该系统化限制了保留名的使用，也限制了在单核含氧酸名称上添加如 'hypo'、'ortho'、'iso' 等前缀以产生保留名的做法。然而，由单核、双核和多核含氧酸衍生的有机化合物的传统命名法得以保留。

关于碳酸、氰酸、双核和多核碳酸，见 P-65.2。

**本节的纲目：**

- **P-67.1** — 单核非碳酸含氧酸（mononuclear noncarbon oxoacids）
- **P-67.2** — 双核和多核非碳酸含氧酸（di- and polynuclear noncarbon oxoacids）

## P-67.1 单核非碳酸含氧酸

单核非碳酸含氧酸的保留名以以下元素为中心原子：N、P、As、Sb、Si、B、S、Se、Te、F、Cl、Br 和 I。它们被用作母体结构，也用于在具有优先被命名为母体化合物的类别存在时衍生前缀。这些母体结构具有作为预选名使用的传统名称——保留名（见 P-12.2）。它们也可以有系统的加成名或取代名，但这些名称不推荐用于生成预选名（见 IR-8，ref. 12）。

首先讨论官能置换命名法；其次讨论使用官能类别命名法形成酯和酸酐；最后描述使用前缀的取代命名法。讨论了 P-42 节中所述的含氧酸及其衍生物优选顺序的应用。本节以 aci-硝基化合物（aci-nitro compounds）的命名法结束，该类化合物被命名为次叠氮酸（azinic acid）的衍生物。

#### P-67.1.1.2 与中心原子相连的氢原子（可取代氢）对单核非碳酸含氧酸的取代

与中心原子相连且带有氢原子的酸可被有机基团取代，并由此形成优选 IUPAC 名称。

> **注**：曾提出另一种方法，将酸视为后缀（像 `sulfonic acid` 那样），从而得出如 `benzenephosphonic acid` 之类的名称。该建议已被否决，因为在酸具有两个可取代氢原子的情况下，需要使用额外的字母位次，从而产生不必要地更繁琐的名称。

示例：

- `C₂H₅–P(O)(OH)₂` → `ethylphosphonic acid` (PIN)（乙基膦酸；非 `ethanephosphonic acid`）
- `(C₂H₅)₂P(O)(OH)` → `diethylphosphinic acid` (PIN)（二乙基次膦酸；非 `P-ethylethanephosphinic acid`）
- `(C₆H₅)₂As(OH)` → `diphenylarsinous acid` (PIN)（二苯基次亚胂酸）
- `C₆H₅Sb(OH)₂` → `phenylstibonous acid` (PIN)（苯基亚锑酸）
- `(naphthalene-2,6-diyl)bis(phosphonous acid)` (PIN)（亚膦酸衍生物）

#### P-67.1.2.3 使用中缀的官能置换命名法通用方法

使用中缀的**官能置换命名法**（见 P-15.5）为以下类别生成官能类别名：酰卤和拟卤化物（叠氮化物、氰化物、异氰化物和异氰酸酯）、酰胺、酰肼，以及亚胺酸（imidic acid）、腙酸（hydrazonic acid）和氮化酸（nitridic acid）。硫族类似物也由中缀描述。

> **注**：优选 IUPAC 名称是由官能命名法修饰的保留名。中缀的使用仅限于 P-67.1.2.1 中列出的酸，并产生优选 IUPAC 名称。前缀按推荐用于 P-67.1.2.2 中列出的酸，并用于所有单核酸的一般命名法。取代名和由前缀修饰的名称仅在特殊场合使用（见 P-67.1.4.1.1.6 和 P-67.3.1）。

示例：

- `(C₆H₅)₂P–SH` → `diphenylphosphinothious acid` (PIN)（二苯基硫代次亚膦酸；非 `diphenylphosphanethiol`；也非 `diphenyl(sulfanyl)phosphane`）

##### P-67.1.2.3.1 描述 =O 和 –OH 被硫族类似物置换的中缀（按优选性递减顺序）：

(1) `-OO-`：**过氧**（peroxo）

(2) `-OS-` 或 `-SO-`：**硫代过氧**（thioperoxo）（类似地有硒代过氧 selenoperoxo、碲代过氧 telluroperoxo）

(3) `-SS-`：**二硫代过氧**（dithioperoxo）（类似地有二硒代过氧 diselenoperoxo、二碲代过氧 ditelluroperoxo）

(4) `-SSe-` 或 `-SeS-`：**硒硫代过氧**（selenothioperoxo）（其他混合硫族元素类似）

(5) `-S-` 或 `=S`：**硫代**（thio）

(6) `-Se-` 或 `=Se`：**硒代**（seleno）

(7) `-Te-` 或 `=Te`：**碲代**（telluro）

##### P-67.1.2.3.4 表示类别的前缀（按优选性递减顺序；卤化物同级但按字母顺序引用，拟卤化物同级但按字母顺序引用）：

(1) `-Br`：溴代（bromo）；`-Cl`：氯代（chloro）；`-F`：氟代（fluoro）；`-I`：碘代（iodo）

(2) `-N₃`：叠氮代（azido）；`-OCN`：氰酸根代（cyanato）；`-CN`：氰代（cyano）；`-NCO`：异氰酸根代（isocyanato）；`-NC`：异氰代（isocyano）；`-NCSe`：异硒氰酸根代（isoselenocyanato）；`-NCTe`：异碲氰酸根代（isotellurocyanato）；`-NCS`：异硫氰酸根代（isothiocyanato）；`-SeCN`：硒氰酸根代（selenocyanato）；`-TeCN`：碲氰酸根代（tellurocyanato）；`-SCN`：硫氰酸根代（thiocyanato）

(4) `-NH-NH₂`：肼代（hydrazido）

(5) `≡N`：氮化代（nitrido）

(6) `=NH`：亚氨基代（imido）

(7) `=NNH₂`：腙代（hydrazono）

> 注：在本源文本中，第 (3) 项氨基代（amido）在前缀表中缺失（编号由 (2) 直接跳到 (4)）；此处按源文保留其编号。

##### P-67.1.2.3.5 中缀与前缀的位置规则

在母体名称的 'ic acid' 或 'ous acid' 词尾之前标示合适的中缀（多于一个时按字母顺序），在元音前省略字母 'o'；但中缀 'thio'、'seleno'、'telluro' 和 'peroxo' 例外，在 'ic' 词尾之前照原样引用，不省略字母 'o'。必要时也可加入谐音字母 'o'。用倍增前缀 'di' 或 'tri' 倍增中缀不改变其在字母顺序中的位置。

在酸的名称之前标示合适的前缀（多于一个时按字母顺序）；不建议省略。用倍增前缀 'di' 或 'tri' 倍增前缀不改变其在字母顺序中的位置。

#### P-67.1.2.4 由官能置换命名法修饰的单核非碳酸含氧酸

P-67.1.2 中描述的预选名用于衍生有机化合物的优选 IUPAC 名称。只要具有保留名的含氧酸中至少还剩有一个 –OH 基团，经官能置换修饰的酸即归类为酸，并以类别名 'acid' 表示。

###### P-67.1.2.4.1.3 前缀 'cyanato' 与中缀 'cyanatido' 的特殊用法

当 –OCN 基团连接到单核非碳酸含氧酸的中心原子时，会形成酸酐连接（见 P-67.1.3.3）。为遵守类别优选顺序，该基团因此在官能置换命名法中用于命名酸；酸优先于酸酐。前缀 'cyanato'、'thiocyanato'、'selenocyanato' 和 'tellurocyanato'，见 P-65.2.2。

示例：

- `CH₃–P(O)(OCN)OH` → `methylphosphonocyanatidic acid` (PIN)（甲基氰酸根膦酸）
- `P(O)(OCN)₂OH` → `phosphorodicyanatidic acid` (PIN)（二氰酸根磷酸）
- `Si(OCN)(OH)₃` → `cyanatosilicic acid` (PIN)（氰酸根硅酸）

##### P-67.1.2.4.2 官能置换命名法的名称构造指南

名称 `phosphonous acid`、`phosphinous acid`、`phosphonic acid` 和 `phosphinic acid`（以及类似的砷、锑和氮酸）仅当 P、As 或 Sb 与氢原子、碳原子或母体氢化物的另一原子（如 N、As、Si）相连时方可使用。因此，`C₆H₅–P(O)Cl(OH)` 是 `phenylphosphonochloridic acid`（苯基氯代膦酸），而非 `chloro(phenyl)phosphinic acid`；`(C₅H₁₀N)–P(O)Cl(OH)` 是 `(piperidin-1-yl)phosphonochloridic acid`（（哌啶-1-基）氯代膦酸），而非 `chloro(piperidin-1-yl)phosphinic acid`；`Cl₂P(O)(OH)` 是 `phosphorochloridic acid`（氯代磷酸），而非 `chlorophosphonic acid`。

#### P-67.1.2.5 酰卤和拟卤化物

##### P-67.1.2.5.1

除硼酸和硅酸外，酰卤和拟卤化物的优选 IUPAC 名称通过将卤化物或拟卤化物的类别名加到酸的名称上形成。例外地，依照传统以及推荐的无机化合物命名法（ref. 12），由磷酸、硫酸、硒酸和碲酸衍生的、具有相同原子或基团的卤化物和拟卤化物，通过将类别名加到酰基名称 'phosphoryl'、'sulfuryl'、'sulfamoyl'、'selenonyl' 和 'telluronyl' 上来命名，而非加到酸本身的名称上。依据卤化物和拟卤化物的优选顺序，名称以较优类别为基础形成，如 P-67.1.2.1 所述。

由硼酸和硅酸衍生的酰卤和拟卤化物的优选 IUPAC 名称分别以母体氢化物名称 `borane` 和 `silane` 为基础形成。

- `(C₆H₅)₂P–Cl` → `diphenylphosphinous chloride` (PIN)（二苯基次亚膦酰氯）
- `(C₆H₅)₂Sb–NCO` → `diphenylstibinous isocyanate` (PIN)（二苯基次亚锑酰异氰酸酯）
- `C₆H₅–PCl₂` → `phenylphosphonous dichloride` (PIN)（苯基亚膦酰二氯化物）
- `C₆H₅–PBrCl` → `phenylphosphonous bromide chloride` (PIN)（苯基亚膦酰溴化氯化物；亦作 `phenylphosphonobromidous chloride`）
- `(C₆H₅)₂P(=N-C₆H₅)Cl` → `N,P,P-triphenylphosphinimidic chloride` (PIN)（N,P,P-三苯基次膦亚胺酰氯）
- `(CH₃–CH₂)₂P(S)Cl` → `diethylphosphinothioic chloride` (PIN)（二乙基硫代次膦酰氯）
- `C₆H₅–P(O)Cl₂` → `phenylphosphonic dichloride` (PIN)（苯基膦酰二氯化物）
- `CH₃–CH₂–P(O)[N(CH₃)₂]Cl` → `P-ethyl-N,N-dimethylphosphonamidic chloride` (PIN)（P-乙基-N,N-二甲基氨基膦酰氯）
- `(CH₃)₂N–P(O)(NCO)Cl` → `N,N-dimethylphosphoramidisocyanatidic chloride` (PIN)（N,N-二甲基氨基异氰酸根膦酰氯）
- `HP(O)(NCO)₂` → `phosphonic diisocyanate` (PIN)（膦酰二异氰酸酯）
- `P(=NH)(NCS)₃` → `phosphorimidic triisothiocyanate` (PIN)（亚胺磷酰三异硫氰酸酯）
- `(CH₃)₂PN₃` → `dimethylphosphinous azide` (PIN)（二甲基次亚膦酰叠氮化物）
- `SO₂(NCO)₂` → `sulfuryl diisocyanate` (PIN)（硫酰二异氰酸酯）
- `S(=N-CH₃)Cl₂` → `N-methylsulfurimidous dichloride` (PIN)（N-甲基亚胺亚硫酰二氯化物）

- `F–S(=NH)(NCO)` → `sulfurimidisocyanatidous fluoride` (PIN)（亚胺异氰酸根亚硫酸酰氟）
- `CH₃–NH–SO₂Cl` → `N-methylsulfamoyl chloride` (PIN)（N-甲基氨磺酰氯）

##### P-67.1.2.5.2

硼酸和硅酸的卤化物的优选 IUPAC 名称为取代名。

示例：

- `C₆H₅–B(Cl)(Br)` → `bromo(chloro)(phenyl)borane` (PIN)（溴（氯）（苯基）硼烷；亦作 `phenylboronic bromide chloride`、`phenylboronobromidic chloride`）
- `CH₃–SiCl₃` → `trichloro(methyl)silane` (PIN)（三氯（甲基）硅烷）
- `SiCl₄` → `tetrachlorosilane`（四氯化硅，预选名）；`silicon tetrachloride`（四氯化硅；非 `silicic tetrachloride`）

#### P-67.1.2.6 酰胺和酰肼

酰胺和酰肼通过官能类别命名法命名，即将相应酸名称中的 'acid' 一词替换为 'amide'（酰胺）或 'hydrazide'（酰肼）。硝酸和亚硝酸的酰胺和酰肼在 P-67.1.2.6.3 中讨论。硼酸和硅酸的酰胺和酰肼的优选 IUPAC 名称是例外（见 P-67.1.2.6.2），`azorous acid`、`azinous acid` 和 `azonous acid` 也是例外，它们是聚氮烷（polyazane）的名称。

##### P-67.1.2.6.1

当 (a) 相应酸中的所有 –OH 基团已被 –NH₂ 或 –NH-NH₂ 基团置换，且 (b) 酰胺或酰肼依据以下优选顺序成为主特征官能团时，酰胺和酰肼的优选 IUPAC 名称以类别名 'amide' 或 'hydrazide' 表示：

**Br, Cl, F, I, N₃, CN, NC, NCO, ONC, NH₂（amide 酰胺）, NH-NH₂（hydrazide 酰肼）**

> **注**：此顺序与 CAS 所用的顺序不尽相同（CAS 中酰胺紧随卤素之后、位于拟卤素之前），但它与 P-41 中化合物类别的顺序一致。

氮原子上的取代基由斜体字母位次表示，如 N（必要时加撇和双撇），此外还有斜体字母位次 'P'、'As' 和 'Sb'。

表示酰肼的位次为 1 和 2，必要时加撇和双撇。

示例：

- `[(CH₃)₂N]₃PO` → `hexamethylphosphoric triamide` (PIN)（六甲基磷酸三酰胺；亦作 `hexamethylphosphoramide`；不使用 `phosphoric tris(dimethylamide)`）
- `(CH₃)₂P(O)[N(CH₃)₂]` → `N,N,P,P-tetramethylphosphinic amide` (PIN)（N,N,P,P-四甲基次膦酰胺；非 `dimethylphosphinic dimethylamide`）
- `C₆H₅–P(O)(NHCH₃)₂` → `N,N′-dimethyl-P-phenylphosphonic diamide` (PIN)（N,N′-二甲基-P-苯基膦酸二酰胺；不使用 `phenylphosphonic bis(methylamide)`）
- `C₆H₅–P(S)[N(CH₃)₂]₂` → `N,N,N′,N′-tetramethyl-P-phenylphosphonothioic diamide` (PIN)（N,N,N′,N′-四甲基-P-苯基硫代膦酸二酰胺）
- `C₆H₅–Sb(S)[N(CH₃)₂][N(CH₂CH₃)₂]` → `N,N-diethyl-N′,N′-dimethyl-Sb-phenylstibonothioic diamide` (PIN)（N,N-二乙基-N′,N′-二甲基-Sb-苯基硫代锑酸二酰胺）
- `(CH₃)₂N–P(O)Cl₂` → `N,N-dimethylphosphoramidic dichloride` (PIN)（N,N-二甲基氨基磷酸酰二氯化物）
- `N,N-diethyl-N′,N′-dimethyl-As-phenylarsonothioic diamide` (PIN)（N,N-二乙基-N′,N′-二甲基-As-苯基硫代胂酸二酰胺）
- `1,1′,1′′-trimethylphosphoric trihydrazide` (PIN)（1,1′,1′′-三甲基磷酸三酰肼）
- `2,2,2′,2′,2′′,2′′-hexamethylphosphorothioic trihydrazide` (PIN)（2,2,2′,2′,2′′,2′′-六甲基硫代磷酸三酰肼；不使用 `phosphorothioic tris(2,2-dimethylhydrazide)`）
- `N-methylsulfurous diamide` (PIN)（N-甲基亚硫酸二酰胺）
- `N,N-dimethylsulfuric diamide` (PIN)（N,N-二甲基硫酸二酰胺；亦作 `N,N-dimethylsulfamide`）
- `pentamethylsulfurimidous diamide` (PIN)（五甲基亚胺亚硫酸二酰胺）
- `CH₃–NH–S(O)(=N-CH₃)–Br` → `N,N′-dimethylsulfuramidimidic bromide` (PIN)（N,N′-二甲基氨基亚胺硫酸酰溴）
- `N,N,N′,N′-tetramethyl-N′′-phenylsulfurimidic diamide` (PIN)（N,N,N′,N′-四甲基-N′′-苯基亚胺硫酸二酰胺）

##### P-67.1.2.6.2

硼酸和硅酸的酰胺和酰肼的预选名是基于预选母体氢化物名称 `borane` 和 `silane` 的取代名。

示例：

- `H₂B–NH₂` → `boranamine`（硼烷胺；名称由预选名 `borane` 派生；非 `borinic amide`）
- `B(NH₂)₃` → `boranetriamine`（硼烷三胺；名称由预选名 `borane` 派生；非 `boric triamide`）
- `1,1′,1′′-boranetriyltrihydrazine`（1,1′,1′′-硼烷三基三肼；名称由预选名 `borane` 派生；非 `boric trihydrazide`）
- `Si(NH₂)₄` → `silanetetramine`（硅烷四胺；名称由预选名 `silane` 派生；非 `silicic tetramide`）
- `Si(NH-NH₂)₄` → `1,1′,1′′,1′′′-silanetetrayltetrahydrazine`（1,1′,1′′,1′′′-硅烷四基四肼；名称由预选名 `silane` 派生；非 `silicic tetrahydrazide`）

##### P-67.1.2.6.3 硝酸和亚硝酸的酰胺和酰肼

硝胺（nitramine）是硝酸的酰胺（见 ref. 23）。该类由 'nitramide'（硝酰胺，即 nitric amide 的缩写形式）、NO₂–NH₂ 组成，其衍生物名称由取代形成。亚硝胺（nitrosamine）是亚硝酸的酰胺，NO–NH₂（见 ref. 23）；其衍生物名称由取代形成。硝酸和亚硝酸是预选名，见 P-12。

(I)（硝酸酰肼）与 (II)（亚硝酸酰肼）的结构式分别对应于硝酸酰肼（nitric hydrazide）与亚硝酸酰肼（nitrous hydrazide）。

类似地，硝酸酰肼（I）和亚硝酸酰肼（II）是预选名，用作生成优选 IUPAC 名称的母体结构。

硝酸和亚硝酸的酰胺和酰肼的优选 IUPAC 名称现系统地基于硝酸酰胺（nitric amide）和亚硝酸酰胺（nitrous amide）及相应酰肼，依据类别优选顺序命名，而非作为硝基胺和亚硝基胺命名；后者名称可用于一般命名法。

示例：

- `ON–N(CH₂-CH₂-CH₃)₂` → `dipropylnitrous amide` (PIN)（二丙基亚硝酸酰胺）；`N-nitroso-N-propylpropan-1-amine`（N-亚硝基-N-丙基丙-1-胺）
- `butyl(ethyl)nitrous amide` (PIN)（丁基（乙基）亚硝酸酰胺）；`N-ethyl-N-nitrosobutan-1-amine`（N-乙基-N-亚硝基丁-1-胺）
- `(chloromethyl)(methyl)nitramide` (PIN)（（氯甲基）（甲基）硝酰胺）；`1-chloro-N-methyl-N-nitromethanamine`（1-氯-N-甲基-N-硝基甲胺）
- `methyl(nitro)nitramide` (PIN)（甲基（硝基）硝酰胺）；`N,N-dinitromethanamine`（N,N-二硝基甲胺）
- `N′-hexylidenenitrous hydrazide` (PIN)（N′-己叉基亚硝酸酰肼）

### P-67.1.3 单核非碳酸含氧酸的盐、酯和酸酐

本节讨论的方法适用于所有单核含氧酸，无论它们是否具有保留名，或使用中缀或前缀的名称。

**本小节纲目：**

- **P-67.1.3.1** — 盐
- **P-67.1.3.2** — 酯
- **P-67.1.3.3** — 酸酐

#### P-67.1.3.1 单核非碳酸含氧酸的盐

单核非碳酸含氧酸的中性盐通过先引用阳离子、后引用作为单独一个词的阴离子名称来命名。阴离子名称通过将 'ic acid' 词尾改为 'ate'、'ous acid' 词尾改为 'ite' 形成。不同的阳离子按字母顺序引用。

示例：

- `Na₂(CH₃-PO₂)` → `disodium methylphosphonite` (PIN)（甲基亚膦酸二钠）
- `K[(CH₃)₂As(O)O]` → `potassium dimethylarsinate` (PIN)（二甲基胂酸钾）

多碱价单核非碳酸含氧酸的酸式盐以与中性盐相同的方式命名，剩余的酸式氢原子由 'hydrogen'（或按需 'dihydrogen' 等）一词表示，插在阳离子名称和阴离子名称之间，并用空格隔开。

> **注**：在无机化学命名法（IR-8.4，ref. 12）中，'hydrogen' 一词直接写在阴离子名称之前，不加空格，以表示它是阴离子的一部分。

示例：

- `Na⁺ B(OH)(OCN)(O⁻)` → `sodium hydrogen borocyanatidate`（氰酸根硼酸钠氢）

#### P-67.1.3.2 单核非碳酸含氧酸的酯

单核非碳酸酸的酯以与有机酸酯相同的方式命名（见 P-65.6.3.2）。烷基、芳基等作为单独的词引用，多于一个时按字母数字顺序排列，后接相应阴离子的名称。多元酸的部分酸酯通过将烷基、芳基等作为单独的词引用（多于一个时按字母数字顺序），后接 'hydrogen' 一词（必要时带合适的倍增前缀，也作为单独的词引用），再接相应阴离子的名称来命名。部分酸酯的盐通过先引用阳离子名称、后引用有机基团名称来命名；剩余的酸式基团按上述方法用 'hydrogen' 一词表示。单核非碳酸含氧酸硫族类似物的酯的结构特异性由合适的斜体元素符号 O、S、Se 和 Te 提供，必要时置于基团名称之前。

示例：

- `CH₃-CH₂-CH₂-CH₂-CH₂-O-NO` → `pentyl nitrite` (PIN)（亚硝酸戊酯）
- `CH₃-S-NO₂` → `S-methyl thionitrate` (PIN)（S-甲基硫代硝酸酯）
- `(C₆H₅)₂P-O-CH₃` → `methyl diphenylphosphinite` (PIN)（二苯基亚膦酸甲酯）
- `CH₃-P(Cl)(S-CH₂-CH₃)` → `ethyl methylphosphonochloridothioite` (PIN)（甲基氯代硫代膦酸乙酯）
- `CH₃-P(NH-CH₃)(OCH₃)` → `methyl N,P-dimethylphosphonamidite` (PIN)（N,P-二甲基氨基亚膦酸甲酯）
- `P(O-CH₃)₃` → `trimethyl phosphite` (PIN)（亚磷酸三甲酯）
- `P(Cl)[N(CH₃)₂](O-CH₃)` → `methyl N,N-dimethylphosphoramidochloridite` (PIN)（N,N-二甲基氨基氯代亚磷酸甲酯）
- `P(O)(O-CH₃)₃` → `trimethyl phosphate` (PIN)（磷酸三甲酯）
- `P(O)(O-C₂H₅)(O-CH₃)(O-C₆H₅)` → `ethyl methyl phenyl phosphate` (PIN)（磷酸乙基甲基苯基酯）
- `P(O)(O-CH₃)₂(OH)` → `methyl dihydrogen phosphate` (PIN)（磷酸二氢甲酯）
- `C₆H₅-HAs(S)(O-CH₃)` → `O-methyl phenylarsinothioate` (PIN)（O-甲基苯基硫代次胂酸酯）
- `CH₃-O-P(O)(OH)-O⁻ Na⁺` → `sodium methyl hydrogen phosphate` (PIN)（磷酸甲基氢钠）
- `HP(O)(O-CH₃)₂` → `dimethyl phosphonate` (PIN)（膦酸二甲酯）
- `(CH₃-CH₂)₂P(S)(S-CH₂-CH₃)` → `ethyl diethylphosphinodithioate` (PIN)（二乙基二硫代次膦酸乙酯）
- `(CH₃)₂As(O)(S-CH₃)` → `S-methyl dimethylarsinothioate` (PIN)（S-甲基二甲基硫代胂酸酯）
- `CH₃-P(O)(O-CH₂-CH₃)₂` → `diethyl methylphosphonate` (PIN)（甲基膦酸二乙酯）
- `C₆H₅-P(O)(O-CH₃)(S-CH₂-CH₃)` → `S-ethyl O-methyl phenylphosphonothioate` (PIN)（S-乙基 O-甲基苯基硫代膦酸酯）
- `C₆H₅-P(O)(Cl)(O-CH₃)` → `methyl phenylphosphonochloridate` (PIN)（苯基氯代膦酸甲酯）
- `(CH₃)₂N-P(O)(O-CH₃)₂` → `dimethyl N,N-dimethylphosphoramidate` (PIN)（N,N-二甲基氨基磷酸二甲酯）
- `(CH₃-CH₂)₂N-P(O)(NCS)(O-CH₂-CH₃)` → `ethyl N,N-diethylphosphoramid(isothiocyanatidate)` (PIN)（N,N-二乙基氨基（异硫氰酸根代）磷酸乙酯）
- `As(O)(F)(O-CH₃)₂` → `dimethyl arsorofluoridate` (PIN)（氟代砷酸二甲酯）
- `Sb(O)(F)₂(S-CH₃)` → `S-methyl stiborodifluoridothioate` (PIN)（S-甲基二氟代硫代锑酸酯）
- `(CH₃)₂B-O-C₆H₅` → `phenyl dimethylborinate` (PIN)（二甲基硼酸苯酯）
- `CH₃-O-SO₂-OH` → `methyl hydrogen sulfate` (PIN)（硫酸氢甲酯）
- `C₆H₅-O-F` → `phenyl hypofluorite` (PIN)（次氟酸苯酯）
- `CH₃-S-Cl` → `methyl thiohypochlorite` (PIN)（硫代次氯酸甲酯）
- `CH₃-CO-CH₂-CH₂-O-BrO` → `3-oxobutyl bromate` (PIN)（3-氧代丁基溴酸酯）
- `methyl bis(1-hydroxybutan-2-yl)borinate` (PIN)（双（1-羟基丁-2-基）硼酸甲酯）
- `Si(S-CH₃)₃(O-CH₂-CH₃)` → `O-ethyl S,S,S-trimethyl trithiosilicate` (PIN)（O-乙基 S,S,S-三甲基三硫代硅酸酯）
- `S,S′-diethyl O,O′-dimethyl P,P′-(ethane-1,2-diyl)bis(phosphonothioate)` (PIN)（P,P′-（乙烷-1,2-二基）双（硫代膦酸）S,S′-二乙基 O,O′-二甲基酯）

#### P-67.1.3.3 单核非碳酸含氧酸的酸酐

由后缀命名的酸与 P-67.1.1 所述的单核非碳酸含氧酸之间形成的中性酸酐，以与由羧酸和以后缀命名的硫磺酸（见 P-65.7）衍生的酸酐相同的方式命名。酸的名称按字母顺序引用，后接类别名 'anhydride'，前面冠以表示酸酐连接数目的数字词头（不使用数字前缀 mono）；此类名称产生优选 IUPAC 名称。由酰基取代磷、砷或锑单核含氧酸（词尾改为 'ate'）形成的名称可用于一般命名法。卤素含氧酸与以词尾表达的羧酸和硫磺酸形成酸酐。

酸性酸酐按 P-67.3.1 所述以较优酸为母体命名，或使用系统的取代命名法命名。

示例：

- `(CH₃)₂B-O-CO-CH₃` → `acetic dimethylborinic anhydride` (PIN)（乙酸二甲基次硼酸酐）
- `CH₃-CO-O-As(O)(CH₃)₂` → `acetic dimethylarsinic anhydride` (PIN)（乙酸二甲基次胂酸酐；亦作 `acetyl dimethylarsinate`）
- `B(O-CO-CH₃)₃` → `acetic boric trianhydride` (PIN)（乙酸硼酸三酸酐）
- `[(CH₃)₂CH]₂Sb-S-C(S)-N(CH₂-CH₃)₂` → `diethylcarbamothioic di(propan-2-yl)stibinous thioanhydride` (PIN)（二乙基氨基甲硫羟酸二（丙-2-基）次亚锑酸硫代酸酐）
- `C₆H₅-CO-O-I` → `benzoic hypoiodous anhydride` (PIN)（苯甲酸次碘酸酐）
- `(CH₃)₂B-O-O-B(CH₃)₂` → `dimethylborinic peroxyanhydride` (PIN)（二甲基次硼酸过氧酸酐）
- `B(OCN)₃` → `boric cyanic trianhydride` (PIN)（硼酸氰酸三酸酐）
- `CH₃-HP(O)(OCN)` → `cyanic methylphosphinic anhydride` (PIN)（氰酸甲基次膦酸酐）

### P-67.1.4 由单核非碳酸含氧酸衍生的取代基前缀基团

**本小节纲目：**

- **P-67.1.4.1** — 由单核氮、磷、砷和锑酸衍生的取代基基团
- **P-67.1.4.2** — 由硼酸和硅酸衍生的取代基基团
- **P-67.1.4.3** — 由硝酸和亚硝酸衍生的取代基基团
- **P-67.1.4.4** — 由硫族酸衍生的取代基基团
- **P-67.1.4.5** — 由卤素酸衍生的取代基基团

#### P-67.1.4.1 由单核氮、磷、砷和锑酸衍生的取代基基团

**本小节纲目：**

- **P-67.1.4.1.1** — 预选前缀
- **P-67.1.4.1.2** — 一般命名法的取代基基团
- **P-67.1.4.1.3** — 复合和复杂取代基基团

##### P-67.1.4.1.1 预选前缀

由单核非碳酸含氧酸衍生的取代基前缀基团具有与简单或复合酰基相对应的保留名和系统名。预选前缀按以下优选顺序依次应用形成，直至作出决定：

###### P-67.1.4.1.1.1 由单核非碳酸含氧酸衍生的取代基基团的保留名

少数表示一价酸性基团的名称被保留。当未被取代时，或对于硫族类似物当官能置换引入的硫族原子位置未知或无需指明其位置时，这些名称是预选名：硫族原子由前缀表达。

| 酸 | 派生的预选前缀 |
|----|----------------|
| –N(O)(OH)₂ | `azono`（叠氮酸根，预选前缀） |
| –P(O)(OH)₂ | `phosphono`（膦酸根，预选前缀） |
| –As(O)(OH)₂ | `arsono`（胂酸根，预选前缀） |
| –Sb(O)(OH)₂ | `stibono`（锑酸根，预选前缀） |
| –P(O)(OH)(SH) 或 –P(S)(OH)₂ | `thiophosphono`（硫代膦酸根，预选前缀） |
| –P(S)(SH)₂ | `trithiophosphono`（三硫代膦酸根，预选前缀） |

###### P-67.1.4.1.1.2 由单核非碳酸含氧酸衍生的取代基的基本酰基

酰基前缀基团通过从具有通式 E(=O)(OH)₃、R–E(=O)(OH)₂ 或 R,R′E(=O)OH（其中 R 和 R′ = H 或有机基团）的单核非碳酸含氧酸中除去所有 –OH 基团形成。由酸（无论是否经官能置换修饰）的名称除去所有羟基或其硫族类似物而派生的酰基基团的名称，通过将酸名称中的 'ic acid' 词尾改为 'oyl' 形成，但 'nitroryl' –N(O)<、'phosphoryl' –P(O)<、'arsoryl' –As(O)< 和 'stiboryl' –Sb(O)< 除外。以此方式形成的前缀为预选前缀。例如，基团 'phosphoryl' –P(O)< 由磷酸 P(O)(OH)₃、或硫代磷酸 S-酸 P(O)(OH)₂(SH)、或二硫代磷酸 S,S-酸 P(O)(SH)₂(OH)、或三硫代磷酸 S,S,S-酸 P(O)(SH)₃ 派生。

前缀 'nitroryl'（非 `azoryl`）用于酰基 –N(O)<，由假想的硝酸 N(O)(OH)₃ 派生，自 1993 年起即被推荐（见 R-3.3，ref. 2）。

| 酸 | 派生的预选前缀 |
|----|----------------|
| N(O)(OH)₃ `nitroric acid`（假想的，预选名） | –N(O)< `nitroryl`（预选前缀） |
| P(O)(OH)₃ `phosphoric acid`（预选名） | –P(O)< `phosphoryl`（预选前缀） |
| As(O)(OH)₃ `arsoric acid`（预选名；非 `arsenic acid`） | –As(O)< `arsoryl`（预选前缀；非 `arsenyl`） |
| Sb(O)(OH)₃ `stiboric acid`（预选名；非 `antimonic acid`） | –Sb(O)< `stiboryl`（预选前缀；非 `antimonyl`） |
| NH(O)(OH)₂ `azonic acid`（预选名） | NH(O)< `azonoyl`（预选前缀） |
| NH₂(O)(OH) `azinic acid`（预选名） | NH₂(O)– `azinoyl`（预选前缀） |
| PH(O)(OH)₂ `phosphonic acid`（预选名） | PH(O)< `phosphonoyl`（预选前缀） |
| PH₂(O)(OH) `phosphinic acid`（预选名） | PH₂(O)– `phosphinoyl`（预选前缀；非 `phosphinyl`） |
| AsH(O)(OH)₂ `arsonic acid`（预选名） | AsH(O)< `arsonoyl`（预选前缀） |
| AsH₂(O)OH `arsinic acid`（预选名） | AsH₂(O)– `arsinoyl`（预选前缀；非 `arsinyl`） |
| SbH(O)(OH)₂ `stibonic acid`（预选名） | SbH(O)< `stibonoyl`（预选前缀） |
| SbH₂(O)OH `stibinic acid`（预选名） | SbH₂(O)– `stibinoyl`（预选前缀） |

###### P-67.1.4.1.1.3 由单核非碳酸含氧酸衍生的取代基本酰基的名称

取代基本酰基的名称直接由 P-67.1.4.1.1.2 所述方法生成的酸形成。酰基的优选前缀名是那些由酸的优选 IUPAC 名称派生的名称。不允许通过 P-67.1.4.1.2 中所述的拼接（concatenation）方法向酰基添加氢原子。

| 酸 | 派生的优选前缀 |
|----|----------------|
| CH₃–P(O)(OH)₂ `methylphosphonic acid` (PIN) | CH₃–P(O)< `methylphosphonoyl`（优选前缀） |
| CH₃–CH₂–SbH(O)OH `ethylstibinic acid` (PIN) | CH₃–CH₂–SbH(O)– `ethylstibinoyl`（优选前缀） |
| C₆H₅–As(CH₃)(O)OH `methyl(phenyl)arsinic acid` (PIN) | C₆H₅–As(CH₃)(O)– `methyl(phenyl)arsinoyl`（优选前缀） |

###### P-67.1.4.1.1.4 由官能置换命名法修饰的单核非碳酸含氧酸衍生的酰基的名称

优选 IUPAC 前缀按 P-65.2.1.5 中针对由官能置换命名法中的中缀和前缀修饰的碳酸衍生的酰基所指示的方法形成。表 1.6 中列出并在 P-65.1.2.3 中引用的所有中缀和前缀均被允许。应用于 B、N、P、As 和 Sb 单核非碳酸含氧酸时，该方法包括先在酸中实现官能置换，然后除去所有剩余的 –OH 基团。预选名使用中缀来表示官能置换。使用前缀实现官能置换的名称可用于一般命名法。

| 酸 | 派生的预选或优选前缀 |
|----|----------------------|
| P(S)(OH)₃ `phosphorothioic O,O,O-acid`（预选名） | >P(S)– `phosphorothioyl`（预选前缀）<br>`thiophosphoric O,O,O-acid` → `thiophosphoryl` |

| Sb(=NNH₂)(OH)₃ `stiborohydrazonic acid`（预选名） | >Sb(=NNH₂)– `stiborohydrazonoyl`（预选前缀）<br>`hydrazonostiboric acid` → `hydrazonostiboryl` |
| NH(S)(OH)₂ `azonothioic acid`（预选名） | >NH(S)– `azonothioyl`（预选前缀）<br>`thioazonic acid` → `thioazonoyl` |
| PH₂(=NH)(OH) `phosphinimidic acid`（预选名） | –PH₂(=NH) `phosphinimidoyl`（预选前缀）<br>`imidophosphinic acid` → `imidophosphinoyl` |
| (CH₃)₂P(Se)(OH)₂ `dimethylphosphinoselenoic acid` (PIN) | (CH₃)₂P(Se)– `dimethylphosphinoselenoyl`（优选前缀）<br>`dimethyl(selenophosphinic acid)` → `dimethyl(selenophosphinoyl)` |
| C₆H₅–P(O)Cl(OH) `phenylphosphonochloridic acid` (PIN) | C₆H₅–P(O)(Cl)– `phenylphosphonochloridoyl`（优选前缀）<br>`phenyl(chlorophosphonic acid)` → `phenyl(chlorophosphonoyl)` |
| P(≡N)(OH)₂ `phosphoronitridic acid`（预选名） | >P(≡N)– `phosphoronitridoyl`（预选前缀）<br>`nitridophosphoric acid` → `nitridophosphoryl` |
| P(=NH)(NHNH₂)(OH)₂ `phosphorohydrazidimidic acid`（预选名） | >P(=NH)(NHNH₂) `phosphorohydrazidimidoyl`（预选前缀）<br>`hydrazidimidophosphoric acid` → `hydrazidimidophosphoryl` |
| P(O)Cl₂(OH) `phosphorodichloridic acid`（预选名） | P(O)(Cl)₂– `phosphorodichloridoyl`（预选前缀）<br>`dichlorophosphoric acid` → `dichlorophosphoryl` |
| (CH₃)₂N–P(O)(OH)₂ `N,N-dimethylphosphoramidic acid` (PIN) | (CH₃)₂N–P(O)< `N,N-dimethylphosphoramidoyl`（优选前缀）<br>`(dimethylamido)phosphoric acid` → `(dimethylamido)phosphoryl` |
| P(O)(OH)₂(OOH) `phosphoroperoxoic acid`（预选名） | >P(O)(OOH) `phosphoroperoxoyl`（预选前缀）<br>`peroxyphosphoric acid` → `(hydroperoxy)phosphoryl`、`peroxyphosphoryl` |
| P(O)(OH)₂(OSH) 或 P(O)(OH)₂(SOH) `phosphoro(thioperoxoic) acid`（预选名） | >P(O)(OSH) 或 >P(O)(SOH) `phosphoro(thioperoxoyl)`（预选前缀）<br>`(thioperoxy)phosphoric acid` → `(thiohydroperoxy)phosphoryl` |

###### P-67.1.4.1.1.5 被羟基或其硫族和过氧类似物取代的酰基的优选或预选前缀的名称

**拼接**（concatenation）是重新引入基团及其硫族类似物到取代基基团或未在官能置换命名法中作为中缀处理的基团（如 '-OR'、'-SR' 等）中的推荐方法。重要的是要遵守拼接程序，即仅使用酰基的加成操作。允许的酰基有：上述 P-67.1.4.1.1.2 中描述的基本酰基、上述 P-67.1.4.1.1.3 中描述的取代基本酰基，以及上述 P-67.1.4.1.1.4 中描述的经官能置换修饰的酰基。不允许取代上述 P-67.1.4.1.1.2 中基本酰基中与中心原子相连的氢原子（可取代氢）来生成优选 IUPAC 名称。不推荐用此方法生成上述 P-67.1.4.1.1.1 中的任何前缀。

示例：

- `–NH(O)(OH)` → `hydroxyazonoyl`（羟基叠氮酰基，预选前缀）
- `–P(Se)(OCH₃)₂` → `dimethoxyphosphoroselenoyl`（二甲氧基硒代磷酰，优选前缀）；亦作 `dimethoxy(selenophosphoryl)`
- `–P(O)(OH)(SH)` → `hydroxy(sulfanyl)phosphoryl`（羟基（硫基）磷酰，预选前缀）
- `–P(O)(SH)₂` → `bis(sulfanyl)phosphoryl`（双（硫基）磷酰，预选前缀）
- `–PH(O)(SeH)` → `selanylphosphonoyl`（硒烷基磷酰，预选前缀）
- `–PH(S)(SH)` → `sulfanylphosphonothioyl`（硫基硫代磷酰，预选前缀）；亦作 `sulfanyl(thiophosphonoyl)`
- `>P(O)(OSH)` → `(sulfanyloxy)phosphoryl`（（硫基氧基）磷酰，预选前缀）；亦作 `(SO-thiohydroperoxy)phosphoryl`
- `>P(S)(SOH)` → `(hydroxysulfanyl)phosphorothioyl`（（羟基硫基）硫代磷酰，预选前缀）；亦作 `(OS-thiohydroperoxy)phosphorothioyl`
- `CH₃–P(O)(OH)–` → `hydroxy(methylphosphonoyl)`（羟基（甲基磷酰），优选前缀）
- `4,4′-(hydroxyphosphoryl)dibenzoic acid` (PIN)（4,4′-（羟基磷酰基）二苯甲酸）

###### P-67.1.4.1.1.6 由单核非碳酸含氧酸衍生的基团的取代名

基于母体氢化物 BH₃、PH₃、AsH₃、SbH₃、PH₅、AsH₅、SbH₅ 的取代命名法用于生成无法通过 P-67.1.4.1.1.1 至 P-67.1.4.1.1.5 的方法及其相应 As 和 Sb 酸生成酰基名称的取代基基团的名称。它也用于表示不同类型的自由价，例如 'ylidene' 型而非在由标准 (b) 和 (d) 中的酸衍生的取代基基团中观察到的 'diyl' 型。

示例：

- `–P(OH)₂` → `dihydroxyphosphanyl`（二羟基磷烷基，预选前缀）
- `–AsH(OH)` → `hydroxyarsanyl`（羟基砷烷基，预选前缀）
- `–AsHCl` → `chloroarsanyl`（氯代砷烷基，预选前缀）
- `–P(NH₂)₂` → `diaminophosphanyl`（二氨基磷烷基，预选前缀）
- `>Sb(OH)` → `hydroxystibanediyl`（羟基锑烷二基，预选前缀）
- `=P(OH)` → `hydroxyphosphanylidene`（羟基磷烷亚基，预选前缀）
- `=B(O-CH₃)` → `methoxyboranylidene`（甲氧基硼烷亚基，优选前缀）
- `–P(O-CH₃)₂` → `dimethoxyphosphanyl`（二甲氧基磷烷基，优选前缀）
- `=P(O)(OH)` → `hydroxy(oxo)-λ⁵-phosphanylidene`（羟基（氧代）-λ⁵-磷烷亚基，预选前缀）
- `=As(O)(OCH₃)` → `methoxy(oxo)-λ⁵-arsanylidene`（甲氧基（氧代）-λ⁵-砷烷亚基，优选前缀）
- `=N(O)OH` → `hydroxy(oxo)-λ⁵-azanylidene`（羟基（氧代）-λ⁵-氮烷亚基，预选前缀；即 aci-硝基，见 P-67.1.6）
- `4-[hydroxy(oxo)-λ⁵-azanylidene]cyclohexane-1-carboxylic acid` (PIN)（4-[羟基（氧代）-λ⁵-氮烷亚基]环己烷-1-甲酸）；`4-aci-nitrocyclohexane-1-carboxylic acid`（4-aci-硝基环己烷-1-甲酸；见 aci-硝基化合物，P-67.1.6）
- `–P=O` → `oxophosphanyl`（氧代磷烷基，预选前缀）
- `–P(O)₂` → `dioxo-λ⁵-phosphanyl`（二氧代-λ⁵-磷烷基，预选前缀）
- `–Sb=O` → `oxostibanyl`（氧代锑烷基，预选前缀）

##### P-67.1.4.1.2 一般命名法的取代基基团

前缀 'hydro' 可通过拼接加入，但仅可用于一般命名法。

示例：

- `>PH(O)` → `hydrophosphoryl`（氢代磷酰）；`phosphonoyl`（预选前缀）
- `>PH(S)` → `hydro(thiophosphoryl)`（氢代（硫代磷酰））；`phosphonothioyl`（预选前缀）

##### P-67.1.4.1.3 复合和复杂取代基基团

如果含 B、N、P、As 或 Sb 的基团通过氧或其他硫族原子或氮原子连接到某一化合物，而该化合物还含有另一个在引用为主基团方面优先于含 B、N、P、As 或 Sb 基团的取代基，则该含 B、N、P、As 或 Sb 的基团由复合或复杂前缀命名，该前缀由上述前缀构建，并按各组分在化合物中出现的顺序排列。

示例：

- `(HO)₂P(O)-O-CH₂-COOH` → `(phosphonooxy)acetic acid` (PIN)（（膦酸根氧基）乙酸）
- `(CH₃O)₂P(O)-S-CH₂-CH₂-COOH` → `3-[(dimethoxyphosphoryl)sulfanyl]propanoic acid` (PIN)（3-[（二甲氧基磷酰基）硫基]丙酸）
- `(HO)(HS)P(S)-NH-CH₂-CH₂-COOH` → `3-{[hydroxy(sulfanyl)phosphorothioyl]amino}propanoic acid` (PIN)（3-{[羟基（硫基）硫代磷酰基]氨基}丙酸）

#### P-67.1.4.2 由硼酸和硅酸衍生的取代基基团

由硼和硅单核酸及其类似物衍生的取代基基团通过取代母体氢化物名称 'borane' 和 'silane' 形成。名称 `borono`（用于 –B(OH)₂）被保留，是预选名。名称 `boryl` 曾用于取代基基团 H₂B–，现以 `boranyl` 作为预选名，因此不得用于由硼酸除去全部三个 –OH 基团而派生的前缀基团。

示例：

- `–B(OH)₂` → `borono`（预选前缀）
- `–BH₂` → `boranyl`（预选前缀；非 `boryl`）
- `>BH` → `boranediyl`（预选前缀；非 `boronoyl`）
- `–B<` → `boranetriyl`（预选前缀；非 `boryl`）
- `=BH` → `boranylidene`（预选前缀；非 `boronoyl`）
- `≡B` → `boranylidyne`（预选前缀；非 `boryl`）
- `–B(NH₂)₂` → `diaminoboranyl`（预选前缀；非 `borodiamidoyl`）
- `–BH(O-CH₃)` → `methoxyboranyl`（优选前缀；非 `hydromethoxyboryl`）
- `–Si(OH)₃` → `trihydroxysilyl`（预选前缀）
- `–SiCl₂(NH₂)` → `aminodichlorosilyl`（预选前缀）
- `–Si(O-CH₃)₃` → `trimethoxysilyl`（优选前缀）
- `–Si(OH)₂(SH)` → `dihydroxy(sulfanyl)silyl`（预选前缀）

#### P-67.1.4.3 由硝酸和亚硝酸衍生的取代基基团

酰基 'nitro'（用于 –NO₂）和 'nitroso'（用于 –NO）当连接到以下元素 C、P、As、Sb、Bi、Si、Ge、Sn、Pb、B、Al、Ga、In 和 Tl 时，已在 P-61.5 中讨论。本节讨论与硝酸和亚硝酸的酯、酰胺和酰肼相关的取代基基团命名规则。

##### P-67.1.4.3.1 由硝酸和亚硝酸的酯衍生的取代基基团

硝酸酯和亚硝酸酯作为硝酸和亚硝酸的酯在 P-67.1.3.2 中讨论。由这些化合物衍生的取代基基团通过拼接命名，即将酰基 'nitro'（用于 –NO₂）和 'nitroso'（用于 –NO）加到前缀 'oxy' 上，或将这些酰基取代到 'sulfanyl'、'selanyl' 或 'tellanyl' 等取代基基团中。

示例：

- `–O-NO₂` → `nitrooxy`（硝基氧基，预选前缀）
- `–S-NO₂` → `nitrosulfanyl`（硝基硫基，预选前缀）
- `–O-NO` → `nitrosooxy`（亚硝基氧基，预选前缀）
- `–Se-NO` → `nitrososelanyl`（亚硝基硒基，预选前缀）

##### P-67.1.4.3.2 由硝酸和亚硝酸的酰胺衍生的取代基基团

硝酸的酰胺 O₂N–NH₂ 命名为 'nitramide'（硝酰胺），由该酰胺失去一个氢原子而衍生的取代基基团通过应用命名酰胺的通用规则（见 P-66.1.1.4.3）称为 'nitramido'（硝酰胺基），即把酰胺名称的最后一个字母 'e' 改为 'o'。其他衍生物以及由亚硝酸酰胺 ON–NH₂ 衍生的那些，通过将酰基 'nitro' 和 'nitroso' 取代到合适的取代基基团 'amino'、'imino' 和 'azanetriyl' 中形成。必须注意，将 –NO 和 –NO₂ 基团定位到另一个氮原子上并不构成链的增长。

示例：

- `–NH-NO` → `nitrosoamino`（亚硝基氨基，预选前缀）
- `>N-NO₂` → `nitroazanediyl`（硝基氮烷二基，预选前缀）
- `=N-NO₂` → `nitroimino`（硝基亚氨基，预选前缀）
- `–NH-NO₂` → `nitramido`（硝酰胺基，预选前缀）
- `–N=S` → `sulfanylideneamino`（硫烷亚基氨基，预选前缀）；亦作 `thioxoamino`、`thionitroso`
- `–O₂S-N=S` → `(sulfanylideneamino)sulfonyl`（（硫烷亚基氨基）磺酰，预选前缀）；亦作 `(thioxoimino)sulfonyl`、`(thionitroso)sulfonyl`

##### P-67.1.4.3.3 由硝酸和亚硝酸的酰肼衍生的取代基基团

由硝酸酰肼 O₂N–NH–NH₂ 和亚硝酸酰肼 ON–NH–NH₂ 衍生的取代基基团，通过将酰基 'nitro' 或 'nitroso' 取代到合适的取代基基团 'hydrazin-1-yl'、'hydrazin-1-ylidene' 等中命名。

示例：

- `2-nitrohydrazin-1-yl`（2-硝基肼-1-基，预选前缀）
- `nitrosohydrazinylidene`（亚硝基肼亚基，预选前缀）
- `1-nitrohydrazin-1-yl`（1-硝基肼-1-基，预选前缀）

#### P-67.1.4.4 由硫族酸衍生的取代基基团

##### P-67.1.4.4.1 酰基

有两种方法可生成用作取代基基团的硫族酸酰基名称。

(1) P-65.3.2.3 中所述的方法，即由中缀表示 –S-、–Se-、–Te-、=NH 和 =NNH₂ 的官能置换，其他原子或基团则用拼接。

(2) P-65.2.1.5 中所述用于从碳酸衍生物派生酰基的通用方法，该方法在 P-67.1.4.1.1.4 中应用于由磷酸、膦酸和次膦酸及其砷和锑同系物派生的酰基，此处应用于硫酸及其官能置换类似物。

方法 (1) 产生预选前缀。

示例：

- `–SO₂-` → `sulfonyl`（磺酰，预选前缀）；亦作 `sulfuryl`
- `–S(O)(S)-` → `sulfonothioyl`（硫代磺酰，预选前缀）；亦作 `sulfurothioyl`
- `–S(S)₂-` → `sulfonodithioyl`（二硫代磺酰，预选前缀）；亦作 `sulfurodithioyl`
- `–S(O)(=NH)-` → `sulfonimidoyl`（亚胺磺酰，预选前缀）；亦作 `sulfurimidoyl`
- `–S(=NH)₂-` → `sulfonodiimidoyl`（二亚胺磺酰，预选前缀）；亦作 `sulfurodiimidoyl`
- `–S(O)(=NNH₂)-` → `sulfonohydrazonoyl`（腙磺酰，预选前缀）；亦作 `sulfurohydrazonoyl`
- `–S(=NNH₂)₂-` → `sulfonodihydrazonoyl`（二腙磺酰，预选前缀）；亦作 `sulfurodihydrazonoyl`
- `–SO₂-Cl` → `chlorosulfonyl`（氯磺酰，预选前缀）；亦作 `sulfurochloridoyl`
- `–SO₂-CN` → `cyanosulfonyl`（氰磺酰，优选前缀）；亦作 `sulfurocyanidoyl`
- `–SO₂-NCS` → `isothiocyanatosulfonyl`（异硫氰酸根磺酰，优选前缀）；亦作 `sulfur(isothiocyanatidoyl)`
- `–S(O)(S)-NCS` → `isothiocyanatosulfonothioyl`（异硫氰酸根硫代磺酰，优选前缀）；亦作 `sulfur(isothiocyanatido)thioyl`
- `–SO₂-O-CH₃` → `methoxysulfonyl`（甲氧基磺酰，优选前缀）；亦作 `methoxysulfuryl`
- `–S(=O)-Cl` → `chlorosulfinyl`（氯亚磺酰，预选前缀）

方法 (2) 不能应用于亚硫酸、硒酸和亚硒酸、碲酸和亚碲酸，因为可能产生歧义名称。

##### P-67.1.4.4.2

如果含硫基团通过氧（硫族）或氮连接到某一化合物，而该化合物还含有另一个在引用为主基团方面优先于含硫基团的取代基，则该含硫基团由 P-65.3.2.3 和 P-67.1.4.4.1 所述的、由拼接或取代（见 P-35.4）形成的合适前缀命名。

示例：

- `3-(sulfooxy)propanoic acid` (PIN)（3-（磺基氧基）丙酸）
- `3-[(methoxysulfinyl)oxy]propanoic acid` (PIN)（3-[（甲氧基亚磺酰基）氧基]丙酸）
- `3-[(chlorosulfonyl)oxy]propanoic acid` (PIN)（3-[（氯磺酰基）氧基]丙酸）；亦作 `3-(sulfurochloridoyloxy)propanoic acid`
- `3-(sulfamoyloxy)propanoic acid` (PIN)（3-（氨磺酰基氧基）丙酸）；亦作 `3-(sulfuramidoyloxy)propanoic acid`（不使用 `3-(sulfonamidoyloxy)propanoic acid`；名称 `sulfonamidic acid` 不是已批准的名称）
- `3-[(aminosulfinyl)oxy]propanoic acid` (PIN)（3-[（氨基亚磺酰基）氧基]丙酸）（不使用 `3-(sulfinamidoyloxy)propanoic acid`；名称 `sulfinamidic acid` 不是已批准的名称）
- `3-[(methoxysulfonyl)amino]propanoic acid` (PIN)（3-[（甲氧基磺酰基）氨基]丙酸）

#### P-67.1.4.5 由卤素酸衍生的取代基基团

由卤素酸及其硫族类似物派生的前缀名称在取代命名法中用作强制前缀。它们列于表 5.1 中，并在 P-61.3.2.3 中讨论。

示例：

- `OCl-` → `chlorosyl`（氧氯化亚氯酰，预选前缀）
- `SCl-` → `thiochlorosyl`（硫代氯酰，预选前缀）
- `O₂Cl-` → `chloryl`（氯酰，预选前缀）
- `O₃Cl-` → `perchloryl`（高氯酰，预选前缀）

相应的 Br、F 和 I 基团以类似方式命名。

示例：

- `C₆H₅-BrO` → `bromosylbenzene` (PIN)（亚溴酰苯）

### P-67.1.5 非碳酸含氧酸及其衍生物之间的优选顺序

#### P-67.1.5.1

当存在优先被引用为主特征基团的特征基团时（见类别优选顺序 P-41 和酸优选顺序 P-42），使用具有保留名或系统形成名称（见 P-67.1.4.1）的前缀来表示无机酸。

示例：

- `4-(dihydroxyarsanyl)benzoic acid` (PIN)（4-（二羟基砷烷基）苯甲酸）——[–COOH 优先于 –As(OH)₂]
- `(HO)₂P(O)-CH₂-COOH` → `phosphonoacetic acid` (PIN)（膦酸根乙酸）
- `[2-(methoxysulfonyl)phenyl]phosphonic acid` (PIN)（[2-（甲氧基磺酰基）苯基]膦酸）——（酸优先于酯）
- `(4-arsonobutyl)phosphonic acid` (PIN)（（4-胂酸根丁基）膦酸）——（磷的酸优先于砷的酸）
- `C₆H₅-SO₂-N=P(NH-C₆H₅)₃` → `N-(trianilino-λ⁵-phosphanylidene)benzenesulfonamide` (PIN)（N-（三苯胺基-λ⁵-磷烷亚基）苯磺酰胺）；亦作 `N-(trianilinophosphoranylidene)benzenesulfonamide`（不使用 `N,N′,N′′-triphenyl-N′′′-benzenesulfonylphosphorimidic triamide`，也不用 `N′′′-benzenesulfonylphosphorimidic tris(phenylamide)`）

#### P-67.1.5.2

当单核酸的衍生物由官能类别命名法命名时，优选顺序依据与中心原子相连的原子数目及在下列列表中出现尽量早来确定：酸的 O、OO、S、Se、Te，其次 F、Cl、Br、I，其次按顺序 N₃、CN、NC、NCO、NCS、NCSe、NCTe 的拟卤化物，其次酰胺和酰肼。

示例：

- `Br₂P(O)-CH₂-CH₂-P(O)Cl₂` → `(2-phosphorodibromidoylethyl)phosphonic dichloride` (PIN)（（2-二溴代磷酰乙基）膦酰二氯化物）——（在类别优选顺序中 Cl 优先于 Br）
- `Br₂P(O)-CH₂-CH₂-P(S)Cl₂` → `(2-phosphorodichloridothioylethyl)phosphonic dibromide` (PIN)（（2-二氯代硫代磷酰乙基）膦酰二溴化物）——（`phosphonic dibromide` 优先于 `phosphonothioic dichloride`；先考虑 O > S 再考虑 Cl > Br）
- `Cl₂P(O)-O-CH₂-CH₂-O-P(O)Cl(NH₂)` → `2-(phosphoramidochloridoyloxy)ethyl phosphorodichloridate` (PIN)（2-（氨基氯代磷酰氧基）乙基二氯代磷酸酯）——（`phosphorodichloridic acid` 优先于 `phosphoramidochloridic acid`）

### P-67.1.6 aci-硝基化合物

aci-硝基化合物值得特别提及。它们是具有通式 R=N(O)OH 或 R₂N(O)OH 的硝基化合物的互变异构体，并被命名为次叠氮酸 H₂N(O)OH 的衍生物。

示例：

- `CH₂=N(O)-OH` → `methylideneazinic acid` (PIN)（甲亚基次叠氮酸）；`aci-nitromethane`（aci-硝基甲烷）

需要时，R₂N(O)– 基团由源自 'azinoyl' 的前缀表示，它优先于 'nitroryl'（见 P-67.1.4.1.1.2）。基团 =N(O)OH 命名为 'hydroxy(oxo)-λ⁵-azanylidene'（羟基（氧代）-λ⁵-氮烷亚基）。

名称 'hydroxy(oxo)-λ⁵-azanylidene' 是对 1993 年（ref. 2）推荐名称 'hydroxynitroryl' 的变更，后者在本推荐中不可接受，因为此处两个自由价必须以正确的 'ylidene' 或 'diyl' 类型表示。

示例：

- `(CH₃)₂N(O)-CH₂-CN` → `cyano-N,N-dimethylmethanamine N-oxide` (PIN，见 P-62.5)（氰基-N,N-二甲基甲胺 N-氧化物）；亦作 `(dimethylazinoyl)acetonitrile`（不使用 `(dimethylnitroryl)acetonitrile`）
- `4-[hydroxy(oxo)-λ⁵-azanylidene]cyclohexane-1-carboxylic acid` (PIN)（4-[羟基（氧代）-λ⁵-氮烷亚基]环己烷-1-甲酸）；`4-aci-nitrocyclohexane-1-carboxylic acid`（4-aci-硝基环己烷-1-甲酸）

## P-67.2 双核和多核非碳酸含氧酸

与单核酸一样，多核酸具有用作预选名的保留名。不推荐取代名或加成名。保留名用作母体，并可以像单核酸那样经官能置换修饰，只是官能置换操作仅使用前缀。

此处描述中心原子为 B、P、As、Sb、S、Se 的双核和多核非碳酸含氧酸。它们分为三种类型。对每个中心原子举例说明了双核和三核酸。在某些情况下还已知更高的多核酸。其名称通过使用合适的倍增前缀来表示中心原子的数目来形成。双核和多核非碳酸含氧酸在 P-67.2 和 P-67.3 节中讨论。

就其结构已知且与磷的酸一致而言，砷和锑的酸以与磷的酸相同的方式命名，分别以 'ars' 和 'stib' 代替 'phosph'。类似地，碲的酸以与硒的酸相同的方式命名，即将酸名称中的 'selen' 改为 'tellur'。

**本小节纲目：**

- **P-67.2.1** — 预选名
- **P-67.2.2** — 双核和多核非碳酸含氧酸的官能置换衍生物
- **P-67.2.3** — 双核和多核非碳酸含氧酸的酰卤和拟卤化物
- **P-67.2.4** — 双核和多核非碳酸含氧酸的酰胺和酰肼
- **P-67.2.5** — 双核和多核非碳酸含氧酸的酯和酸酐
- **P-67.2.6** — 由多酸衍生的取代基基团

### P-67.2.2 双核和多核非碳酸含氧酸的官能置换衍生物

**本小节纲目：**

- **P-67.2.2.1** — 通用方法
- **P-67.2.2.2** — 用 –OO-、–S-、=S、–Se-、=Se、–Te-、=Te、–NH- 和 =NH 置换

#### P-67.2.2.1 通用方法

前缀用于表示 P-67.1.2.3.3 和 P-67.1.2.3.4 中列出的多核非碳酸含氧酸的官能置换。前缀按字母顺序引用和编号，置于多酸保留名的前面，必要时带合适的位次。每个酸从一端编号到另一端，从中心原子开始并在中心原子结束。在应用官能置换操作之前，必须选择主官能团；它得到较低的位次。要考虑的官能团顺序为：酸（见 P-67.2.2.2）、酰卤和拟卤化物（见 P-67.2.3）、酰胺和酰肼（见 P-67.2.4）。

#### P-67.2.2.2 用 –OO-、–S-、=S、–Se-、=Se、–Te-、=Te、–NH- 和 =NH 置换

氧原子的官能置换由前缀表示，即：peroxy（用于 –OO-）；thio（用于 –S- 或 =S）；seleno（用于 –Se- 或 =Se）；telluro（用于 –Te- 或 =Te）；imido（用于 –NH- 或 =NH）。上标斜体字母位次 N1、N2 用于指明亚氨基基团上的取代，这些亚氨基基团不是作为链的一部分接受数字位次的原子之间的连接。撇号规则见 P-16.9。

使用上标 'N' 位次是对以往推荐（连续字母如 'N′'、'N′′' 等）的变更；撇号序列跟随链的阿拉伯数字，撇号数目与阿拉伯数字值的增大相平行。

上标斜体字母用于具体定位酸基团中的硫族原子，例如 S3。

这是对以往推荐的变更，以往推荐中酸基团中硫族原子的具体位置由前缀到原子符号上的一行阿拉伯数字描述。

示例：

- `1,3-dithiotriphosphoric S1,S3-acid`（1,3-二硫代三磷酸 S1,S3-酸；非 `1,3-dithiotriphosphoric 1-S,3-S-acid`；名称由预选名 `triphosphoric acid` 派生）
- `1-thiodiphosphoric S1-acid`（1-硫代焦磷酸 S1-酸；名称由预选名 `diphosphoric acid` 派生；'thio' 置换确定位次 '1'）
- `2-seleno-1,1,3-trithiodiarsonic S1,S3-acid`（2-硒代-1,1,3-三硫代二胂酸 S1,S3-酸；名称由预选名 `diarsonic acid` 派生；一个酸基团的 'dithio' 置换确定位次 '1'）
- `1,3-dithiodiphosphonic O1,S3-acid`（1,3-二硫代二膦酸 O1,S3-酸；名称由预选名 `diphosphonic acid` 派生；酸官能团的 'OH' 基团按字母顺序优先于 'SH' 基团获得较低位次）
- `1-imidohypodiarsonic acid`（1-亚氨基连二胂酸；名称由预选名 `hypodiarsonic acid` 派生；'imido' 置换前缀确定位次 '1'）
- `1,3-diimidodiphosphoric acid`（1,3-二亚氨基焦磷酸；名称由预选名 `diphosphoric acid` 派生）
- `1-thiodisulfuric S1-acid`（1-硫代焦硫酸 S1-酸；名称由预选名 `disulfuric acid` 派生）
- `3-amido-1-selenodisulfuric Se1-acid`（3-氨基-1-硒代焦硫酸 Se1-酸；名称由预选名 `disulfuric acid` 派生；酸确定位次 '1'）
- `2-thiodisulfuric acid`（2-硫代焦硫酸，预选名）；亦作 `sulfanedisulfonic acid`；传统名 `trithionic acid`（三硫代硫酸）
- `2-(dithioperoxy)disulfuric acid`（2-（二硫代过氧）焦硫酸，预选名）；亦作 `disulfanedisulfonic acid`；传统名 `tetrathionic acid`（四硫代硫酸）
- `2,4-diimidotrisulfuric acid`（2,4-二亚氨基三硫酸；名称由预选名 `trisulfuric acid` 派生）
- `N1-methyl-1-imido-2-thiodithionous S2-acid` (PIN)（N1-甲基-1-亚氨基-2-硫代连二亚硫酸 S2-酸；'imido' 置换前缀确定位次 '1'；不使用 `1-(methylimido)-2-thiodithionous 2-S-acid`）
- `N1-methyl-1,2-diimidodithionous acid` (PIN)（N1-甲基-1,2-二亚氨基连二亚硫酸）
- `2-imido-1,1,3-trithiodisulfuric O3,S1-acid`（2-亚氨基-1,1,3-三硫代焦硫酸 O3,S1-酸；名称由预选名 `disulfuric acid` 派生）
- `1-imido-1,3-dithiodisulfuric O1,S3-acid`（1-亚氨基-1,3-二硫代焦硫酸 O1,S3-酸；名称由预选名 `disulfuric acid` 派生；酸官能团的 'OH' 基团按字母顺序优先于 'SH' 基团获得较低位次）

### P-67.2.3 双核和多核非碳酸含氧酸的酰卤和拟卤化物

所有 –OH 基团均已被卤化物或拟卤化物原子或基团置换的酰卤和拟卤化物，通过官能类别命名法命名，即将名称中的 'acid' 一词替换为相应卤化物或拟卤化物的名称。对于酰卤和酸式拟卤化物，优级序为卤化物（按字母顺序），其后是拟卤化物的如下优级序：N₃、CN、NC、NCO、NCS、NCSe、NCTe。

示例：

- `2-imidodiphosphonic 1-bromide 3-chloride`（2-亚氨基二膦酸 1-溴化物 3-氯化物；名称由预选名 `diphosphonic acid` 派生；'Br'（溴化物）按字母顺序优先于 'Cl'（氯化物），并确定位次 '1'）
- `2-thiodiphosphoric tetrachloride`（2-硫代焦磷酸四氯化物；名称由预选名 `diphosphoric acid` 派生）
- `diphosphoric tetraisocyanate` (PIN)（焦磷酸四异氰酸酯）
- `cyanohypodiphosphorous triiodide` (PIN)（氰代连二亚磷酸三碘化物）
- `3-amido-2-imidodiphosphonic chloride`（3-氨基-2-亚氨基二膦酰氯；名称由预选名 `diphosphonic acid` 派生；酰氯优先于酰胺基团并确定位次 '1'）

### P-67.2.4 双核和多核非碳酸含氧酸的酰胺和酰肼

所有 –OH 基团均已被 –NH₂ 或 –NHNH₂ 基团置换的多核非碳酸含氧酸，分别通过官能类别命名法命名为酰胺或酰肼。酰胺由类别名 'amide' 表示，前面加合适的倍增前缀 'di'、'tri' 等。类似地，酰肼由类别名 'hydrazide' 表示。官能置换由整个名称之前引用的前缀描述，而非在类别名之前。斜体字母位次 N、N′ 等和上标字母位次 N1、N′1 等用于指明氮原子上的取代，这些氮原子不是作为链的一部分接受数字位次的中心原子之间的连接。当需要选择时，酰胺优先于酰肼，并获得较低位次。

示例：

- `hypodiphosphoric tetraamide`（连二磷酸四酰胺；名称由预选名 `hypodiphosphoric acid` 派生）
- `hypodiphosphonic diamide`（连二膦酸二酰胺；名称由预选名 `hypodiphosphonic acid` 派生）
- `diphosphoric tetraamide`（焦磷酸四酰胺；名称由预选名 `diphosphoric acid` 派生）
- `2,4-diimidotrisulfuric diamide`（2,4-二亚氨基三硫酸二酰胺；名称由预选名 `trisulfuric acid` 派生）
- `diphosphonic dihydrazide`（二膦酸二酰肼；名称由预选名 `diphosphonic acid` 派生）
- `2-thiodiphosphoric tetraamide`（2-硫代焦磷酸四酰胺；名称由预选名 `diphosphoric acid` 派生）
- `triphosphonic diamide`（三膦酸二酰胺；名称由预选名 `triphosphonic acid` 派生）
- `N1-methyl-1,2,3-triimidodiphosphoric tetraamide` (PIN)（N1-甲基-1,2,3-三亚氨基焦磷酸四酰胺）
- `2,4-diimidotriphosphoric pentaamide`（2,4-二亚氨基三磷酸五酰胺；名称由预选名 `triphosphoric acid` 派生）
- `2,4,6-triimidotetraphosphoric hexaamide`（2,4,6-三亚氨基四磷酸六酰胺；名称由预选名 `tetraphosphoric acid` 派生）
- `pentaimidotriphosphoric pentaamide`（五亚氨基三磷酸五酰胺；名称由预选名 `triphosphoric acid` 派生）
- `heptaimidotetraphosphoric hexaamide`（七亚氨基四磷酸六酰胺；名称由预选名 `tetraphosphoric acid` 派生）
- `H₂N-SO₂-O-SO₂-NH₂` → `disulfuric diamide`（焦硫酸二酰胺；名称由预选名 `disulfuric acid` 派生）
- `H₂N-SeO₂-O-SeO₂-NH₂` → `diselenic diamide`（二硒酸二酰胺；名称由预选名 `diselenic acid` 派生）
- `3-hydrazidodiphosphonic 1-amide`（3-肼代二膦酸 1-酰胺）
- `1,3-dihydrazidodiphosphoric 1,3-diamide`（1,3-二肼代焦磷酸 1,3-二酰胺）

### P-67.2.5 双核和多核非碳酸含氧酸的盐、酯和酸酐

**本小节纲目：**

- **P-67.2.5.1** — 双核和多核非碳酸含氧酸的盐
- **P-67.2.5.2** — 多碱价非碳酸含氧酸的酯
- **P-67.2.5.3** — 多碱价非碳酸含氧酸的酸酐

#### P-67.2.5.1 双核和多核非碳酸含氧酸的盐

##### P-67.2.5.1.1

双核和多核非碳酸含氧酸的中性盐通过先引用阳离子、后引用作为（一个）单独词的阴离子名称来命名。阴离子名称通过将 'ic acid' 词尾改为 'ate'、'ous acid' 改为 'ite' 形成。不同的阳离子按字母顺序引用。

示例：

- `disodium N-methyl-1,2-diimidodithionite` (PIN)（N-甲基-1,2-二亚氨基连二亚硫酸二钠）
- `4 Na⁺ (−O)₂P(=O)-O-P(=O)(O⁻)₂` → `tetrasodium diphosphate`（焦磷酸四钠；名称由预选名 `diphosphoric acid` 派生）

##### P-67.2.5.1.2

双核和多核非碳酸含氧酸的酸式盐以与中性盐相同的方式命名，剩余的酸式氢原子由 'hydrogen'（或按需 'dihydrogen' 等）一词表示，插在阳离子名称和阴离子名称之间，并用空格隔开。

示例：

- `NaO-SO₂-SS-SO₂-OH` → `sodium hydrogen 2-dithioperoxydisulfate`（2-二硫代过氧焦硫酸钠氢；名称由预选名 `disulfuric acid` 派生）

#### P-67.2.5.2 多核非碳酸含氧酸的酯

完全酯化的多核非碳酸含氧酸按中性盐命名，只是用允许基团（烷基、芳基等，多于一个时按字母数字顺序引用）的名称代替阳离子名称。多碱价非碳酸含氧酸的部分（酸式）酯及其盐按中性酯和酸式盐的程序命名，只是表示酸式氢原子的 'hydrogen' 名称由单独的词 'hydrogen'（带合适的表示多重性的倍增前缀）表示，插在阳离子或有机基团的名称和阴离子名称之间。

示例：

- `dimethyl thiohypodiphosphonite` (PIN)（硫代连二亚磷酸二甲酯）
- `methyl hydrogen dithiohypodiphosphonite` (PIN)（二硫代连二亚磷酸甲基氢酯）
- `CH₃-O-SO₂-O-SO₂-S-CH₂-CH₃` → `S-ethyl O-methyl thiodisulfate` (PIN)（硫代焦硫酸 S-乙基 O-甲基酯）
- `(CH₃)₂CH-O-SO-O-SO-O-CH(CH₃)₂` → `di(propan-2-yl) disulfite` (PIN)（焦亚硫酸二（丙-2-基）酯）
- `CH₃-O-SO₂-S-SO₂-O-CH₃` → `O1,O3-dimethyl thiodisulfate` (PIN)（硫代焦硫酸 O1,O3-二甲基酯）

#### P-67.2.5.3 多核非碳酸含氧酸的酸酐

在有机酸与具有预选名的多核非碳酸含氧酸之间形成的中性酸酐，通过按字母顺序引用酸的名称、后接类别名 'anhydride' 来命名；倍增前缀 'di'、'tri' 等用于表示酸酐连接的数目。

酸性酸酐以较优酸为母体命名，或按 P-67.3.1 所述使用系统的取代命名法命名。

示例：

- `(CH₃-CO-O)₂P(O)-P(O)(O-CO-CH₃)₂` → `tetraacetic hypodiphosphoric tetraanhydride` (PIN)（四乙酸连二磷酸四酸酐）
- `CH₃-CO-O-SO-SO-O-CO-CH₂-CH₃` → `acetic dithionous propanoic dianhydride` (PIN)（乙酸连二亚硫酸丙酸二酸酐）；亦作 `acetic hypodisulfurous propanoic dianhydride`

### P-67.2.6 由多酸衍生的取代基基团

在存在优先被引用为主基团的特征基团时，多核非碳酸含氧酸作为前缀引用。这些前缀的名称由以下方式形成：

(1) 酰基的组合；

(2) 基于包含最多 P、As、Sb、S、Se 和 Te 中心原子的基团名称；

(3) 当使用条件满足时，采用骨架置换命名法（见 P-15.4 和 P-51.4）。

当对母体取代基有选择时，优先权给予尺寸最大的母体取代基，然后，如有需要，按字母数字顺序。

示例：

- (2) `3-[(1,3,3-trihydroxy-1,3-dioxo-1λ⁵,3λ⁵-diphosphoxan-1-yl)oxy]propanoic acid` (PIN)（3-[（1,3,3-三羟基-1,3-二氧代-1λ⁵,3λ⁵-二磷杂氧杂环己烷-1-基）氧基]丙酸）
- (1) `3-{[hydroxy(phosphonooxy)phosphoryl]oxy}propanoic acid`（3-{[羟基（膦酸根氧基）磷酰基]氧基}丙酸）

## P-67.3 多酸的取代名和官能类别名

### P-67.3.1 无法基于基本含氧酸形成的多核非碳酸含氧酸的名称

无法基于基本含氧酸形成的多核非碳酸含氧酸的名称，要么通过使用类别名（如 anhydride，酸酐）命名，要么取代地形成。酸酐名称优先于取代名。

本节也包含某些名称，因为其结构不符合二酸或连二酸（hypodiacid）名称所隐含的名称，例如下面举例的 'disulfurous acid'（连二亚硫酸）这一名称。

无法直接通过官能置换形成的酸衍生物的名称，通过取代具有优选名（如 `phosphonic acid` 和 `phosphinic acid`）的酸来生成；或者它们是类别名，如 'anhydride'。母体依据类别的优选顺序选择：酸、酰卤、叠氮化物、氰化物、异氰化物、异氰酸酯（及其硫族类似物，按 O > S > Se > Te 顺序）、酰胺、酰肼，以及代表较优类别的基团的最大数目（见 P-67.1.2.3.2）。

示例：

- `{[amino(hydroxy)phosphanyl]oxy}phosphonamidic acid`（{[氨基（羟基）磷烷基]氧基}膦酰胺酸，预选名）——（`phosphonamidic acid` 优先于 `phosphonamidous acid`）
- `phosphoramidic phosphoramidous monoanhydride`（氨基磷酸氨基亚磷酸单酸酐）——（在类别优选顺序中酸优先于酸酐）
- `phosphorodiamidic phosphorodiamidous anhydride`（二氨基磷酸二氨基亚磷酸酸酐，预选名）；亦作 `[(diaminophosphanyl)oxy]phosphonic diamide`（[（二氨基磷烷基）氧基]膦酸二酰胺）——（酸酐优先于酰胺）
- `(arsonosulfanyl)phosphonic acid`（（胂酸根硫基）膦酸，预选名）；亦作 `arsoric phosphoric thiomonoanhydride`（砷酸磷酸硫代单酸酐）——（酸优先于酸酐；磷的酸优先于砷的酸）
- `N-(hydroxyphosphonoyl)phosphoramidic acid`（N-（羟基磷酰基）氨基磷酸，预选名）——（此情形下仅可能用取代名）
- `(HO)₂P-HP(O)-OH` → `(dihydroxyphosphanyl)phosphinic acid`（（二羟基磷烷基）次膦酸，预选名）
- `(CH₃-O)₂P(O)-O-HP(O)-O-CH₃` → `methyl [(dimethoxyphosphoryl)oxy]phosphonate` (PIN)（[（二甲氧基磷酰基）氧基]膦酸甲酯）——（`phosphonic acid` 优先于 `phosphoric acid`，见 P-42；旧称 `trimethyl isohypophosphate`）
- `(CH₃)₂P-P(OH)-P(CH₃)₂` → `bis(dimethylphosphanyl)phosphinous acid` (PIN)（双（二甲基磷烷基）次亚膦酸；非 `1,1,3,3-tetramethyltriphosphan-2-ol`；酸优先于杂醇）
- `1-hydroxy-1,1-diiodo-1λ⁴-disulfane-2-carbonitrile` (PIN)（1-羟基-1,1-二碘代-1λ⁴-二硫烷-2-甲腈；旧称 `diiodo(thiocyanatido)orthosulfurous acid`；非 `orthosulfurodiiodidothiocyanatidous acid`）
- `methyl hydrogen {[ethoxy(hydroxy)boranyl]oxy}phosphonate` (PIN)（{[乙氧基（羟基）硼烷基]氧基}膦酸甲基氢酯；即（乙基二氢硼酸酯）（甲基二氢磷酸酯）酸酐）
- `CH₃-CO-O-P(O)(OH)₂` → `(acetyloxy)phosphonic acid` (PIN)（（乙酰氧基）膦酸）；亦作 `acetic phosphoric monoanhydride`（乙酸磷酸单酸酐）、`monoacetyl phosphate`（单乙酰磷酸酯）
- `HO-SeO₂-O-SO₂-OH` → `selenic sulfuric anhydride`（硒酸硫酸酸酐，预选名）；亦作 `(selenonooxy)hydroxy-λ⁶-sulfanedione`
- `CH₃-CH₂-CO-O-B(OH)₂` → `(propanoyloxy)boronic acid` (PIN)（（丙酰氧基）烃基硼酸）；亦作 `boric propanoic monoanhydride`（硼酸丙酸单酸酐）
- `CH₃-CO-O-CO-O-CO-OH` → `{[(acetyloxy)carbonyl]oxy}formic acid` (PIN)（{[（乙酰氧基）羰基]氧基}甲酸）；亦作 `acetic dicarbonic monoanhydride`（乙酸二碳酸单酸酐）

### P-67.3.2 连二亚硫酸名称的困境

名称 `disulfurous acid`（连二亚硫酸）应当对应于结构 HO–SO–O–SO–OH，该结构是按 P-67.2 中给出的定义对所有均相二酸所隐含的。由于在《无机化学命名法》（ref. 12）中，已报道的结构 HO–SO–SO₂–OH 被称为 'disulfurous acid'，因此必须为 HO–SO–O–SO–OH 指定一个不同的名称。在此情形下取代名是合适的。

由于在《无机化学命名法》（ref. 12）中名称 'disulfurous acid' 用于 HO–SO–SO₂–OH，它不能以系统的方式用于 HO–SO–O–SO–OH。因此，后者的预选名为 '1,3-dihydroxy-1λ⁴,3λ⁴-dithioxane-1,3-dione'（1,3-二羟基-1λ⁴,3λ⁴-二硫杂环己烷-1,3-二酮）。

示例：

- `HO-SO-O-SO-OH` → `1,3-dihydroxy-1λ⁴,3λ⁴-dithioxane-1,3-dione`（1,3-二羟基-1λ⁴,3λ⁴-二硫杂环己烷-1,3-二酮，预选名）
- `CH₃-O-S(=O)-O-S(=O)-O-CH₃` → `1,3-dimethoxy-1λ⁴,3λ⁴-dithioxane-1,3-dione` (PIN)（1,3-二甲氧基-1λ⁴,3λ⁴-二硫杂环己烷-1,3-二酮）
- `CH₃-O-S(=NH)-O-S(=NH)-O-CH₃` → `1,3-dimethoxy-1λ⁴,3λ⁴-dithioxane-1,3-diimine` (PIN)（1,3-二甲氧基-1λ⁴,3λ⁴-二硫杂环己烷-1,3-二亚胺）
