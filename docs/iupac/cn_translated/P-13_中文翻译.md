> Chapter P-1, Section P-13: Operations in Nomenclature of Organic Compounds
> 原文页码: 57–67

本节所述的各种操作都涉及结构修饰，首先按修饰的类型分类，例如"置换"（replacement）；然后再按修饰的表达方式分类，例如"通过使用置换中缀"（replacement infixes）。被施以各种修饰的结构可被视为母体结构，而修饰通过后缀、词缀、中缀和前缀，或通过词尾的改变来表达。

- **P-13.1** — 取代操作（The substitutive operation）
- **P-13.2** — 置换操作（The replacement operation）
- **P-13.3** — 加成操作（The additive operation）
- **P-13.4** — 消去操作（The subtractive operation）
- **P-13.5** — 缀合操作（The conjunctive operation）
- **P-13.6** — 倍增操作（The multiplicative operation）
- **P-13.7** — 稠合操作（The fusion operation）
- **P-13.8** — 仅用于天然产物命名的操作（Operations used only in the nomenclature of natural products）

## P-13.1 取代操作（The Substitutive Operation）

取代操作涉及将一个或多个氢原子交换为另一个原子或原子团。此过程通过表示所引入原子或原子团的后缀或前缀来表达。

示例：
- `ethane` (PIN) → `ethanethiol` (PIN)（取代后缀 = 'thiol'）
- `benzene` (PIN) → `bromobenzene` (PIN)（取代前缀 = 'bromo'）

---

## P-13.2 置换操作（The Replacement Operation）

### P-13.2.1

置换操作涉及将一组原子或单个非氢原子交换为另一组原子或原子。这可以通过多种方式表达，如下列各小节所示。

#### P-13.2.1.1 通过置换（'a'）前缀

通过代表所引入元素的置换（'a'）前缀表达。此类置换称为**骨架置换**（skeletal replacement）。在有机化合物命名中最常见的置换类型是：将一个或多个碳原子置换为下列元素之一：O、S、Se、Te、N、P、As、Sb、Bi、Si、Ge、Sn、Pb。

示例：
- `cyclotetradecane` (PIN) → `silacyclotetradecane` (PIN)［置换（'a'）前缀 = 'sila'］
- `cyclopenta[cd]pentalene` (PIN) → `1,2,3,4,5,6-hexaazacyclopenta[cd]pentalene` (PIN)［置换（'a'）前缀 = 'aza'］

#### P-13.2.1.2

在特定情形下，杂原子可以被碳原子或另一杂原子置换。前者见于环状多硼烷的命名（见 IR-6.2.4.4，ref. 12），两者均见于天然产物中（见 RF-5，ref. 9 和 P-101.4），并且只能在有专门规定时应用，因为有机化合物的命名通常以碳原子为基础。

示例：
- `1-carba-nido-pentaborane(5)` (PIN)［置换（'a'）前缀 = 'carba'；碳置换硼；见 P-68.1.1.2.1］
- `(4βH)-4-carbayohimban`［置换（'a'）前缀 = 'carba'；碳置换氮；见 P-101.4］

### P-13.2.2 通过表示置换氧原子或含氧基团的前缀或中缀

#### P-13.2.2.1

此类置换称为**官能置换**（functional replacement）。词缀代表所引入的基团。官能置换命名在 P-15.5 中描述。

示例：
- `methyl dimethylphosphinate` (PIN) → `methyl P,P-dimethylphosphinimidate` (PIN)（置换中缀 = 'imid(o)'；=NH 置换 =O）
- `methyl P,P-dimethyl(imidophosphinate)`（置换前缀 = 'imido'；=NH 置换 =O）
- `phenylphosphonic acid` (PIN) → `phenylphosphononitridic acid` (PIN)（置换中缀 = 'nitrid(o)'；≡N 同时置换 =O 和 -OH）
- `phenyl(nitridophosphonic acid)`（置换前缀 = 'nitrido'；≡N 同时置换 =O 和 -OH）

#### P-13.2.2.2

词缀 'thio'、'seleno' 和 'telluro' 表示将特征基团的一个氧原子置换为另一硫族原子。

示例：
- `benzoic acid` → `benzenecarboselenoic acid` (PIN)（置换中缀 = 'selen(o)'；硒置换 =O 或 -O- 中的任一）
- `selenobenzoic acid`（置换前缀 = 'seleno'；硒置换 =O 或 -O- 中的任一）
- `hexanoic acid` (PIN) → `hexane(dithioic) acid` (PIN)（置换中缀 = 'thi(o)'；S 同时置换 =O 和 -O-）（非 hexanedithioic acid）
- `4-formylbenzoic acid` (PIN) → `4-(methaneselenoyl)benzoic acid` (PIN)、`4-(selenoformyl)benzoic acid`（置换前缀 = 'seleno'；=Se 置换 =O）

#### P-13.2.2.3

在特定情形下，前缀 'thio'、'seleno' 和 'telluro' 表示骨架修饰。这种置换发生在具有保留名的环状母体氢化物上，即 morpholine（吗啉）（见表 2.3）、pyran（吡喃）（见表 2.2）、chromene（色烯）、isochromene（异色烯）和 xanthene（呫吨）（见表 2.8），以及 chromane（色满）和 isochromane（异色满）（见表 3.1）。

示例：
- `2H-pyran` (PIN) → `2H-thiopyran` (PIN)（非 2H-oxine，见 P-22.2.2.1.1）（置换前缀 = 'thio'；S 置换 O）
- `2H-thiine`（Hantzsch-Widman 名）（见 P-22.2.2.1.1）

## P-13.3 加成操作（The Additive Operation）

加成操作涉及从其组成部分形式化地组装一个结构，不失去任何原子或基团。此操作可以通过多种方式表达，如下列各小节所示。

### P-13.3.1 通过加成前缀

示例：
- `naphthalene` (PIN) → `1,2,3,4-tetrahydronaphthalene` (PIN)（'hydro' = 表示加合一个氢原子的前缀）
- `1aH-1(9)a-homo(C₆₀-Iₕ)[5,6]fullerene` (PIN)
- `1,9-seco(C₆₀-Iₕ)[5,6]fullerene` (PIN)
- `5α-pregnane` → `4a-homo-5α-pregnane`（'homo' = 加合一个亚甲基，-CH₂-，在此情况下使环扩大，见 P-101.3.2.1）
- `2,3-seco-5α-pregnane`（'seco' = 在 2 和 3 位加合两个氢原子，这是由 C-2 与 C-3 之间键的断裂所必需的）

### P-13.3.2 通过加成后缀

示例：
- `pyridine` (PIN) → `pyridin-1-ium` (PIN)（'ium' = 表示加合一个 H⁺ 的后缀）
- `methylborane` (PIN) → `methylboranuide` (PIN)（'uide' = 表示加合一个 H⁻ 的后缀）

### P-13.3.3 通过独立单词

#### P-13.3.3.1 与中性母体结构的名称连用

示例：
- `acetonitrile` (PIN) → `acetonitrile oxide` (PIN)
- `styrene` / `ethenylbenzene` (PIN) → `styrene oxide` / `phenyloxirane` (PIN)

#### P-13.3.3.2 与一个或多个取代基前缀名连用

此处独立单词是一个类别或亚类名称，代表取代基所连接到的特征基团或特征基团种类（另见官能类别命名，P-15.2）。

示例：
- `methyl`（优选前缀）+ `alcohol`（类名）→ `methanol` (PIN)
- `cyclohexyl`（优选前缀）+ `cyclohexyl`（优选前缀）+ `ketone`（类名）→ `dicyclohexyl ketone` → `dicyclohexylmethanone` (PIN)
- `methyl`（优选前缀）+ `phenyl`（优选前缀）+ `oxy`（预选前缀）→ `methyl phenyl ether` → `anisole` (PIN) / `methoxybenzene`
- `benzyl`（优选前缀）+ `cyanide`（类名）→ `benzyl cyanide` → `phenylacetonitrile` (PIN)

### P-13.3.4 通过将取代基基团加合在一起，此操作称为"串联"（concatenation）

示例：
- `pentyl`（优选前缀）+ `oxy`（预选前缀）→ `pentyloxy`（优选前缀）
- `chloro`（预选前缀）+ `carbonyl`（优选前缀）→ `chlorocarbonyl`，即 `carbonochloridoyl`（优选前缀）
- `azanediyl`（预选前缀）+ `ethane-1,2-diyl`（优选前缀）+ `azanediyl`（预选前缀）→ `ethane-1,2-diylbis(azanediyl)`（优选前缀）

### P-13.3.5 通过将分子实体加合在一起

其中两个分子实体 A 和 B 直接结合、且不从 A 或 B 失去任何原子的化学物种 AB，可称为加合物（见 P-14.8），即将 A 和 B 的名称用长破折号（em dash）连接后引用。

示例：
- `carbon monoxide` (PIN) + `methylborane` (PIN) → `carbon monoxide-methylborane` (PIN)

## P-13.4 消去操作（The Subtractive Operation）

消去操作涉及除去名称中隐含的一个原子或基团。此操作可以在无其他变化的情况下发生，也可以伴随着不饱和度的引入，或伴随着取代基、自由基或离子的形成。在天然产物中有多个前缀用于表示各种消去操作。消去可以通过多种方式表达，如下列各小节所示。

### P-13.4.1 通过后缀

示例：
- `methane` (PIN) → `methyl`（PIN；一种自由基；后缀 'yl' 表示失去一个氢原子）
- `ethane` (PIN) → `ethanide`（PIN；一种阴离子；后缀 'ide' 表示失去一个氢离子 hydron）
- `butane` (PIN) → `butylium`（PIN；后缀 'ylium' 表示失去一个氢负离子 hydride ion）

### P-13.4.2 通过改变词尾

示例：
- `benzenesulfonic acid` (PIN) → `benzenesulfonate`（PIN；词尾 'ate' 表示从 'ic acid' 失去一个氢离子 hydron）
- `butane` (PIN) → `but-1-ene`（PIN；词尾 'ene' 表示失去两个氢原子）

### P-13.4.3 通过前缀 'dehydro' 和 'nor'

#### P-13.4.3.1 前缀 'dehydro'

示例：
- `oxepane` (PIN) → `2,3-didehydrooxepane`（前缀 'didehydro' 表示失去 2 个氢原子）
- `2,3,4,5-tetrahydrooxepine`（PIN，见 P-54.4.1）

#### P-13.4.3.2 前缀 'nor'

前缀 'nor' 用于表示从 stereoparent（立体母体结构）的环或链上除去一个未被取代的饱和骨架原子连同其所连接的氢原子。它也可以表示从 stereoparent 的 mancude 环上失去一个 -CH= 基团（见 P-101.3.1），以及从富勒烯结构中失去一个碳原子（见 P-27.4.2）。

示例：
- `labdane`（基本母体结构）→ `3-norlabdane`（通过除去一个环亚甲基 -CH₂- 基团使环收缩）
- `germacrane`（基本母体结构）→ `13-norgermacrane`（除去一个侧链亚甲基 -CH₂- 基团）
- `(1R,4s,7S)-4-ethyl-1,7-dimethylcyclodecane`（基本母体结构，见 P-101.3.1.1）
- `morphinan`（基本母体结构）→ `1H-4-normorphinan`
- `1,9-dinor(C₆₀-Iₕ)[5,6]fullerene` (PIN)

## P-13.5 缀合操作（The Conjunctive Operation）

缀合操作涉及由其组分的名称形式化地构建一个化合物的名称，在每个连接位点从各组分减去相同数目的氢原子。此操作如下列各小节所述表达。

### P-13.5.1 通过将倍增前缀 'bi'、'ter'、'quater' 等（见 P-14.2.3）置于相应母体氢化物的名称之前

示例：
- `pyridine` (PIN) + `pyridine` (PIN) → `2,2′-bipyridine` (PIN)
- `2,2′-bipyridyl`（见 P-28.2.1）

### P-13.5.2 通过组分名称的并置（缀合命名，conjunctive nomenclature）

此方法被 Chemical Abstracts Service 使用。不推荐用它来构建优选 IUPAC 名称；取代命名是推荐的操作（见 P-51）。当待连接的两个组分是环或环系，以及被化合物的主特征基团取代的碳链（或若干链）时，最常使用此方法。在此方法中，主特征基团和环或环系都必须位于链的末端；连接在链上的其余结构（如有）用取代基前缀描述，其位置用希腊字母位次 α、α1、β、β1 等标示（α 指与主特征基团相邻的原子）。

示例：
- `cyclohexane` (PIN) + `ethanol` (PIN) → `cyclohexaneethanol` / `2-cyclohexylethan-1-ol` (PIN)
- `cyclopentane` (PIN) + `acetic acid` → `cyclopentaneacetic acid` / `cyclopentylacetic acid` (PIN)
- `α-ethylcyclpentaneacetic acid` / `2-cyclopentylbutanoic acid` (PIN)

### P-13.5.3 成环

通过母体结构中任意两个原子之间的直接连接形成环，且各失去一个氢原子，用前缀 'cyclo' 表示。

示例：
- `propane` (PIN) → `cyclopropane` (PIN)
- `5β,9β-androstane`（基本母体结构）→ `9,19-cyclo-5β,9β-androstane`（见 P-101.3.3）
- `2H-2,9-cyclo-1-nor(C₆₀-Iₕ)[5,6]fullerene` (PIN)

## P-13.6 倍增操作（The Multiplicative Operation）

此操作允许表达通过一个对称的多价结构连接起来的多个母体结构出现。

### P-13.6.1

在取代命名中，倍增操作用于命名由二价或多价取代基基团连接的相同母体结构的集合体。相同母体结构是指官能化母体氢化物、官能母体化合物，以及环或环系。实际上，它就是相同母体结构由二价或多价取代基基团相互连接而成的取代命名。

示例：
- `benzonitrile` (PIN) + `methylene`（优选前缀）→ `2,2′-methylenedibenzonitrile` (PIN)
- `acetic acid` + `nitrilo`（预选前缀）→ `2,2′,2′′-nitrilotriacetic acid` / `N,N-bis(carboxymethyl)glycine`（见 P-103.1，表 10.4）
- `cyclohexane` (PIN) + `oxy`（优选前缀）→ `1,1′-oxydicyclohexane` (PIN)

### P-13.6.2

在官能类别命名中，倍增操作用于命名由二价或多价官能类别名称连接的相同母体结构的集合体。

示例：
- `dimethyl 1,4-phenylene dipropanedioate` (PIN)
- `dimethyl butanedioylbis(oxy-2,1-phenylene) dibutanedioate` (PIN)

---

## P-13.7 稠合操作（The Fusion Operation）

稠合操作涉及两个环或环系的并合，使得它们彼此共有原子，或共有原子与键。螺环系统共有一个原子；稠环系统则同时共有原子和键。

示例：
- `cyclopentane` (PIN) + `1H-indene` (PIN) → `spiro[cyclopentane-1,1′-indene]` (PIN)
- `cycloocta-1,3,5,7-tetraene` (PIN)（8-annulene）+ `benzene` (PIN) → `benzo[8]annuene`（PIN；见 P-25.3.2.1.1）

---

## P-13.8 仅用于天然产物命名的操作（Operations Used Only in the Nomenclature of Natural Products）

在天然产物命名中，多个前缀用于表示失去一个基团，即将一个基团交换为氢。水的元素减去并伴随成键也可以视为一种消去操作。这些操作由下列前缀表示：

- 'abeo' — stereoparent 结构中单键的重排（见 P-101.3.5.1）
- 'anhydro' — 从两个羟基失去 H₂O 并伴随成键（见 P-102.5.6.7）
- 'apo' — 从类胡萝卜素系统除去整个侧链（见 P-101.3.4.2）
- 'de' — 在碳水化合物命名中从 -OH 基团减去一个氧原子（见 P-102.5.3），或将一个甲基交换为氢原子（见 P-101.7.5）
- 'des' — 从肽中除去一个氨基酸残基（见 P-103.3.5.4），或从类固醇骨架除去一个末端未被取代的环（见 P-101.3.6）
- 'retro' — 使类胡萝卜素系统中的双键移动（见 P-101.3.5.2）

### P-13.8.1 通过前缀 'de' 和 'des'

#### P-13.8.1.1 前缀 'de'

前缀 'de'（不是 'des'）后接一个基团或原子（氢除外）的名称，表示除去（或失去）该基团并加合必需的氢原子，即将该基团与氢原子交换。

示例：
- I `(5βH)-17-methyl-7,8-didehydrofuro[2′,3′,4′,5′:4,12,13,5]morphinan-3,6α-diol` / `4,5α-epoxy-17-methyl-7,8-didehydromorphinan-3,6α-diol`（morphine 吗啡）
- II `(5βH)-7,8-didehydrofuro[2′,,3′,,4′,,5′,:4,12,13,5]morphinan-3,6α-diol` / `4,5α-epoxy-7,8-didehydromorphinan-3,6α-diol`（`demethylmorphine`，甲基交换为 H）

作为例外，'deoxy' 在应用于羟基化合物时，表示从 -OH 基团除去一个氧原子并重新连接氢原子。'Deoxy' 在碳水化合物命名中被广泛用作消去前缀（见 P-102.5.3）。

示例：
- `β-D-galactopyranose`（基本母体结构）→ `4-deoxy-β-D-xylo-hexopyranose`（非 4-deoxy-β-D-xylo-galactopyranose）
- `(2R,3R,4S,6S)-6-(hydroxymethyl)oxane-2,3,4-triol`（基于母体氢化物 oxane 编号）

#### P-13.8.1.2 前缀 'des'

前缀 'des' 表示除去多肽的一个氨基酸残基并将链重新连接（见 P-103.3.5.4），或除去 stereoparent 的一个末端环（见 P-101.3.6）。

示例：
- `oxytocin` → `des-7-proline-oxytocin`（除去 oxytocin 第 7 位的 proline 脯氨酸残基）
- `5α-androstane`（基本母体结构）→ `des-A-androstane`（除去 5α-androstane 的 A 环）（见 P-101.3.6）

### P-13.8.2 通过前缀 'anhydro'

由单分子单糖（醛糖或酮糖）或单糖衍生物的两个羟基消除水而形式上形成的分子内醚，用可分离前缀 'anhydro' 表示，前缀前附有一对位次以标识所涉及的两个羟基。前缀 'anhydro' 按字母顺序原则置于名称中（见 P-102.5.6.7.1）。

示例：
- `2,4,5-tri-O-methyl-D-mannose`（基本母体结构）→ `3,6-anhydro-2,4,5-tri-O-methyl-D-mannose`（前缀 'anhydro' 描述从同一结构中的两个 'OH' 基团除去 H₂O）
