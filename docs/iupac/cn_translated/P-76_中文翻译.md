## P-76 离域自由基和离子

在涉及一个自由基或离子中心、其余部分为共轭双键结构的名称中，离域通过相应的后缀表示，且不带位次。

示例：

- x = • ：`cyclopentadienyl` (PIN)（环戊二烯基，离域自由基）
- x = + ：`cyclopentadienylium` (PIN)（环戊二烯阳离子，离域阳离子）
- x = - ：`cyclopentadienide` (PIN)（环戊二烯阴离子，离域阴离子）
- `benzo[7]annulenylium` (PIN)（苯并[7]环庚三烯阳离子，离域阳离子）
- `pentadienyl` (PIN)（戊二烯基，离域自由基）
