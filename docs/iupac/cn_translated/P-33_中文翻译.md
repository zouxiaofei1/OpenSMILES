> 译自 IUPAC Blue Book 2013, "Nomenclature of Organic Chemistry: IUPAC Recommendations and Preferred Names 2013"
> Chapter P-4, Section P-33: Suffixes
> 原文页码: 344–349

---

## P-33.0 引言

本节包括表示特征基团的取代基名称，这些名称以后缀形式表达。这些特征基团本质上是在诸如氧族元素（O、S、Se、Te）和氮等原子上具有自由价的基团。该概念扩展到与卤素、氧族元素和氮相连的碳原子，如 -CO-Cl、-CO-OH、-CS-SH、-CHO、-CN。自由基和离子在取代命名法中虽不被归类为特征基团，但也以后缀表示。

---

## P-33.1 定义

后缀分为表示特征基团的"官能后缀"（functional suffixes）和用于表示自由基与离子的"累积后缀"（cumulative suffixes）。官能后缀（P-33.2）用于表示特征基团；它们是排他的，因为名称的末尾只能放置一个后缀来表示主要特征基团或官能。另一方面，表示自由基和离子的后缀可以相互连用，也可以与官能后缀连用（见第 P-7 章）。在名称中，官能后缀总是连接在母体氢化物的名称之后，无论其是否带有 'ene' 和 'yne' 词尾修饰。"累积后缀"（见 P-33.3）可以直接连接在母体氢化物的名称之后，无论其是否带有 'ene' 和 'yne' 词尾修饰；但当存在官能后缀时，累积后缀连接在官能后缀之后。

示例：
- `CH₄` — methane（甲烷，PIN）
- `CH₅⁺` — methanium（甲鎓，PIN）。后缀 `-ium` 表示 H⁺ 的加成
- `CH₄` — methane（甲烷，PIN）
- `CH₃-NH₂` — methanamine（甲胺，PIN）。后缀 `-amine` 表示取代作用
- `CH₃-NH₃⁺` — methanaminium（甲铵，PIN）。后缀 `-ium` 表示 H⁺ 的加成
- `CH₃-CH₃` — ethane（乙烷，PIN）
- `•CH₂-CH₃` — ethyl（乙基，PIN）。后缀 `-yl` 表示失去一个氢原子
- `•CH₂-CH₂•` — ethan-1-yl-2-ylidene（乙烷-1-基-2-亚基，PIN）。后缀 `-ylidene` 表示失去两个氢原子

## P-33.2 官能后缀

### P-33.2.1 基本官能后缀

基本后缀是仅由氧和/或氮组成的后缀，可带有或不带有与碳的关联，如羧酸、酰胺、腈和醛的情况；它们也可与硫关联，以表示磺酸和亚磺酸及其相应的酰胺和酰肼。这些后缀列于表 3.3。

后缀 `peroxol`（表示 -OOH）已被添加到基本后缀列表中。它经官能团置换修饰，生成表示 -OSH 的后缀 `-OS-thioperoxol` 和表示 -SOH 的后缀 `-SO-thioperoxol`。后缀 `sulfenic acid`（次磺酸，表示 -SOH）已在 1993 年建议（参考文献 2）中被废止。

| 序号 | 结构式 | 基本后缀 |

| 1 | -CO-OH | carboxylic acid（羧酸，优选后缀） |
| 2 | -(C)O-OH | oic acid（-酸，优选后缀） |
| 3 | -SO₂-OH | sulfonic acid（磺酸，预选后缀） |
| 4 | -SO-OH | sulfinic acid（亚磺酸，预选后缀） |

## P-33.2.2 衍生优选后缀和预选后缀

衍生后缀通过以多种方式修饰表 3.3 中的基本后缀而形成。关于官能团置换前缀和中缀的末尾字母 'o' 在元音前是否省略，没有通用规则。它按传统用法省略或不省略，例如后缀 'thioic acid' 和 'imidic acid'。优选后缀如下：

**（1）包含一个碳原子的基本后缀**通过官能团置换来修饰，使用中缀表示氧原子被 -OO-、-S-、=S、-Se-、=Se、-Te-、=Te、=NH 和 =NNH₂ 所置换，如 P-15.5 所述；应注意，'carboxylic' 中的字母 'x' 在元音前予以保留，且字母 'o' 在 amide 前不省略。

示例：
- `carboxylic acid`（优选后缀）— 结构式 -CO-OH（羧酸）
- `carboperoxoic acid`（优选后缀）— 结构式 -C(O)-OOH（过氧羧酸）
- `carbothioic S-acid`（优选后缀）— 结构式 -C(O)-SH（硫代羧酸 S-酸）
- `carboselenoic O-acid`（优选后缀）— 结构式 -C(Se)-OH（硒代羧酸 O-酸）
- `carboximidic acid`（优选后缀）— 结构式 -C(=NH)-OH（羧亚氨酸）
- `carbohydrazonic acid`（优选后缀）— 结构式 -C(=NNH₂)-OH（碳腙酸）
- `carboximidothioic acid`（优选后缀）— 结构式 -C(=NH)-SH（硫代羧亚氨酸）
- `carboxamide`（优选后缀）— 结构式 -CO-NH₂（甲酰胺）
- `carbotelluroamide`（优选后缀）— 结构式 -C(Te)-NH₂（碲代甲酰胺）
- `carbohydrazide`（优选后缀）— 结构式 -CO-NHNH₂（甲酰肼）
- `carbothiohydrazide`（优选后缀）— 结构式 -C(S)-NHNH₂（硫代甲酰肼）
- `carbaldehyde`（优选后缀）— 结构式 -CHO（甲醛）
- `carbothialdehyde`（优选后缀）— 结构式 -CHS（硫代甲醛）

**（2）包含一个隐含碳原子的基本后缀**通过官能团置换来修饰，使用前缀表示氧原子被 -OO-、-S-、=S、-Se-、=Se、-Te-、=Te、=NH 和 =NNH₂ 所置换，如 P-15.5 所述；应注意，字母 'o' 在 amide 前不省略，且为谐音起见，'imide' 在 'oic' 前额外省略一个 'o'。

示例：
- `oic acid`（优选后缀）— 结构式 -(C)O-OH（-酸）
- `peroxoic acid`（优选后缀）— 结构式 -(C)O-OOH（过氧酸）
- `thioic S-acid`（优选后缀）— 结构式 -(C)O-SH（硫代酸 S-酸）
- `telluroic O-acid`（优选后缀）— 结构式 -(C)Te-OH（碲代酸 O-酸）
- `imidic acid`（优选后缀）— 结构式 -(C)(=NH)-OH（亚氨酸；不是 imidoic acid）
- `hydrazonic acid`（优选后缀）— 结构式 -(C)(=NNH₂)-OH（腙酸）
- `imidoselenoic acid`（优选后缀）— 结构式 -(C)(=NH)-SeH（硒代亚氨酸）
- `amide`（优选后缀）— 结构式 -(C)O-NH₂（酰胺）
- `thioamide`（优选后缀）— 结构式 -(C)S-NH₂（硫代酰胺）
- `hydrazide`（优选后缀）— 结构式 -(C)O-NHNH₂（酰肼）
- `thiohydrazide`（优选后缀）— 结构式 -(C)S-NHNH₂（硫代酰肼）
- `al`（优选后缀）— 结构式 -(C)HO（-醛）
- `selenal`（优选后缀）— 结构式 -(C)HSe（硒醛）

**（3）不包含碳原子的基本后缀**通过官能团置换命名法来修饰，使用前缀表示氧原子被其他硫属原子（chalcogen）所置换。

示例：
- `one`（预选后缀）— 结构式 =O（-酮）
- `thione`（预选后缀）— 结构式 =S（-硫酮）
- `selone`（预选后缀）— 结构式 =Se（-硒酮；不是 selenone）
- `tellone`（预选后缀）— 结构式 =Te（-碲酮；不是 tellurone）
- `ol`（预选后缀）— 结构式 -OH（-醇）
- `thiol`（预选后缀）— 结构式 -SH（-硫醇）
- `peroxol`（预选后缀）— 结构式 -OOH（过氧醇）
- `OS-thioperoxol`（预选后缀）— 结构式 -OSH（OS-硫代过氧醇）

**（4）词干 'sulf' 被 'selen' 和 'tellur' 替换**，以生成磺酸和亚磺酸的硒类似物和碲类似物。

示例：
- `sulfonic acid`（预选后缀）— 结构式 -SO₂-OH（磺酸）
- `sulfinic acid`（预选后缀）— 结构式 -SO-OH（亚磺酸）
- `selenonic acid`（预选后缀）— 结构式 -SeO₂-OH（硒代磺酸）
- `tellurinic acid`（预选后缀）— 结构式 -TeO-OH（亚碲代磺酸）

**（5）'sulfonic acid' 型后缀及其类似物**通过官能团置换来修饰，使用中缀表示氧原子被 -OO-、-S-、=S、-Se-、=Se、-Te-、=Te、=NH 和 =NNH₂ 所置换，如 P-15.5 所述。

示例：
- `sulfonic acid`（预选后缀）— 结构式 -SO₂-OH（磺酸）
- `sulfonoperoxoic acid`（预选后缀）— 结构式 -SO₂-OOH（过氧磺酸）
- `sulfonodihydrazonic acid`（预选后缀）— 结构式 -S(=NNH₂)₂-OH（磺二腙酸）
- `seleninic acid`（预选后缀）— 结构式 -SeO-OH（亚硒代磺酸）
- `seleninothioic S-acid`（预选后缀）— 结构式 -SeO-SH（硫代亚硒代磺酸 S-酸）
- `telluronic acid`（预选后缀）— 结构式 -TeO₂-OH（碲代磺酸）
- `telluronimidic acid`（预选后缀）— 结构式 -Te(O)(=NH)-OH（碲代磺亚氨酸）
- `sulfinic acid`（预选后缀）— 结构式 -SO-OH（亚磺酸）
- `sulfinohydrazonic acid`（预选后缀）— 结构式 -S(=NNH₂)-OH（亚磺腙酸）

**（6）酰胺和酰肼的名称**通过将后缀中的 'ic acid' 词尾分别替换为 'amide' 或 'hydrazide' 而形成；必要时添加谐音字母 'o'：

示例：
- `imidic acid`（优选后缀）— 结构式 -(C)(=NH)-OH（亚氨酸）
- `imidamide`（优选后缀）— 结构式 -(C)(=NH)-NH₂（亚氨酰胺）
- `carboximidic acid`（优选后缀）— 结构式 -C(=NH)-OH（羧亚氨酸）
- `carboximidamide`（优选后缀）— 结构式 -C(=NH)-NH₂（羧亚氨酰胺）
- `hydrazonic acid`（优选后缀）— 结构式 -(C)(=NNH₂)-OH（腙酸）
- `hydrazonohydrazide`（优选后缀）— 结构式 -(C)(=NNH₂)-NHNH₂（腙酰肼）
- `sulfonic acid`（预选后缀）— 结构式 -SO₂-OH（磺酸）
- `sulfonamide`（预选后缀）— 结构式 -SO₂-NH₂（磺酰胺）
- `seleninic acid`（预选后缀）— 结构式 -SeO-OH（亚硒代磺酸）
- `seleninohydrazide`（预选后缀）— 结构式 -SeO-NHNH₂（亚硒代磺酰肼）

**（7）带有被 -OH 基取代的 -NH₂ 和 =NH 基的后缀**有两种命名方式：
（1）命名为酰胺或亚氨酸的 N-羟基衍生物；
（2）通过将系统命名的酸的 '-oic acid' 或 '-carboxylic acid' 后缀修饰为 '-hydroxamic acid' 或 '-carbohydroxamic acid'、'-hydroximic acid' 或 '-carbohydroximic acid'，或将酸之保留名称（retained name）的 '-ic acid' 词尾修饰为 '-hydroxamic acid' 或 '-hydroximic acid'。为谐音起见，在 'h' 与前一个辅音之间添加字母 'o'。

方法（1）用于优选 IUPAC 名称。
优选 IUPAC 名称现按酰胺或亚氨酸的 N-羟基衍生物来命名。

示例：
- `propanamide` (PIN) — 丙酰胺（结构式 CH₃-CH₂-CO-NH₂）
- `N-hydroxypropanamide` (PIN) — N-羟基丙酰胺（结构式 CH₃-CH₂-CO-NH-OH）
- `propanohydroxamic acid` — 丙异羟肟酸（同一结构的替代名称，方法（2））
- `propanimidic acid` (PIN) — 丙亚氨酸（结构式 CH₃-CH₂-C(=NH)-OH）
- `N-hydroxypropanimidic acid` (PIN) — N-羟基丙亚氨酸（结构式 CH₃-CH₂-C(=N-OH)-OH）
- `propanohydroximic acid` — 丙羟肟酸（同一结构的替代名称，方法（2））

## P-33.3 累积后缀（Cumulative suffixes）

用于表示母体结构中自由基中心和离子中心的后缀列于表 3.4。它们按优先性递减顺序分类：自由基 > 阴离子 > 阳离子。后缀以惯常方式添加到母体氢化物的名称上，或添加到表示另一类型自由基或离子的后缀上，或添加到表示特征基团的后缀上。自由基的名称以与取代基相同的方式形成（见 P-29.2），不同之处在于：集中于单一原子上的二价和三价自由基分别用后缀 'ylidene' 和 'ylidyne' 表示，而绝不用 'diyl' 或 'triyl'。

注意：'ene'、'yne' 等被视为词尾（endings）而非后缀；它们是累积词尾（cumulative endings）。

### 表 3.4 母体结构中自由基中心和离子中心的词缀

| 操作（Operation） | 后缀（Suffix） | 词尾（Ending） |
|:---|:---|:---|
| 自由基（Radicals） | 失去 H• | -yl |
| | 从一个原子失去 2 个 H• | -ylidene |
| | 从不同原子失去 2 个 H• | -diyl |
| | 从一个原子失去 3 个 H• | -ylidyne |
| | 从不同原子失去 3 个 H• | -triyl |
| | | -ylylidene 等 |
| 阴离子（Anions） | 失去 H⁺ | -uide |
| | 加成 H⁻ | -ate、-ite |
| 阳离子（Cations） | 失去 H⁻ | -ylium |
| | 加成 H⁺ | -ium |

示例：
- `ethane` (PIN) — 乙烷（结构式 CH₃-CH₃）
- `ethyl` (PIN) — 乙基（结构式 CH₃-CH₂•，失去一个 H•）
- `ethan-2-id-1-yl` (PIN) — 乙烷-2-基阴离子-1-基（位置 1 为自由基，位置 2 为阴离子）
- `methanamine` (PIN) — 甲胺（结构式 CH₃-NH₂）
- `methanaminium` (PIN) — 甲铵（结构式 CH₃-NH₃⁺，加成 H⁺）
- `methanaminiumyl` (PIN) — 甲铵自由基阳离子
- `methanaminyl` (PIN) — 甲胺自由基（结构式 CH₃-NH•）
- `naphthalen-3-yl-1(2H)-ylidene` (PIN) — 萘-3-基-1(2H)-亚基（位置 3 为自由基，位置 1 为亚基）
