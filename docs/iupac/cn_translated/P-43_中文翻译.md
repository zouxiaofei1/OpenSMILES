# P-43 后缀的优先顺序

## P-43.0 导论

后缀按表 4.3（针对酸）和表 4.4（针对所有取代后缀）所示进行修饰。后缀的优先顺序在本节中描述。该顺序基于表 4.1 中第 7 至第 20 类的优先顺序，并包括经官能团置换修饰后的后缀。

## P-43.1 官能团置换的一般方法

后缀按表 4.3（针对酸）和表 4.4（针对酸及其他类别）所示进行修饰。前缀和中缀按表 4.2 所示使用。前缀用于修饰诸如 'ol'、'al' 等后缀，例如 'thiol' 和 'thial'。建议使用中缀来修饰后缀 'carboxylic acid'、'sulfonic acid' 及相关后缀，例如 'carboperoxoic acid' 和 'sulfonothioic acid'。

---

### 表 4.2 用于通过官能团置换生成 IUPAC 优选名称后缀的前缀和中缀（按优先性递减顺序）

| 前缀 (Prefix) | 中缀 (Infix) | 被置换原子 | 置换原子 |
|:---|:---|:---|:---|
| peroxy- | -peroxo- | -O- | -OO- |
| thioperoxy- | -(thioperoxo)- | -O- | -OS- 或 -SO- |
| dithioperoxy- | -(dithioperoxo)- | -O- | -SS- |
| thio- | -thio- | -O- 或 =O | -S- 或 =S |
| seleno- | -seleno- | -O- 或 =O | -Se- 或 =Se |
| telluro- | -telluro- | -O- 或 =O | -Te- 或 =Te |
| imido- | -imido- | =O | =NH |
| hydrazono- | -hydrazono- | =O | =NNH₂ |

当有多个可置换的氧原子时，按顺序应用以下标准，直到做出决定：

(a) 最大数量的氧原子，然后是 S、Se、Te 原子、=NH 和 =NNH₂ 基团；
(b) -OO- 基团中最大数量的氧原子，然后是 S、Se、Te 原子；
(c) -(O)OH 和 -OH 基团中的氧原子，然后是 S、Se、Te 原子。

对于羧酸、磺酸和亚磺酸，优先顺序通过在修饰后缀名称之后标出置换操作中使用的原子数量和种类来描述（见表 4.3）。

表 4.3 给出了羧酸和磺酸后缀及经官能团置换修饰后缀的优先顺序递减列表。亚磺酸后缀与磺酸类似。硒酸和碲酸后缀通过将 'sulf' 替换为 'selen' 或 'tellur' 来形成。

> **说明：**
> - 表中 "carbox-" 前缀形式用于主链末端为 -COOH 的情况（如 cyclohexanecarboxylic acid），而 "-(C)OOH" 形式（oic acid）用于主链碳原子计入羧基碳的情况。

> - 第 12-15 类（硒代磺酸、亚硒代磺酸、碲代磺酸、亚碲代磺酸）的结构与磺酸和亚磺酸完全类似，仅将 S 替换为 Se 或 Te。
