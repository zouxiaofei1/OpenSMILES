# P-56 主特征基团优选后缀的选择（完整中文翻译）

> 译自 IUPAC Blue Book 2013, "Nomenclature of Organic Chemistry: IUPAC Recommendations and Preferred Names 2013"
> Chapter P-5, Section P-56: Selecting the Preferred Suffix for the Principal Characteristic Group
> 原文页码: 469–470

---

后缀一直被认为是构成名称的最独特元素。过去，一些后缀已被废弃并由新后缀取代。本推荐引入或修改了以下后缀。

## P-56.1 后缀 'peroxol'，用于 -OOH

本推荐现建议使用后缀 'peroxol' 为氢过氧化物提供取代名称。此类名称优先于由官能类别命名法生成的名称。

后缀 'peroxol'（用于 -OOH）现被采纳用于命名氢过氧化物，而在以前的推荐中，氢过氧化物由官能类别命名法命名。

示例：
- `CH₃-CH₂-OOH`：`ethaneperoxol` (PIN)；`ethyl hydroperoxide`

## P-56.2 后缀 'SO-thioperoxol' 及其硫族类似物

后缀 'sulfenic acid' 及其硫族类似物在 1993 年推荐（文献 2）中已被废弃。在本推荐中，这些后缀由新后缀 'SO-thioperoxol'、'SeO-selenoperoxol'、'dithioperoxol'、'TeS-tellurothioperoxol'、'diselenoperoxol'、'SeTe-selenotelluroperoxol' 和 'TeSe-telluroselenoperoxol' 取代（见 P-63.4.2.1）。

现引入后缀 SO-thioperoxol 及其硫族类似物，以取代在 1993 年推荐中被废弃的后缀 'sulfenic acid' 及其硫族类似物。

示例：
- `CH₃-S-OH`：`methane-SO-thioperoxol` (PIN)（不用 `methanesulfenic acid`）
- `C₆H₅-SeSe-H`：`benzenediselenoperoxol` (PIN)（不用 `benzeneselenoselenic acid`）

## P-56.3 后缀 'imidamide' 和 'carboximidamide'

后缀 'amidine' 和 'carboxamidine'（分别用于 `-C(=NH)-NH₂` 和 `-(C)(=NH)-NH₂`）不再推荐使用。在优选 IUPAC 名称中，它们由新的官能团置换后缀 'imidamide' 和 'carboximidamide' 取代（见 P-66.4.1）。

示例：
- `CH₃-C(=NH)-NH₂`：`ethanimidamide` (PIN)（不再推荐 `acetamidine`）
- `C₆H₁₁-C(=NH)-NH₂`：`cyclohexanecarboximidamide` (PIN)（不再推荐 `cyclohexanecarboxamidine`）

## P-56.4 词尾 'diyl' 和 'ylidene' 对 'ylene'

除 'methylene'、'ethylene' 和 'phenylene' 外，后缀 'ylene'（以前用于描述自由价不形成双键的二价取代基团，即 `-E-` 或 `E<`）已于 1993 年（文献 2）被废弃。自由价形成双键（即 `E=`）的取代基团曾用后缀 'ylidene' 描述。后缀 'ylene' 被后缀 'diyl'（用于表示 `-E-` 或 `E<` 型键合）和 'ylidene'（用于 `E=`）取代，例如分别用 `ethane-1,2-diyl` 表示 `-CH₂-CH₂-`，用 `ethylidene` 表示 `H₃C-CH=`。然而，名称 'methylene' 保留用于描述取代基团 `-CH₂-`；在优选 IUPAC 名称中使用它，而非 `methanediyl`。CAS 仍使用 'ylene' 后缀来描述 'diyl' 和 'ylidene' 类型的键，尤其是用 'methylene' 表示 `-CH₂-` 和 `CH₂=`。

示例：

| `-E-` 或 `E<` 型 | `E=` 型 |
| --- | --- |
| `-CH₂-`：`methylene` (preferred prefix)（不用 `methanediyl`） | `H₂C=`：`methylidene` (preferred prefix)（旧称 `methylene`） |
| `-CH₂-CH₂-`：`ethane-1,2-diyl` (preferred prefix)；`ethylene` | `CH₃-CH=`：`ethylidene` (preferred prefix) |
| `-SiH₂-`：`silanediyl` (preselected prefix)（不用 `silylene`，该名仍为 CAS 使用） | `H₂Ge=`：`germylidene` (preselected prefix)（不用 `germylene`，该名仍为 CAS 使用） |
| `-BH-`：`boranediyl` (preselected prefix)（不用 `borylene`，该名仍为 CAS 使用） | `HB=`：`boranylidene` (preselected prefix)（不用 `borylene`，该名仍为 CAS 使用） |
| `-SbH-`：`stibanediyl` (preselected prefix)（不用 `stibinediyl`；不用 `stibylene`，该名仍为 CAS 使用） | `HSb=`：`stibanylidene` (preselected prefix)（不用 `stibinylidene`；不用 `stibylene`，该名仍为 CAS 使用） |
| `-NH-CO-NH-`：`carbonylbis(azanediyl)` [preferred prefix，倍增命名法中使用的名称（见 P-66.1.6.1.1.3）]（不用 `carbonyldiimino`，该名仍为 CAS 使用；不用 `ureylene`） | |
