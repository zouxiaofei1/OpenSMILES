# P-91 立体异构体的图形表示和命名（完整中文翻译）

> 译自 IUPAC Blue Book 2013, "Nomenclature of Organic Chemistry: IUPAC Recommendations and Preferred Names 2013"
> Chapter P-9, Section P-91: Stereoisomer Graphical Representation and Naming
> 原文页码: 870–874

---

立体异构体的图形表示和命名涉及如何在结构图中描绘构型，以及如何通过**立体描述符**（stereodescriptors）在名称中系统地指明构型。

- **P-91.1** — 立体异构体的图形表示
- **P-91.2** — 立体描述符
- **P-91.3** — 立体异构体的命名

---

## P-91.1 立体异构体的图形表示

描绘构型的结构式必须以格外小心的方法绘制。为达到这一目标，1996 年曾提出相关建议（文献 37）。现有一组新的建议载于题为《立体化学构型的图形表示，IUPAC 建议 2006》（Graphical representation of stereochemical configuration, IUPAC Recommendations 2006）的文件中（文献 38）。

一般而言，普通实线表示近似位于图纸平面内的键。指向平面以上原子的键以实心楔形线表示（从图纸平面内的原子开始，位于楔形的窄端）；指向平面以下原子的键以虚线楔形（hashed wedge）表示，其含义与实心楔形类似（从图纸平面内的原子开始，位于楔形的窄端）。若构型未知，可用等幅波状线明确表示。本书即采用这些键型，但天然产物领域中的例外情况在 P-10 章关于碳水化合物的部分已明确指出。

在本章中，单一的图形表示描绘手性分子的**绝对构型**。

## P-91.2 立体描述符

有机化合物的构型通过在一个本身不规定构型的名称上添加一个或多个词缀来系统地指明；这类词缀称为"立体描述符"（stereodescriptors）。

### P-91.2.1 推荐的立体描述符

立体描述符分为两类：

- P-91.2.1.1 卡恩-英戈尔德-普雷洛格（CIP）立体描述符
- P-91.2.1.2 其他可接受的立体描述符

#### P-91.2.1.1 卡恩-英戈尔德-普雷洛格（CIP）立体描述符

卡恩-英戈尔德-普雷洛格（CIP）优先体系中描述的一些立体描述符，称为"CIP 立体描述符"，被推荐用于指明有机化合物的构型，其描述和示例见本章，并应用于 P-1 至 P-8 各章，以及 P-10 章的天然产物命名中。以下立体描述符用作优选立体描述符（见 P-92.1.2）：

(a) 'R' 和 'S'，用于指明四配位（四键）手性中心的绝对构型；
(b) 'r' 和 's'，用于指明假不对称中心的绝对构型；
(c) 'M' 和 'P'，用于按螺旋性规则（helicity rule）指明轴手性或平面手性实体的绝对构型；
(d) 'm' 和 'p'，用于按螺旋性规则指明假不对称实体的绝对构型；
(e) 'seqCis' 和 'seqTrans'，用于描述对映异构双键的构型。

为指明相对构型，与 'R' 或 'S' 关联的描述符 'rel' 优先于立体描述符 'R*' 或 'S*'。外消旋体用描述符 'rac' 描述，它优先于 'RS' 或 'SR' 立体描述符。

以下立体描述符推荐用于一般命名：

- 'R'<sub>a</sub> 和 'S'<sub>a</sub>，用于指明具有**轴手性**（axial chirality）的分子实体的构型；
- 'R'<sub>p</sub> 和 'S'<sub>p</sub>，用于指明具有**平面手性**（planar chirality）的分子实体的构型；
- 'r'<sub>a</sub> 和 's'<sub>a</sub>，用于指明假不对称立体生成轴的构型；
- 'r'<sub>p</sub> 和 's'<sub>p</sub>，用于指明假不对称立体生成平面的构型。

> 注：源 PDF 中原书将下标 'a'（轴向）与 'p'（平面）置于符号之后单独一行，此处已按正确结构还原为 'R'<sub>a</sub>/'S'<sub>a</sub>（轴手性）、'R'<sub>p</sub>/'S'<sub>p</sub>（平面手性）、'r'<sub>a</sub>/'s'<sub>a</sub>（假不对称立体生成轴）、'r'<sub>p</sub>/'s'<sub>p</sub>（假不对称立体生成平面）。

大写的 CIP 立体描述符在镜面反射下发生互变（即 'R' 变为 'S'，'S' 变为 'R'）；小写的 CIP 立体描述符在镜面反射下保持不变（即 'r' 仍为 'r'，'s' 仍为 's'）。它们以斜体书写，以表明它们不参与字母数字排序的初始阶段（见 P-16.6）。

#### P-91.2.1.2 其他可接受的立体描述符

非卡恩-英戈尔德-普雷洛格（CIP）立体描述符分为两类：

- P-91.2.1.2.1 取代命名中使用的立体描述符；
- P-91.2.1.2.2 天然产物命名中使用的立体描述符（见 P-10 章）。

##### P-91.2.1.2.1 取代命名中使用的立体描述符

系统取代名称中用于指明优选 IUPAC 名称构型以及一般命名中使用的立体描述符；其中一些立体描述符仅推荐用于一般命名：

(a) 优选 IUPAC 名称中使用的立体描述符

(i) 'E' 和 'Z'，用于描述非对映异构烯烃 R1R2C=CR3R4（R1 ≠ R2，R3 ≠ R4，且 R1 或 R2 均无需与 R3 或 R4 不同）、累积烯烃 R1R2C=[C=]<sub>n</sub>CR3R4 体系的构型，例如 R1R2C=NOH 和 HON=C{[CH2]<sub>n</sub>}<sub>2</sub>C=NOH。将连接在烯烃、肟等或累积烯烃末端双键原子之一（即 R1 或 R2）上的 CIP 优先性最高的基团，与连接在另一末端原子（即 R3 或 R4）上的优先性最高的基团进行比较。若两基团位于通过双键且垂直于连接各基团与双键原子的键所在平面的参考平面的同一侧，则该立体异构体被指定为 'Z'（zusammen = 同侧）；另一异构体被指定为 'E'（entgegen = 相反）。这些描述符可应用于键级介于一与二之间的分数键级结构，以及涉及碳以外元素的双键。

(ii) 'A' 和 'C'，用于描述五配位（五键，如三角双锥或四方锥）和六配位（六键，如八面体）立体生成中心的绝对构型。

(b) 以下立体描述符推荐用于一般命名：

(i) 'cis'、'trans' 与 'r'、'c'、't' 分别用于指明非对映异构双键的构型（见 P-93.4.2.1.1）和脂环化合物的相对构型（见 P-93.5.1.3）；
(ii) 'endo'、'exo'、'syn' 和 'anti' 用于指明某些冯·拜尔（von Baeyer）环系的相对构型（见 P-93.5.2.2.1）。

在优选 IUPAC 名称中，立体描述符必须在其前冠以位次以指明每个立体生成单元，如 P-91.3 所示。当构型未知或因缺乏构型均匀性而必须不作规定时，使用斜体符号 'ξ' 或 'Ξ'，其前冠以所需的位次（见 P-91.3）。符号 'ξ'（小写希腊字母 xi）代替非大写的 CIP 立体描述符，如 'r'、's'、'm'、'p'。符号 'Ξ'（大写希腊字母 xi）代替大写的 CIP 立体描述符，如 'R'、'S'、'M'、'P'、'E'、'Z'、'seqCis' 和 'seqTrans'。

##### P-91.2.1.2.2 天然产物命名中使用的立体描述符（见 P-10 章）

(i) 描述符 'D' 和 'L' 用于描述碳水化合物（文献 27 和 P-102）、氨基酸和肽（文献 18 和 P-103）以及环醇类（cyclitols）（文献 39 和 P-104）的构型；
(ii) 描述符 'erythro' 和 'threo' 用于碳水化合物的系统命名中，与 'arabino'、'gluco' 等描述符一起使用（见文献 27 和 P-102）；
(iii) 立体描述符 'α'、'β' 用于天然产物命名中，以描述生物碱、萜类和萜类化合物、甾族化合物及其他化合物的绝对构型，如 P-101 所述；
(iv) 立体描述符 'cis'、'trans' 以及 'all-E' 和 'all-trans' 用于类胡萝卜素及类似化合物的命名（见文献 40 和 P-101.6）；
(v) 描述符 'meso' 用于碳水化合物命名中，指代对称因而光学不活泼的化合物，如糖醇（alditols）和糖二酸（aldaric acids）（见 P-102.5.6.5.2；P-102.5.6.6.5）；
(vi) 立体描述符 'ambo' 描述在非手性分子的非立体生成中心反应生成非对映异构体，或手性化合物与外消旋化合物反应（通常不会得到 50:50 的混合物）的情况。为指明这一点，使用前缀 'ambo'（见 P-93.1.4 和 P-103.3.4）。

### P-91.2.2 立体描述符的省略

对于三至七元不饱和脂环化合物，若任何双键具有固定构型（烃类为 'Z'，或根据连接在双键上的配体性质为 'Z' 或 'E'，见 P-93.5.1.4.1），建议省略指明双键的立体描述符。如 'cyclohexene' 或 'cyclohepta-1,3,5-triene' 这样的名称是无歧义的；添加立体描述符 'Z' 不会增加任何额外信息。在八元环中，需要带位次的立体描述符 'Z' 或 'E'：在优选 IUPAC 名称中，当存在一个双键时需要，即在 '(Z)-cyclooctene' 和 '(E)-cyclooctene' 中；但相应的二烯、三烯或四烯则不需要，即 'cycloocta-1,3,5,7-tetraene'。从九元环起，需要立体描述符。在冯·拜尔体系（P-93.5.2.3）、螺环化合物（P-93.5.3.3）、稠环体系（P-93.5.4）、环蕃体系（P-93.5.5.3）以及相同环和环系的集合体（P-93.5.7.3）的名称中，也建议省略立体描述符。

## P-91.3 立体异构体的命名

立体描述符添加到一个按 P-59.1 所述优选 IUPAC 名称形成程序构建的名称上。规则 E-0（文献 1）和 R-7.0（文献 2）中表述的"立体描述符不改变依照这些建议所述命名原则、规则和惯例所确定的化合物的名称或编号"的规则仍然有效，尤其适用于优选 IUPAC 名称。嵌套符号可能改变在引入这些词缀之前确立的嵌套模式。此问题在 P-16.5.4.1 和 P-93.6 中讨论并举例说明。

在优选 IUPAC 名称中，立体描述符紧置于其所相关的名称部分之前。当与母体结构相关时，置于完整名称之前；置于括号中后接连字符。当它们与取代基团相关时，置于相应前缀之前。当存在此类位次时，其前冠以数字或字母位次以描述立体生成单元的位置；应用一般的编号规则（见 P-14.4）。

示例：
- `(R)-bromo(chloro)fluoromethane` (PIN) — 溴（氯）氟甲烷，'R' 指明手性中心（碳原子）的绝对构型
- `(2Z)-but-2-ene` (PIN) — 2-丁烯，'Z' 指明双键构型，位次为 2
- `(3R)-pent-1-en-3-ol` (PIN) — 戊-1-烯-3-醇，'R' 指明 C-3 立体生成中心的绝对构型（另见 P-92.2.1.2）
- `[(1R)-1-chloropropyl]benzene` (PIN) — (1R)-1-氯丙基苯，取代基团前缀中给出 'R' 构型
- `(2S)-butan-2-yl (4R)-4-chlorohexanoate` (PIN) — (2S)-丁-2-基 (4R)-4-氯己酸酯，两个立体生成中心分别以位次 2 和 4 指明

当一个分子含有多于一个立体生成单元时，对每个立体生成单元应用上述程序，母体结构的构型以一组合符号表示。在化合物名称中，这些符号连同其位次写在括号中，用逗号分隔，后接连字符，置于完整名称或取代基之前。多个立体描述符按其各自位次的递增顺序列出。

示例：
- `(2S,3S)-3-chloro-2-hydroxybutanoic acid` (PIN) — 3-氯-2-羟基丁酸，两个立体生成中心（C-2 和 C-3）的构型均以 'S' 表示，按位次递增顺序排列
- `(2Z,6S)-6-chlorohept-2-ene` (PIN) — 6-氯庚-2-烯，'Z'（位次 2）与 'S'（位次 6）混合列出（编号见 P-14.4）
- `(1Ξ)-1-chlorocyclododec-1-ene` (PIN) — 1-氯环十二碳-1-烯，'Ξ'（大写 xi）指明 C-1 处构型未知或未规定

示例：
- `(5Z)-4-[(1E)-prop-1-en-1-yl]hepta-1,5-diene` (PIN) — 4-[(1E)-丙-1-烯-1-基]庚-1,5-二烯，两个双键的构型分别为 'E'（位次 1，取代基内）和 'Z'（位次 5）
- 注：在仅举例说明双键时，'C-4' 处手性中心的立体描述符未包含在名称中。
