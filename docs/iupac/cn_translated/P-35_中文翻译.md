## P-35.0 引言

取代命名法中用于指定特性基团的前缀，是那些具有连接于第 17 族（F、Cl、Br 和 I）或第 16 族（O、S、Se 和 Te）原子、或连接于氮原子的自由价的前缀。它们有保留名（retained name），或按 P-29 所述的由母体氢化物衍生的取代基的方法系统地形成。

氧原子和氮原子也可以连接于碳原子，例如 -CO-OH、-CO-NH2 和 -CO-CH2-CH3，或连接于硫属原子，例如 -S(O)2-OH、-Se(O)2-OH。这些前缀对应于 P-33 中列出的后缀，例如 -OH 的前缀 `hydroxy` 对应于同一基团的后缀 `ol`。前缀也由 P-34 和 P-15.1.2 所定义的官能母体化合物衍生，特别是酰基，例如由乙酸衍生的 -CO-CH3 的 `acetyl`，以及 -PO< 的 `phosphoryl`。

前缀可能既有保留名也有系统名，两者中只有一个是优选 IUPAC 名。为便于选择优选 IUPAC 名，第 P-6 章对每类化合物都给出了明确指示。前缀也按字母顺序列于附录 2 中，并注明其作为优选 IUPAC 名的地位，以及它们在取代命名法中的使用和作为官能置换前缀的使用。

本节描述了取代命名法和倍增命名法中所用不同类型的前缀。

## P-35.1 通用方法

对应于特性基团和官能母体化合物的取代前缀可分为简单前缀（simple prefix，见 P-29.1.1）、复合前缀（compound prefix，见 P-29.1.2）和复杂前缀（complex prefix，见 P-29.1.3）；混合取代基是由取代与加合操作组合而成的复杂取代基。

简单前缀的多次出现用基本倍数词 'di'、'tri' 等表示，或用派生倍数前缀 'bis'、'tris'、'tetrakis' 等表示，以区分两个简单前缀和那些包含基本倍数词的前缀，例如 disulfanyl（'-SSH'，一个 -SSH 基团）与 bis(sulfanyl)（两个 -SH 基团）。复合和混合取代基前缀需要派生倍数词 'bis'、'tris'、'tetrakis' 等来指定它们在取代命名法中的多重性。

简单前缀要么是保留名，要么按下述方法系统地形成：

(1) 从母体氢化物减去氢原子（在 P-29 中称为由母体氢化物衍生的取代基），例如 `sulfanyl`、-SH，和 `diselanyl`、-SeSeH；从官能母体化合物减去氢原子，例如 acetonyl、CH3-CO-CH2-；或从缩写名减去氢原子，例如 `methoxy`、CH3-O-；
(2) 酰基通过从含氧酸减去全部 -OH 基团形成，例如 `acetyl`、CH3-CO-，和 `carbonyl`、>C=O。

## P-35.2 指定特性基团的简单前缀

### P-35.2.1 保留的传统前缀

| 结构式 | 前缀 |
|--------|------|
| -F | `fluoro`（preselected prefix，预选前缀） |
| -Cl | `chloro`（preselected prefix，预选前缀） |
| -Br | `bromo`（preselected prefix，预选前缀） |
| -I | `iodo`（preselected prefix，预选前缀） |
| -OH | `hydroxy`（preselected prefix，预选前缀） |
| =O | `oxo`（preselected prefix，预选前缀） |
| -O- | `oxy`（preselected prefix，预选前缀） |
| -COOH | `carboxy`（preferred prefix，优选前缀） |
| -SO2-OH | `sulfo`（preselected prefix，预选前缀）；`selenono`（Se 替代 S；preselected prefix，预选前缀）；`tellurono`（Te 替代 S；preselected prefix，预选前缀） |
| -SO-OH | `sulfino`（preselected prefix，预选前缀）；`selenino`（Se 替代 S；preselected prefix，预选前缀）；`tellurino`（Te 替代 S；preselected prefix，预选前缀） |
| -NH2 | `amino`（preselected prefix，预选前缀） |
| -N3 | `azido`（preselected prefix，预选前缀） |

|--------|------|

| -NC | `isocyano`（preferred prefix，优选前缀） |

| -NCO | `isocyanato`（preferred prefix，优选前缀） |
|  | `isothiocyanato`（S 替代 O；preferred prefix，优选前缀） |
|  | `isoselenocyanato`（Se 替代 O；preferred prefix，优选前缀） |
|  | `isotellurocyanato`（Te 替代 O；preferred prefix，优选前缀） |

### P-35.2.2 由单核和双核母体氢化物减去一个或多个氢原子形成的取代基（见 P-21.1、P-21.2）

系统名按 P-29.3.1 所述的一般方法形成。

示例：

| 结构式 | 前缀 |
|--------|------|
| -SH | `sulfanyl`（preselected prefix，预选前缀）（不用 mercapto） |
| -S- | `sulfanediyl`（preselected prefix，预选前缀）；`thio` |
| =S | `sulfanylidene`（preselected prefix，预选前缀）；`thioxo` |
| -SS- | `disulfanediyl`（preselected prefix，预选前缀）；`dithio` |
| -SeH | `selanyl`（preselected prefix，预选前缀）（不用 selenyl） |
| -Se- | `selanediyl`（preselected prefix，预选前缀）；`seleno` |
| =Se | `selanylidene`（preselected prefix，预选前缀）；`selenoxo` |
| -SeSe- | `diselanediyl`（preselected prefix，预选前缀）；`diseleno` |
| -TeH | `tellanyl`（preselected prefix，预选前缀） |
| -Te- | `tellanediyl`（preselected prefix，预选前缀）；`telluro` |
| =Te | `tellanylidene`（preselected prefix，预选前缀）；`telluroxo` |
| -TeTe- | `ditellanediyl`（preselected prefix，预选前缀）；`ditelluro` |
| H2N-NH- | `hydrazinyl`（preselected prefix，预选前缀）；`diazanyl` |
| HN=N- | `diazenyl`（preselected prefix，预选前缀） |
| -NH- | `azanediyl`（preselected prefix，预选前缀）（连接于不同原子） |
| -N= | `azanylylidene`（preselected prefix，预选前缀）（连接于不同原子） |
| ≡N | `azanylidyne`（preselected prefix，预选前缀）（连接于同一原子） |

基于母体氢化物 azane 的系统名是 -HN- 的优选 IUPAC 名，以区分 HN= 与 -HN-（两者通常都称为 'imino'）。

基于母体氢化物 azane 的系统名是 -N= 的优选 IUPAC 名，以区分 -N< 与 -N=（两者通常都称为 'nitrilo'）。

## P-35.3 复合取代基前缀

### P-35.3.1

由后缀或官能母体化合物衍生的复合前缀名，可通过将简单前缀代入其他简单前缀而形成。当有选择时，P-57.4 提供优选复合前缀（preferred compound prefix）的选择规则。

示例：
- `selanylsulfanyl`（preselected prefix，预选前缀）— 用于 -SSeH
- `chloroamino`（preselected prefix，预选前缀）— 用于 -NH-Cl
- `methylamino`（preferred prefix，优选前缀）— 用于 -NH-CH3
- `chlorophosphanyl`（preselected prefix，预选前缀）— 用于 -PH-Cl

### P-35.3.2

由后缀或官能母体化合物衍生的复合前缀名，可通过称为连接（concatenation）的加合操作形成。该操作用于组装简单的一价、二价、三价和四价前缀。烃基二价取代基可以连接到表达特性基团的前缀上。此方法在没有氢原子可供取代时使用（见 P-15.1）；它也可用于在倍增命名法中形成取代基（见 P-15.3.1.2.2）。

示例：
- `pentyloxy`（preferred prefix，优选前缀）— 用于 -O-CH2-CH2-CH2-CH2-CH3
- `benzyloxy`（preferred prefix，优选前缀）— 用于 -O-CH2-C6H5
- `carbonochloridoyl`（preferred prefix，优选前缀）；`chlorocarbonyl` — 用于 -CO-Cl
- `C-hydroxycarbonimidoyl`（preferred prefix，优选前缀）；`hydroxy(imino)methyl` — 用于 -C(=NH)-OH
- `C-hydroxycarbonohydrazonoyl`（preferred prefix，优选前缀）；`hydrazinylidene(hydroxy)methyl` — 用于 -C(=N-NH2)-OH
- `ethane-1,2-diylbis(oxy)`（preferred prefix，优选前缀）— 用于 -O-CH2-CH2-O-
- `methylenedinitrilo`（preferred prefix，优选前缀）— 用于 >N-CH2-N<
- `methylenebis(phosphorothioyl)`（preferred prefix，优选前缀）— 用于 >P(S)-CH2-P(S)<

## P-35.4 复杂取代基前缀

### P-35.4.1

复杂取代基前缀名可通过将简单或复合取代基前缀代入复合取代基前缀而形成。当有选择时，P-57.4 提供优选复杂取代基前缀（preferred complex substituent prefix）的选择规则。

示例：
- `(selanylsulfanyl)amino`（preselected prefix，预选前缀）— 用于 -NH-S-SeH
- `(chloromethyl)amino`（preferred prefix，优选前缀）— 用于 -NH-CH2Cl
- `(4-chlorophenyl)methoxy`（preferred prefix，优选前缀）
- `(methoxyamino)phosphanyl`（preferred prefix，优选前缀）— 用于 -PH-NH-OCH3

### P-35.4.2

复杂取代基前缀名可通过将简单或复合取代基前缀加到复合取代基前缀上，以称为'连接'（concatenation）的过程形成。

示例：
- `(benzyloxy)carbonyl`（preferred prefix，优选前缀）— 用于 -CO-O-CH2-C6H5
- `(methoxycarbonothioyl)oxy`（preferred prefix，优选前缀）— 用于 -O-CS-OCH3
- `[(dimethoxyphosphoryl)oxy]carbonothioyl`（preferred prefix，优选前缀）— 用于 -CS-O-P(O)(OCH3)2

---

## P-35.5 混合取代基前缀

### P-35.5.1

混合取代基前缀名通过组合取代与加合操作形成。

示例：
- `(ethoxysulfinyl)amino`（preferred prefix，优选前缀）— 用于 CH3-CH2-O-SO-NH-
- `(acetylsulfanyl)carbonyl`（preferred prefix，优选前缀）— 用于 CH3-CO-S-CO-
- `{[(acetyloxy)amino]sulfinyl}oxy`（preferred prefix，优选前缀）— 用于 CH3-CO-O-NH-SO-O-
- `[bis(sulfanyl)phosphoryl]amino`（preselected prefix，预选前缀）— 用于 (HS)2(O)P-NH-
