**P-21 单核及无环多核母体氢化物（mononuclear and acyclic polynuclear parent hydrides）**

- **P-21.1** — 单核母体氢化物（mononuclear parent hydrides）

## P-21.1 单核母体氢化物

### P-21.1.1 标准键数的单核母体氢化物

#### P-21.1.1.1 系统名称

在取代命名（substitutive nomenclature）法中命名有机化合物时用作母体的单核元素氢化物的名称列于表 2.1。多数名称是通过引用元素的 'a' 词缀（见 Table 2.4）并省去词尾 'ane' 之前的末尾字母 'a' 而系统性构成的（仿照 methane），例如 `borane` 表示 `BH₃`，`silane` 表示 `SiH₄` 等。**存在重要例外**：`oxidane` 表示 `H₂O`，`sulfane` 表示 `H₂S`，`selane` 表示 `H₂Se`，`tellane` 表示 `H₂Te`，`polane` 表示 `H₂Po`，`bismuthane` 表示 `BiH₃`（见表 2.1）。系统构成的名称 `oxane`、`thiane`、`selenane`、`tellurane`、`polonane` 和 `bismane` 是 Hantzsch-Widman 名称，指代含单个杂原子的相应饱和六元环。名称 `carbane` 从未被用来替代 `methane`；**不推荐使用**。

**表 2.1 具有正常键数的第 13、14、15、16、17 族元素单核母体氢化物的系统名称**

（除 `carbane` 外，所有系统名称均为预选名称（preselected name）；见 P-12.2；保留名（retained name）`methane` 见 P-21.1.1.2）

| 族 | 13 | 14 | 15 | 16 | 17 |
|----|----|----|----|----|----|
| | `BH₃` `borane` | `CH₄` (`carbane`)* | `NH₃` `azane` | `OH₂` `oxidane` | `FH` `fluorane` |
| | `AlH₃` `alumane` | `SiH₄` `silane` | `PH₃` `phosphane` | `SH₂` `sulfane` | `ClH` `chlorane` |
| | `GaH₃` `gallane` | `GeH₄` `germane` | `AsH₃` `arsane` | `SeH₂` `selane` | `BrH` `bromane` |
| | `InH₃` `indigane` | `SnH₄` `stannane` | `SbH₃` `stibane` | `TeH₂` `tellane` | `IH` `iodane` |
| | `TlH₃` `thallane` | `PbH₄` `plumbane` | `BiH₃` `bismuthane` | `PoH₂` `polane` | `AtH` `astane` |

\* 注意：`methane` 是优选 IUPAC 名称（PIN）。

用于 IUPAC 有机及无机化合物命名的俗名见 P-21.1.1.2。

新推荐的名称 `gallane` 和 `thallane` 系系统性构成。`alumane` 和 `indigane` 是例外。名称 `aluminane` 可能有歧义，因为它既可指单核氢化物 `AlH₃`，也可指含一个铝原子、具有以词尾 '-inane' 表示的 Hantzsch-Widman 名称的饱和六元环。名称 `alane` 曾被使用，但也必须弃用，因为其系统性衍生的取代基 `H₂Al-` 会被命名为 `alanyl`，而 `alanyl` 是源自氨基酸丙氨酸（alanine）的酰基的既定名称。名称 `alumane` 没有负面含义。推荐使用前缀 `aluma` 构成 Hantzsch-Widman 名称，因此名称 `aluminane` 描述含一个铝原子的饱和六元单环（见 P-22.2.2）。系统构成的名称 `indane` 不能使用，因为它已被用于指代一个部分饱和的双环稠合烃。Reich 和 Richter（参考文献 20）于 1863 年根据靛蓝色（indigo colored）火焰试验将元素铟（indium）命名，该颜色被认定不同于铯（caesium）所呈现的颜色。回归本源 indigo，`indigane` 可以是可接受的名称；因此推荐用它表示氢化物 `InH₃`。

示例：

- `AlH₃` → `alumane`（预选名称，见 P-12.2）（不是 `alane`）
  `aluminane`（含一个铝原子的饱和六元单环）
- `InH₃` → `indigane`（预选名称，见 P-12.2）
  `indane` — 不可用
  `2,3-dihydro-1H-indene` (PIN)

表 2.1 中所列的单氢化物名称构成"广义 ane 命名法"（generalized ane nomenclature）的基础。取代命名法应用于烷烃、环烷烃和多环烷烃时已被系统性地扩展至第 13、14、15、16、17 族元素的氢化物。广义 'ane' 命名法分为"carbane 命名法"（涵盖碳母体氢化物的传统取代命名法）和"heterane 命名法"（涉及碳以外的原子，这些原子称为杂原子（heteroatom））。

#### P-21.1.1.2 保留名

俗名 `methane` 被保留。俗名 `water`（水）、`ammonia`（氨）、第 17 族氢酸（hydracid）的二元名称（例如 `hydrogen chloride`（氯化氢））以及第 16 族氢化物的二元名称（例如 `hydrogen sulfide`（硫化氢））在这些建议中使用，但其用作优选 IUPAC 名称的使用被推迟，有待优选无机名称选择建议的发布；因此，包含它们的名称将不标注 PIN（见 P-14.8）。然而，这些俗名的系统替代名称，例如用 `oxidane` 代替 water、`azane` 代替 ammonia，以及第 17 族氢酸二元名称和第 16 族氢化物二元名称的替代，例如用 `chlorane` 代替 hydrogen chloride、`sulfane` 代替 hydrogen sulfide，对于命名某些衍生物以及生成自由基、离子和多核同系物的名称是必要的。

名称 `phosphine`（`PH₃`）、`arsine`（`AsH₃`）、`stibine`（`SbH₃`）和 `bismuthine`（`BiH₃`）被保留用于一般命名法中。

### P-21.1.2 非标准键数的单核母体氢化物

#### P-21.1.2.1 系统名称与传统名称

若元素的键数（bonding number）不同于 P-14.1 中定义并在表 2.1 中例示的标准键数，则**通过在该氢化物名称上附加符号 λn（其中 'n' 为键数）来修饰该氢化物的名称**（参考文献 13）。此即 λ 约定（λ-convention）。

名称 `phosphorane`（`PH₅`）、`arsorane`（`AsH₅`）和 `stiborane`（`SbH₅`）被保留用于一般命名法。然而，近期文献中使用的名称 `sulfurane`（`SH₄`）、`selenurane`（`SeH₄`）、`iodinane`（`IH₃`）、`persulfurane`（`SH₆`）和 `periodinane`（`IH₅`）**不被推荐**。

示例：

- `IH₃` → `λ3-iodane`（预选名称，见 P-12.2）（不是 `iodinane`）
- `SH₄` → `λ4-sulfane`（预选名称，见 P-12.2）（不是 `sulfurane`）
- `SnH₂` → `λ2-stannane`（预选名称，见 P-12.2）
- `PH₅` → `λ5-phosphane`（预选名称，见 P-12.2）
  `phosphorane`（保留名）
- `AsH₅` → `λ5-arsane`（预选名称，见 P-12.2）
  `arsorane`（保留名）
- `SbH₅` → `λ5-stibane`（预选名称，见 P-12.2）
  `stiborane`（保留名）

## P-21.2 无环多核母体氢化物

- **P-21.2.1** — 烃（hydrocarbons）
- **P-21.2.2** — 烃和硼氢化物以外的均一（homogeneous）无环母体氢化物
- **P-21.2.3** — 不均一（heterogeneous）无环母体氢化物
- **P-21.2.4** — 含非标准键数杂原子的无环母体氢化物

### P-21.2.1 烃

饱和无支链无环烃 `C₂H₆`、`C₃H₈` 和 `C₄H₁₀` 分别具有保留名 `ethane`、`propane` 和 `butane`。该系列更高成员的系统名称由一个数词（见表 1.4）后接词尾 'ane' 构成，同时省去数词的末尾字母 'a'。饱和无环烃（支链或无支链）的属名为 `alkane`（烷烃）。**链用阿拉伯数字从一端到另一端编号**。在结构式中使用方括号表示链中基团的重复。不饱和无环烃见 P-31.1。

示例：

- `heptane` (PIN)
- `icosane` (PIN)（Beilstein 和 CAS 索引名为 `eicosane`）
- `tricosane` (PIN)
- `heptacontane` (PIN)

### P-21.2.2 烃和硼氢化物以外的均一无环母体氢化物

由含两个或更多相同杂原子、以氢原子饱和的无支链链组成的化合物，通过**引用表 1.4 中适当的倍增前缀（multiplying prefix）（倍增前缀的末尾元音不省略）后接按 P-21.1 确定的适当氢化物名称**来命名。这些名称为预选名称（见 P-12.2）。末端基团的潜在官能性（如 `-SH` 或 `-OH`）被忽略。

示例：

- `hydrazine`（保留名，预选名称，见 P-12.3）
  `diazane`（系统名称）
- `nonaazane`（预选名称，见 P-12.2）
- `pentasilane`（预选名称，见 P-12.2）
- `pentaphosphane`（预选名称，见 P-12.2）
- `HS-S-S-SH` → `tetrasulfane`（预选名称）（不是 `disulfanedithiol` 或 `trisulfanethiol`，见 P-58.3.1）

### P-21.2.3 不均一无环母体氢化物

需考虑两种类型。

- **P-21.2.3.1** — 由交替原子组成的不均一母体氢化物
- **P-21.2.3.2** — 通过骨架置换（'a'）命名法构成的不均一母体氢化物

#### P-21.2.3.1 由交替杂原子组成的不均一母体氢化物，即 [a(ba)ₙ 氢化物]，不包括碳原子和卤素原子

含有无支链交替原子链、链两端由优先级序列 **O > S > Se > Te > N > P > As > Sb > Bi > Si > Ge > Sn > Pb > B > Al > Ga > In > Tl** 中较晚出现的同一元素的两个相同原子封端的化合物，可通过**依次引用表示末端元素原子数的倍增前缀后接该元素的 'a' 词缀，再接链中另一元素的 'a' 词缀和词尾 'ane'** 来命名。**当 'a' 词缀后跟元音时，其末尾字母 'a' 省略；数值前缀的末尾元音即使 'a' 词缀以相同元音开头也不省略。**当存在氮原子时，由于胺的官能度更高，应使用胺名称（见 P-62）。该概念不扩展到其他元素。这些母体氢化物是预选母体氢化物（见 P-12.2），只要用于命名含碳化合物，就有资格获得优选 IUPAC 名称。

这是对 1993 版指南（参考文献 2）的变更，其中 'amine'（胺）特征基团未被识别。

示例：

- `tetrastannoxane`（预选名称，见 P-12.2）
- `SiH₃-S-SiH₃` → `disilathiane`（预选名称，见 P-12.2）
- `HS-O-SH` → `dithioxane`（预选名称，见 P-12.2）
- `PH₂-Se-PH₂` → `diphosphaselenane`（预选名称，见 P-12.2）
- `SiH₃-NH-SiH₃` → `N-silylsilanamine`（名称由预选名称 silane 衍生，见 P-12.2）（不是 `disilazane`）

#### P-21.2.3.2 通过骨架置换（'a'）命名法构成的不均一母体氢化物

由含至少一个碳原子和杂原子（相同或不同）、并以 C、P、As、Sb、Bi、Si、Ge、Sn、Pb、B、Al、Ga、In 或 Tl 封端的链组成的不均一无环母体氢化物，通过**骨架置换（'a'）命名法**（skeletal replacement ('a') nomenclature）命名（见 P-15.4.3）。骨架置换（'a'）名称作为优选 IUPAC 名称的使用在第 P-5 章中考虑。

示例：

- `2,4,7,10-tetraoxaundecane` (PIN)
- `7,10-dioxa-2-thia-4-silaundecane` (PIN)
- `2-oxa-7-thia-3,6-disilaoctane` (PIN)

### P-21.2.4 含非标准键数杂原子的无环母体氢化物

#### P-21.2.4.1

非标准键数杂原子用 λn 符号表示，**该符号置于每个适当的位次（locant）之后**（见 P-14.1）。**通常先以通常方式将低位次给予杂原子，而不考虑非标准键数。当有选择时，较低位次给予较高的非标准键数。**

示例：

- `2λ4-trisulfane`（预选名称，见 P-12.2）
- `1λ6-trisulfane`（预选名称，见 P-12.2）
- `1λ5,2λ5,3λ5-triphosphane`（预选名称，见 P-12.2）（不是 `tri-λ5-phosphane`）
- `1λ5,3λ5-diphosphoxane`（预选名称，见 P-12.2）

#### P-21.2.4.2

当需要在同一骨架原子具有两个或更多非标准键数之间选择时，**按键数递减的顺序分配低位次**，例如 `λ6` 的位次低于 `λ4`。

示例：

- `2λ6,5λ4-hexasulfane`（预选名称，见 P-12.2）
- `2,5λ4,8,11-tetrathiadodecane` (PIN)
