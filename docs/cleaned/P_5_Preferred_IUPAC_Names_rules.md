[ ] [P-51.3.1#3] [P-437] [L5690-5694] 本版要求所有取代基团包括主要特征基团必须相同且定位编号相同才能构建乘法名称，与早期规则不同

[ ] [P-51.3.2.2#2] [P-440] [L5726-5728] 当满足条件时，优选IUPAC名称由骨架替换命名法或phan命名法形成

[ ] [P-51.3.2.3] [P-440] [L5770-5776] 当需在母体结构和乘法基团组分间选择时，使用类别优先级顺序

[ ] [P-51.3.3] [P-441] [L5777-5780] 当P-51.3.1条件不满足时，优选IUPAC名称由取代命名法原则生成

## P-52 选择母体氢化物的优选IUPAC名称和预选名称

[ ] [P-52#1] [P-445] [L6074-6078] 命名P-2章所述母体氢化物时，当只有一种方法描述，所得单一名称自然是优选IUPAC名称

[ ] [P-52#2] [P-445] [L6079-6083] 当推荐多种方法生成母体氢化物名称时，必须选择优选IUPAC名称，某些情况下选择预选名称

### P-52.1 选择预选名称

[ ] [P-52.1.1] [P-445] [L6087-6090] 单核母体氢化物名称列于P-21.1.1；phosphane、arsane、stibane和bismuthane是预选名称

[ ] [P-52.1.2] [P-446] [L6094-6097] 同质无环多核母体氢化物的预选名称描述于P-21.2.2；hydrazine是预选名称

[ ] [P-52.1.3#1] [P-446] [L6101-6104] 由交替'ab'原子组成的非均质无环母体氢化物的预选名称描述于P-21.2.3.1

[ ] [P-52.1.3#2] [P-446] [L6105-6108] 本版规定'amine'特征基团在a(ba)n母体氢化物中被认可，与早期规则不同

[ ] [P-52.1.4] [P-446] [L6131-6133] 具有非标准键合数的母体氢化物的预选名称讨论于P-21.1.2.1

#### P-52.1.5 杂单环非碳Hantzsch-Widman母体氢化物

[ ] [P-52.1.5#1] [P-446] [L6141-6143] Hantzsch-Widman名称中的最终'e'在优选IUPAC名称中为必需，在通用命名中仍可选

[ ] [P-52.1.5#2] [P-446] [L6144-6147] 1979规则中，当环中无氮时省略Hantzsch-Widman名称的最终'e'；1993指南使其可选

[ ] [P-52.1.5.1] [P-446] [L6148-6158] 由十个或更少环成员组成的同质杂单环母体氢化物的预选名称是Hantzsch-Widman名称

[ ] [P-52.1.5.2] [P-447] [L6178-6187] 由交替杂原子组成的非均质杂单环母体氢化物的预选名称是Hantzsch-Widman名称或骨架替换名称

#### P-52.1.6 杂环非碳von Baeyer和螺化合物

[ ] [P-52.1.6.1] [P-447] [L6211-6219] von Baeyer化合物和螺化合物的预选名称由前缀、方括号描述符、数字前缀和单核母体氢化物名称组成

[ ] [P-52.1.6.2] [P-448] [L6241-6249] 由交替杂原子组成的von Baeyer和螺化合物的预选名称由前缀、描述符和骨架替换名称组成

[ ] [P-52.1.7] [P-448] [L6082-6091] 同质和非均质杂双环和杂多环稠环系统的预选名称由融合命名法原则形成

### P-52.2 选择优选IUPAC名称

[ ] [P-52.2.1.1] [P-449] [L6133-6137] methane、ethane、propane和butane用作优选IUPAC名称；acetylene是优选IUPAC名称但不允许取代

[ ] [P-52.2.1.2] [P-449] [L6138-6147] [n]annulene在优选IUPAC名称中用作融合命名法的母体组分；优选IUPAC名称由相应环烷烃名称生成

[ ] [P-52.2.2.2#1] [P-449] [L6159-6163] 具有不超过十个环成员的杂单环的优选IUPAC名称是Hantzsch-Widman名称

[ ] [P-52.2.3] [P-449] [L6182-6193] 具有十个以上环成员的不饱和杂单环化合物的优选IUPAC名称由饱和杂单环的'ane'结尾改为'ene'等形成

#### P-52.2.4 融合命名法中的优选IUPAC名称

[ ] [P-52.2.4.1#1] [P-450] [L6208-6212] 融合命名法仅给予具有至少两个至少五元环的化合物的优选IUPAC名称

[ ] [P-52.2.4.3] [P-450] [L6269-6276] 当两个或更多可能的母体组分被奇数个中间组分分隔且对称排列时，整个系统被视为多母体系统

[ ] [P-52.2.4.4] [P-451] [L6296-6301] 当第三组分正交-和周边-稠合到两个本身正交或正交-和周边-稠合的组分时，需应用特定程序生成优选IUPAC名称

#### P-59.2.2 杂原子优先于后缀

[ ] [P-59.2.2] [P-494] [L9039-9045] 杂环化合物和骨架替换命名法的链被类似处理；杂原子优先获得低定位编号，后缀获得下一个可能的最低定位编号

[ ] [P-59.2.2.1] [P-495] [L9053-9056] 对链应用替换操作创建具有固定编号的新母体氢化物；后缀按结果编号获得最低定位编号

[ ] [P-59.2.2.2] [P-495] [L9099-9103] 具有保留或系统名称的杂环化合物被视为母体氢化物；后缀按固定编号获得最低定位编号，添加指示氢获得下一个最低定位编号

#### P-59.2.3 后缀优先于不饱和

[ ] [P-59.2.3.1] [P-496] [L9159-9162] 后缀之后，若有选择，将低定位编号分配给'ene'和'yne'结尾，然后是可分离前缀

[ ] [P-59.2.3.2] [P-496] [L9191-9200] hydro和dehydro前缀用于表达母体氢化物氢化度的变化；它们是可分离的但不属于按字母顺序排列的可分离取代基前缀

[ ] [P-59.2.3.3] [P-497] [L9242-9246] Mancude酮、亚胺等使用'添加指示氢'方法命名；若有选择，指示氢优先获得低定位编号，然后是后缀、添加指示氢、最后是hydro前缀

#### P-59.2.4 'ene'和'yne'结尾及hydro前缀优先于可分离前缀

[ ] [P-59.2.4] [P-500] [L9425-9428] 若有选择，低定位编号首先分配给'ene'和'yne'结尾和'hydro/dehydro'前缀，然后是按字母顺序排列的可分离前缀

#### P-59.2.5 可分离前缀的处理

[ ] [P-59.2.5] [P-500] [L9464-9467] 若有选择，低定位编号分配给一起考虑的可分离前缀；若有进一步选择，按字母数字顺序
